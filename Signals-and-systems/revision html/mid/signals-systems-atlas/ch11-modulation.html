1. 为什么非要调制：一根天线引出的问题

先回答一个最朴素的问题：直接把人声送进天线不行吗？不行，原因是物理的。 天线要把电磁波有效地辐射出去，它的尺寸得和波长同一个量级（常用半波振子 λ/2、四分之一波长 λ/4）。而波长和频率的关系是

λ = cf, 　c ≈ 3 × 108 m/s (11-1)

算两个数你就明白问题的严重性：

信号频率 f波长 λ = c/fλ/4 天线长度能不能做
人声（最高约 4 kHz）4 × 103 Hz75 km≈ 19 km不可能
中波广播载波550 kHz545 m≈ 136 m能做（广播塔就这么高）
手机/Wi-Fi 载波2.4 GHz12.5 cm≈ 3.1 cm轻松（芯片上天线几毫米）

结论：要把信息送出去，就得先把它"抬"到一个高得多的频率上去。这个"抬"的动作就叫 调制（modulation）， 接收端把它"放回来"的动作叫 解调（demodulation）。

第二个理由是频谱是一种公共资源。大气对 10 Hz～20 kHz 的音频衰减极快，根本传不远； 而几百 kHz 到几十 GHz 的频段可以传播很远。可这段"好频段"是有限的：如果每个人声信号都占着 0～4 kHz 这一段，谁也挤不进去。调制让我们把不同的信号搬到不同的载频上， 于是它们在同一根电缆、同一段空气里各占一块地盘，互不干扰。这就是 频分复用（frequency-division multiplexing，FDM）。

本章的三个关键词，先记下来

设要传的信号叫 调制信号（modulating signal） x(t)，用来"承载"它的高频振荡叫 载波（carrier） c(t) = cos(ωct)，其中 载波频率（carrier frequency） ωc 就是收音机面板上调的那个数。 调制器做的运算只有一件事：相乘 y(t) = x(t)·c(t)。

2. 复指数载波：频谱整体搬移

先从最简单的载波开始：复指数 c(t)=ejωct。 虽然它物理上不能单独存在（复信号），但把它的道理弄懂，实信号的调制就是"取实部"而已。

推导（点开/收起）：y(t)=x(t)ejωct ⟹ Y(jω)=X(j(ω−ωc))

第 1 步：写出相乘性质（第 6 章证过）。

Y(jω) = 12π ∫+∞−∞ X(jθ) C(j(ω−θ)) dθ

为什么：时域相乘 ⟺ 频域卷积（卷积定义就是"翻转移位相乘积分"）。这里的 1/2π 来自反变换的定义约定，不能丢。

第 2 步：写出复指数的频谱（第 6 章变换对 ④）。

ejωct ⟷ 2π δ(ω − ωc)

为什么是冲激：复指数只含"一个"频率，所以它的谱是一根线；2π 是因为反变换里带了 1/2π，两边要配平。

第 3 步：把 C(j(ω−θ)) = 2π δ(ω−θ−ωc) 代进卷积积分，用冲激的筛选性质。

Y(jω) = 12π ∫+∞−∞ X(jθ) · 2π δ(ω−θ−ωc) dθ = ∫+∞−∞ X(jθ) δ(θ − (ω−ωc)) dθ = X(j(ω−ωc))

为什么：筛选性质 ∫f(θ)δ(θ−a)dθ = f(a)——冲激只把 θ=a 那一处的值"挑"出来。这里 a = ω−ωc；同时 2π 与 1/2π 相消。

第 4 步：一行读完结论。

Y(jω) = X(j(ω−ωc))：把整条 X 曲线沿频率轴向右平移 ωc

为什么这也叫频移性质：第 6 章性质表里"乘 ejω₀t ⟺ 频谱搬移"就是这条。从这里看，调制的数学本质 = 频谱搬家。

复指数调制的解调只要一步

再乘一次 e−jωct 就搬回来了： x(t) = y(t)·e−jωct（把上面的推导里 ωc 换成 −ωc）。 干净利落，不需要滤波器、不需要放大。可惜现实里我们只能发实信号。

3. 正弦载波：频谱劈成两半（完整推导）

现在用真正的载波 c(t) = cos(ωct)， 发出的信号是实的：y(t) = x(t)cos(ωct)。 这一步的代价是：一条谱变成了两条。

推导（点开/收起）：Y(jω) = ½[X(j(ω−ωc)) + X(j(ω+ωc))]

第 1 步：先把余弦拆成两个复指数的和（欧拉公式）。

cos(ωct) = 12 ( ejωct + e−jωct )

为什么：欧拉公式 ejθ+e−jθ = 2cosθ。实余弦天生就是"两个复指数"的组合。

第 2 步：写出余弦的频谱。

cos(ωct) ⟷ π[ δ(ω−ωc) + δ(ω+ωc) ]

为什么：由第 1 步，两个复指数各贡献一根 2πδ，再乘 1/2 得 πδ。第 6 章变换对 ⑤ 就是它——一个余弦在谱上占两根线（±ωc）。

第 3 步：套相乘性质。

Y(jω) = 12π ∫+∞−∞ X(jθ) · π[ δ(ω−θ−ωc) + δ(ω−θ+ωc) ] dθ

为什么：把 C(j(ω−θ)) 写出来——它与第 2 步的形式一样，只是自变量换成 ω−θ，两根冲激分别落在 θ = ω−ωc 和 θ = ω+ωc。

第 4 步：拆成两个积分，各自用筛选性质。

= π2π [ ∫+∞−∞ X(jθ)δ(θ−(ω−ωc))dθ + ∫+∞−∞ X(jθ)δ(θ−(ω+ωc))dθ ]
Y(jω) = 12 [ X(j(ω−ωc)) + X(j(ω+ωc)) ] (11-2)

为什么系数是 1/2：π/2π = 1/2。两个积分分别把 θ 钉在 ω−ωc 和 ω+ωc 上，于是得到"X 分别向左、向右搬 ωc"的两份拷贝。

第 5 步：几何图像与一个硬条件。

设 x(t) 是带限的：|ω| > ωM 时 X(jω)=0（ωM 叫最高频率）。 那 Y(jω) 就是两块宽 2ωM 的频谱， 分别坐在 ±ωc 上。

为什么必须 ωc > ωM：两块拷贝各自从 ωc−ωM 和 −ωc+ωM 开始向中间延伸。只有 ωc−ωM > −ωc+ωM， 即 ωc > ωM，它们才不重叠、互不污染。一旦重叠（ωc < ωM）， 信息就被搅在一起，后面无论怎么滤波都救不回来。

"双边带、抑制载波"这个名字是怎么来的

以 +ωc 为中心的那块谱，从 ωc−ωM 到 ωc 的一段叫下边带，从 ωc 到 ωc+ωM 的一段叫上边带；两块谱就是"双边带"。 而 cos(ωct) 自身那两根谱线在相乘之后不见了（被搬走的是 X，不是 C）， 所以叫抑制载波（suppressed carrier，缩写 DSB/SC）。

你可能会问：既然正负频率各搬一份、内容重复，那是不是浪费了一半带宽？是的， 这就是第 10 节"单边带"要解决的问题。但它换来一个巨大的好处：信号仍然是实的， 一根天线就能发。

4. 接收端：同步解调、低通与放大 2 倍

接收端拿到的只有 y(t)=x(t)cos(ωct)。 怎么把 x(t) 掏出来？答案简单到让你怀疑： 再乘一次同一个余弦。这个操作叫 同步解调（synchronous demodulation）。

推导（点开/收起）：cos²θ=(1+cos2θ)/2 —— 解调的全部秘密就在这一步

第 1 步：接收端再乘一次载波，记结果叫 w(t)。

w(t) = y(t)·cos(ωct) = x(t)cos(ωct)·cos(ωct) = x(t)cos2(ωct)

为什么能这样乘：接收端自己有一个本地振荡器，产生与发送端同频同相的余弦。相乘在电路里就是一个乘法器（混频器）。

第 2 步：用倍角公式把 cos² 降次——这一步是全部的关键。

cos2θ = 1 + cos 2θ2 (11-3)

为什么成立：由 cos(2θ) = cos²θ − sin²θ = 2cos²θ − 1 反解即得。它的意义是：平方之后，直流成分出现了——而直流成分正是我们要的信息。

第 3 步：把 θ = ωct 代进去。

w(t) = x(t)·1 + cos(2ωct)2 = 12x(t) + 12x(t)cos(2ωct) (11-4)

为什么拆成两项：第一项 x(t)/2 是"低频项"（x 的频谱还在 0 附近），第二项是一个被 2ωc 调制过的高频项（频谱跑到 ±2ωc 去了）。两项在频率上已经分家了，这就给了我们"用滤波器把它们分开"的机会。

第 4 步：换成频域看清楚。对式 (11-4) 两边做变换，用式 (11-2)（把 ωc 换成 2ωc）：

W(jω) = 12X(jω) + 14 [X(j(ω−2ωc)) + X(j(ω+2ωc))] (11-5)

为什么第二项系数是 1/4：它先是 +½x·cos(2ωct)，而余弦调制本身就带一个 ½，½ × ½ = ¼。所以高频副本的高度只有直流那份的一半。
注意这里是加号：cos²θ=(1+cos2θ)/2 里两项同号，所以 w(t) = ½x + ½x cos 2ωct。 如果写成减号，2ωc 处那份副本就会反相，与下面频域推导式 (11-5) 的结论矛盾——两边的符号必须一致。

第 5 步：低通滤波，把高频副本切掉。取一个理想低通，截止频率 ωco 满足

ωM < ωco < 2ωc − ωM (11-6)

低通输出就是 ½x(t)。最后乘 2（一个放大器）：

2 × 12x(t) = x(t) ✓

为什么截止频率是这个范围：
下界 ωco > ωM：x(t) 的最高频率是 ωM，低通必须比它宽，否则会把 x 自己的高频成分砍掉（声音变闷、脉冲变钝）。
上界 ωco < 2ωc − ωM：高频副本从 2ωc − ωM 开始，低通必须比它窄，否则高频副本漏进来，输出上会叠一层 2ωc 的纹波。
为什么必须放大 2 倍：cos² 的降次公式"多"了一个 1/2 因子（这就是信息被"摊薄"的地方），不补回来信号就小了一半。

为什么理想低通的截止频率有整整一段区间可以选

因为 ωM 和 2ωc−ωM 之间有一段"真空"（ωc > ωM 保证了 ωM < 2ωc−ωM）， 只要把低通放在这段真空里就不会错。这段真空的宽度 = 2(ωc−ωM)，载波越高，容错越大。 实践中的滤波器都不理想（第 10 章），所以工程师总希望载波尽量高一些。

一句话记住这条链

发送：乘 cos ⟹ 频谱搬到 ±ωc。
接收：再乘 cos ⟹ 每个副本又"劈成两半"，其中一半回到 0（有用，高度 ½），另一半跑到 ±2ωc（垃圾）。
低通：扔掉 ±2ωc 的垃圾。放大 2 倍：补回 ½ 的亏空。

下面这个实验台把整条链路摊开：上排三张是发送端（基带、已调波形、搬移后的频谱）， 下排两张是接收端（再乘 cos 之后的频谱、低通滤波并放大 2 倍之后的波形）。 基带信号取严格带限的 x(t) = (W/π)sinc(Wt)， 它的频谱正好是一个高度 1、宽度 2W 的矩形，所以下面每一张图都能对得严丝合缝。

请按这个顺序玩，并且只看图不看文字

① 认三块砖：第三张图（已调频谱）里，基带那块"砖"被一分为二，各搬到 ±ωc，高度变成一半。这就是调制。

· 刚好（W < ωco < 2ωc−W）：恢复的波形与原来的 x(t) 完全重合（看误差数字应该是 0）；

6. 本地载波不同步会怎样

上面的一切都建立在"接收端的余弦与发送端的余弦同频同相"这个假设上。 现实里它们是两台独立的振荡器，永远有误差。把误差代进推导，看看会发生什么。

推导（点开/收起）：相位误差 φ 与频率误差 Δω

第 1 步：设发送载波为 cos(ωct + θc)，本地载波为 cos((ωc+Δω)t + φc)。

w(t) = x(t)·cos(ωct + θc)·cos((ωc+Δω)t + φc)

为什么这样设：Δω 表示频率对不上，θc−φc 表示相位对不上。两个误差可以同时存在。

第 2 步：用积化和差 cosA·cosB = ½[cos(A−B) + cos(A+B)]。

w(t) = 12x(t)cos(Δω·t + φc − θc) + 12x(t)cos((2ωc+Δω)t + φc + θc)

为什么：A−B 把两个 ωc 消掉，只剩频率差 Δω 和相位差；A+B 把频率加倍到 2ωc 附近。第一项是"低频"，第二项是"高频"。

第 3 步：低通滤掉第二项，再乘 2。

只有相位误差（Δω = 0）：输出 = x(t)·cos(φc−θc) (11-7)
只有频率误差（相位差记作 φ）：输出 = x(t)·cos(Δω·t + φ) (11-8)

为什么这就是全部结论：注意两式的形式——恢复出来的信号被乘上了一个"缓慢变化"的因子。 相位差是常数，所以只是整体音量变小（乘以 cos φ）；频率差让这个因子随时间摆动（cos Δωt）， 于是音量周期性起伏，听起来像"忽大忽小"，严重时还会听出明显的拍音。

两个必须记住的灾难值

φc−θc = π/2（正交）：cos(π/2)=0， 输出的音量是 0。你什么也听不到——哪怕载频、带宽、低通全都完美。

Δω ≠ 0（频率有偏差）：输出带着 cos(Δωt) 的包络， 周期性过零。这就是为什么同步解调要求接收端"锁相"—— 要么用昂贵的同步接收机，要么改用不需要同步的 异步解调（包络检波）。

8. 频分复用（FDM）

调制最值钱的用途不是"搬高"，而是让很多路信号和平共处。 把第 1 路搬到 ωc1、第 2 路搬到 ωc2、第 3 路搬到 ωc3…… 然后把它们全部加起来一起发出去。这就是 频分复用（FDM）。

y(t) = x1(t)cos(ωc1t) + x2(t)cos(ωc2t) + x3(t)cos(ωc3t) + ⋯ (11-9)

接收端怎么把第 2 路单独拿出来？两步：

  1. 解复用（demultiplexing）：用一个中心频率为 ωc2 的 带通滤波器， 把别路的频谱挡在外面，只留下第 2 路那一对频谱砖。
  2. 解调（demodulation）：再乘 cos(ωc2t) + 低通 + 放大 2 倍， 就得到 x2(t)（第 4 节已经推过）。
相邻频道之间的最小间隔

第 i 路的频谱占据 [ωci−ωM, ωci+ωM] （这是 DSB 的固有宽度 2ωM）。要不重叠，就要求

|ωci − ωcj| ≥ 2ωM　（i ≠ j）

这就是生活中那个熟悉的现象：中波广播（AM）的电台间隔是 10 kHz， 而音频带宽只需 5 kHz——多出来的一倍正好被 DSB 用掉了。 收音机调谐旋钮转一点点就能换台，靠的就是"载波间距 = 两倍信号带宽"这条规则。

9. 动手：三路信号挤进一条信道

三路基带信号的带宽都是 W（频谱是宽 2W 的矩形）， 分别搬到 Δ、2Δ、3Δ。拖动"载波间隔 Δ"， 看它们什么时候还分得开。

10. 单边带（SSB）：砍掉一半带宽

回头看式 (11-2)：Y(jω) 是 X 的两份拷贝。可是 X 是实信号的频谱， 本身就满足共轭对称 X(−jω) = X*(jω)。 这意味着 两个边带携带的信息是重复的——只要留下其中一个边带，理论上就能把 x(t) 完整恢复。

DSB（双边带）

正频率处占 [ωc−ωM, ωc+ωM]， 总带宽 2ωM。
优点：解调简单（乘 cos + 低通）。
缺点：带宽和功率都浪费了一倍。

SSB（单边带）

只留上边带（或只留下边带）， 单边带 总带宽 ωM。
优点：带宽减半，发射功率减半（长距离短波通信的标配）。
缺点：调制器复杂得多。

怎么把不要的那个边带砍掉？工程上有两条路：

  • 滤波法：先做出 DSB 信号，再用一个极其陡峭的带通/高通滤波器把不需要的边带切掉。 难处在于：两个边带在 ωc 处紧挨着， 滤波器必须在很小的间隔内从通带掉到阻带（第 10 章：过渡带越窄越难做、振铃越大）。
  • 相移法（90° 相移网络）：用两个乘法器做成
    y(t) = x(t)cos(ωct) ∓ xp(t)sin(ωct)
    其中 xp(t) 是 x(t) 经过"所有频率都相移 90°"的系统得到的版本， 这个系统的频率响应是
    H(jω) = −j·sgn(ω) = −j,　ω > 0+j,　ω < 0
    因为两路相减后，其中一个边带的两项恰好反相抵消，另一个边带同相叠加。 它叫 希尔伯特变换（Hilbert transform）。

为什么两种方法都对：滤波法在频域"切掉一块"，相移法在时域让两块"一部分相加、一部分相消"—— 目标都是让最终频谱只剩下一个边带。单边带的解调方法和 DSB 一模一样（再乘 cos + 低通）， 所以省下的带宽是"白赚"的，代价全在发送端的复杂度上。

11. 脉冲载波、PAM 与时分复用（TDM）

载波不一定是余弦。用一串周期脉冲去乘信号，也能实现调制——而且在现实里更常见。 设 c(t) 是周期为 T、脉宽为 Δ、 幅度为 1 的脉冲串，ωc = 2π/T。它就是第 4 章见过的周期信号， 可以展成傅里叶级数：

c(t) = ∞Σk=−∞ ak ejkωct, 　ak = ΔT · sinc(kπΔT) (11-10)

（为什么：对脉宽 Δ、周期 T 的矩形脉冲在一个周期内积分，用第 4 章的结果即可。 a0 = Δ/T 就是占空比，也是 c(t) 的平均值。）

推导（点开/收起）：脉冲载波调制 = 无穷多份频谱副本

第 1 步：写出 c(t) 的频谱。对它取傅里叶变换，

C(jω) = 2π ∞Σk=−∞ ak δ(ω − kωc)

为什么：周期信号的傅里叶变换是一串等间距冲激，间隔 ωc=2π/T，每根冲激的"重量"就是级数系数 ak（第 4 章结论）。

第 2 步：套相乘性质，用冲激筛选。

Y(jω) = 12π ∫+∞−∞ X(jθ) · 2π ∞Σk=−∞ ak δ(ω−θ−kωc) dθ

为什么可以交换求和与积分：求和里的每一项都是"X 乘一个冲激"，逐项用筛选性质即可（有限项时可以逐项处理；无限项要靠绝对可积/绝对可和的条件保证极限与求和可交换，Oppenheim 教材中这条性质正是在这个前提下成立的）。

第 3 步：每一项把 θ 钉在 ω−kωc 上。

Y(jω) = ∞Σk=−∞ ak · X(j(ω − kωc)) (11-11)

为什么：X 的频谱被复制了无穷多份，第 k 份坐在 kωc 上， 高度被 ak 缩放。k=0 那一份就是原始基带（高度 a0=Δ/T）；k=±1 是搬到 ±ωc 的余弦调制副本——和上一节的 DSB 是同一种东西。

第 4 步：能否恢复？两个条件。

(a) 副本不重叠：相邻副本中心相距 ωc， 每份宽度 2ωM，所以要求

ωc = 2πT > 2ωM (11-12)

为什么这看着眼熟：这就是采样定理（第 9 章）！脉冲载波调制在频域上和"用冲激串采样"完全同构，唯一的区别是副本被 ak 缩放了。

(b) 直流那一份不能太小：a0 = Δ/T。 如果脉冲很窄（占空比 d 很小），a0 就很小，直接低通取出基带的信噪比会很差； 这时可以改用带通滤波器选出某个 ak 较大的副本（第 k 副本）， 得到一个货真价实的正弦调制信号，再用第 4 节的同步解调把它解出来。

为什么 ak 会随 k 起伏：ak = d·sinc(kπd)，sinc 的零点在 kπd = π, 2π, … 处。 当 d = 0.5 时，所有偶数次副本（k = ±2, ±4, …）系数恰好为 0——那些副本直接消失了。

时分复用 TDM 从这里长出来

脉冲载波在"脉冲关断"的间隙里什么都不发。既然有空隙，为什么不塞别的路？ 把第 2 路、第 3 路…的脉冲错开时间放进去，就得到 时分复用（TDM）。 和 FDM 对照着记：FDM 分的是频率，TDM 分的是时间。 脉冲越窄（Δ/T 越小），一帧里能塞的路数越多——但每路分到的能量也越少。

11.1 PAM：用样本去调制脉冲幅度

现实信道对最大幅度有限制，"发无穷大的冲激"是不现实的。 于是工程上发出的是一串宽度有限、幅度等于样本值的脉冲， 这叫做 脉冲幅度调制（PAM）。 它本质上是"采样 + 保持"：

y(t) = ∞Σn=−∞ x(nT) · p(t − nT) (11-13)

p(t) 是单个脉冲的形状（最简单的是宽 Δ 的矩形）。只要采样率 2π/T > 2ωM，样本里就完整地包含了 x(t) 的全部信息， 所以 PAM 是可以被接收端完美重建的（用第 9 章的 sinc 内插）。

码间干扰 ISI：PAM 的头号敌人

采样定理保证"样本够"，但没保证"脉冲在接收端还是原样"。信道是有带宽限制的（第 10 章）， 窄脉冲经过它会被抹开、拖尾，于是前一个符号的尾巴叠加到后一个符号的采样点上—— 这叫 码间干扰（intersymbol interference，ISI）。

解决办法很巧妙：用一个"本身也是带限的"脉冲，并且让它在其它采样时刻恰好过零—— 最典型的就是 p(t) = sinc(t/T1)， 它在 ±T1, ±2T1, … 处都是 0。 这样虽然脉冲彼此重叠，但每个采样点上别人的贡献都是 0。代价：采样时刻必须非常准（第 10 章的群延迟又来了）。

再往前一步：如果把样本值量化成有限个电平、再编成 0/1 比特流去调制脉冲， 就成了 PCM（脉冲编码调制）——今天所有数字通信的起点。

12. 动手：脉冲载波与 PAM 的频谱副本

基带信号仍是带限的 x(t)=(W/π)sinc(Wt)（带宽 W=1.5 rad/s）。 拖动脉冲重复频率 ωc，看频谱副本什么时候开始"打架"； 再拖占空比和路数，看时分复用是怎么塞进去的。

13. 频率调制与离散时间调制

13.1 频率调制（FM）：让载波的频率跟着信号变

前面所有方法都是"调制幅度"。还有一整类方法是调制频率：

y(t) = cos( ωct + kf ∫t−∞ x(τ)dτ ) (11-14)

这里 kf 是调制灵敏度。它的 瞬时频率 （相位对时间的导数）是

ωi(t) = ddt [ωct + kf∫x] = ωc + kfx(t)

也就是说：信号大，载波就"唱"得快一点；信号小，就慢一点。 常用来做对照的是 相位调制（PM）： y(t)=cos(ωct + kpx(t))。 两者只差一个积分/微分的关系。

FM 的优缺点

优点：信息的载体是相位/频率而不是幅度，所以 对幅度噪声（雷电、电器干扰）几乎免疫——这也是 FM 广播比 AM 广播音质好的原因。
缺点：占用带宽大得多（Carson 准则 B ≈ 2(Δf + fm)， Δf 是最大频偏、fm 是信号最高频率）， 并且分析起来不是线性的（式 (11-14) 里的 cos 套着积分，不能像前面那样用"搬移"简单处理）。

为什么 FM 的频谱比 AM 复杂

前面所有调制都是"线性"的：y = x·c，频谱只是搬移和缩放。 FM 里 x 出现在余弦的相位里，经过 cos 这个非线性函数后 会产生无穷多组边频（贝塞尔函数展开），带宽往往比 2ωM 大好几倍。 这就是"宽带有代价、但换来抗噪"。

13.2 离散时间调制：把同一套做法搬到序列上

把上面所有内容和第 7 章（DTFT）拼起来，就是离散时间调制：

y[n] = x[n]cos(ωcn) ⟷ Y(ejω) = 12 [ X(ej(ω−ωc)) + X(ej(ω+ωc)) ] (11-15)

推导过程和连续时间一模一样（相乘性质 → 周卷积 → 冲激筛选）， 唯一的区别是 DTFT 以 2π 为周期，所以搬移后的副本会被"卷回来"重复。这带来两条限制：

ωc > ωM　且　ωc + ωM < π (11-16)

第一条和连续时间相同（两个副本不能互相重叠）； 第二条是离散时间独有的：因为频谱在 2π 处会周期重复， 坐在 ωc 的副本不能"顶到" π—— 否则它会和从 2π−ωc 卷回来的那份撞上。 合并起来就是 ωM < ωc < π − ωM， 所以离散时间调制的载波频率有上限（最高只能到 π，也就是每个样本半个周期）。

ωc = π 的特殊情形：高低频互换

取 ωc=π，则 cos(πn) = (−1)n， 于是 y[n] = (−1)nx[n]：奇数点变号。 在频域上，这件事等于把频谱左右翻转——低频变成高频、高频变成低频。 所以"乘 (−1)n"可以用来把一个低通滤波器变成高通滤波器， 这是数字信号处理里最便宜的一个小技巧（第 8 章 DFT 里也会再见到它）。

再往前一步就是"上采样/下采样 + 调制"的数字收发机，以及 TDM↔FDM 的互换（transmultiplexing）—— 那是通信专业后续课程的内容，这里只需要知道：同一套频域语言，离散时间照样能用。

15. 常见坑

坑 1：忘了那个 1/2

x(t)cos ωct 的频谱是两份拷贝各自减半。 算功率/幅度时少这个 1/2，结果会差一倍（−6 dB）。

坑 2：以为解调只乘 cos 就完事

乘完 cos 得到的是 x/2 + (x/2)cos 2ωct， 还必须低通（滤掉 2ωc）并放大 2 倍。三步缺一不可。

坑 3：忘记 ωc > ωM

载波比基带最高频率还低时，两块拷贝重叠，信息在发送端就已经被破坏， 接收端再怎么滤波都救不回来。这不是"质量差一点"，是不可逆的失真。

坑 4：把"同步"当成理所当然

同步解调要求收发载波同频同相。相位差 90° 时输出为 0； 频率差 Δω 会产生 cos(Δωt) 的衰落包络。 想省掉同步就用包络检波，但代价是发送端必须带载波（多花功率）。

坑 5：带宽算错

基带带宽是 ωM（单边）， DSB 已调信号占 2ωM，SSB 占 ωM， FM 比 2ωM 大得多。别把"最高频率"和"带宽"混着用。

坑 6：离散时间调制里让 ωc 顶到 π

DTFT 以 2π 为周期，搬移后的副本会卷回来。 可用范围是 ωM < ωc < π−ωM， 没有上限的自由——这是离散时间与连续时间最大的不同。
