1. 一条主线：滤波就是"给每个频率配一个权重"

先别看具体应用。把十四章的结论压成一句话：

整门课的一句话

选一组基把信号摊开（傅里叶基、哈尔基、PCA 基……），得到一堆"分量系数"； LTI 系统对每个分量只做一个动作——乘一个复数； 把乘完的分量加回去，就是输出。

y(t) = Σk [ H(jωk) · ak ] ejωkt

方括号里的 H(jωk)·ak 就是把"第 k 个分量"先乘权重、再放回去。 所谓低通滤波（low-pass filtering），不过是让 |H(jω)| 在低频处等于 1、高频处等于 0。

这句话的好处是：图像、声音、通信、数据降维全都套得进去，只是"基"和"要加的权重"不同：

应用用什么基权重怎么定对应章节
图像去噪 / 模糊二维复指数 ej(ux+vy)离中心（低频）近的留下，远的清 0第 10 章 + 本页第 2 节
图像边缘检测 / 锐化同上反过来：中心清 0，远的留下本页第 2 节
声音降噪复指数（按帧做）截止频率以下通过本页第 4 节
通信复指数把整段频谱搬到载频附近第 11 章
数据降维（PCA）由数据算出来的特征向量保留方差大的方向第 3 章 + 本页第 7 节
为什么低通等于"模糊"，高通等于"边缘"

图像的"低频"是大片平滑区域（天空、墙面）；"高频"是灰度突变处——也就是轮廓和边缘。 所以：留低频 = 模糊（去掉细节），留高频 = 描出轮廓（去掉大片底色）。 如果现在还不信，下面第 2 节可以当场用手拖出来看。

2. 二维傅里叶变换与图像滤波（实验 1）

一张灰度图就是一个二元函数。把像素坐标记作 (x, y)，灰度值记作 f(x, y)（8 比特图像取 0–255），那么 二维傅里叶变换 （2-D Fourier transform）就是在一维公式里把"时间"换成"两个方向的空间坐标"：

F(u, v) = ∫+∞−∞ ∫+∞−∞ f(x, y) e−j(ux+vy) dx dy (A-1)
f(x, y) = 14π2 ∫+∞−∞ ∫+∞−∞ F(u, v) ej(ux+vy) du dv (A-2)
为什么反变换的系数是 1/4π²，而不是 1/2π

一维反变换带 1/2π；二维是两个独立方向各带一份，所以是 (1/2π)·(1/2π) = 1/4π²。这不是新规定，只是把一维公式用了两遍。 同理，可分离信号 f(x,y)=f1(x)f2(y) 的变换等于 F1(u)F2(v)——这就是"行列分离"能成立的原因。

图像是离散的，计算机里用的是它的离散版本（N×N 的二维 DFT）：

F[u, v] = N−1Σx=0 N−1Σy=0 f[x, y] e−j2π(ux+vy)/N

它和一维 DFT（第 8 章）没有本质区别，只是下标多了一个。 直接算要 N4 次运算，但按行列分离先对每行做一维 DFT、再对每列做一维 DFT， 就降到 2N3；再套 FFT，还能降到 2N2log2N。 下面这个实验台用的就是行列分离。

看懂了什么

① 低频中心化：右边那张"频谱图"里，最亮的地方在正中间，那是 (u,v)=(0,0) 的 直流分量（DC，等于灰度平均值）。 越往外圈，对应的空间频率越高。程序为了让中间亮、外面暗，画的是 log(1+|F|)—— 因为 |F[0,0]| 往往比别处大好几个数量级，不取对数就只能看见一个亮点。

② 低通 = 模糊：把截止半径调小，条纹和方块的边都被抹平，文字糊成一团； 高通 = 只剩轮廓：调大截止半径、改用高通，大片平坦区域变成灰色（它的低频被拿掉了）， 只有边缘还留着亮暗。

③ "年轮效应"：注意看理想低通（n→∞ 那一档，或者把理想阶数调大）的结果， 在强边缘（黑方块的角）附近会冒出一圈一圈的波纹。这不是程序算错了，而是 理想低通 = 时域 sinc 的必然结果（第 10 章）：sinc 会上下振荡，卷积到突变的边缘上，就把振荡"印"了出来。 课件里管这叫理想低通滤波器的"年轮效应"。

3. 幅度谱与相位谱：谁更重要

和连续时间一样，F(u,v) 是复数，可以拆成两部分：

|F(u, v)| = √( Re{F(u,v)}2 + Im{F(u,v)}2 ) ,    θ(u, v) = arctanIm{F(u,v)}Re{F(u,v)}

前者是幅度谱（magnitude spectrum）， 后者是相位谱（phase spectrum）。

一个反直觉但极其重要的实验（经典结论）

如果我们把照片 A 的幅度谱和照片 B 的相位谱拼在一起再做反变换，人眼看到的是—— B 的轮廓。

道理：幅度谱只说"有哪些粗细的条纹、各多强"，但条纹放在画面的哪个位置完全由相位谱决定。 抹掉相位，你得到一张纹理对但位置全错的图。所以在图像处理里， 粗量化幅度谱通常没问题，粗量化相位谱会立刻毁掉图像。 这也回应了第 6 章的坑 4：只看幅度谱不足以描述一个信号。

4. 声音信号与多频成分滤波（实验 2）

声音是 f(t)：一维随时间变化的信号，采样后变成一串数。 课件里给过两个真实声音信号的时域波形和频谱——你会发现 声音的时域波形完全看不出内容，但幅度谱一眼就能看出"音高"（谱峰位置）和"音色"（谱峰高低比例）。 这就是频域分析最实用的地方：换成频率轴，规律就自己跳出来了。

下面这个实验台把这件事压缩到几根谱线上：合成一个含 5 个频率成分的信号（你可以理解成"一个音 + 若干泛音 + 一点高频噪声"）， 用几种不同的低通滤波器去滤它，同时看时域和频域。

看懂了什么

频域一眼看穿：右边两张图里，输入频谱是几根线；滤波器曲线的值 |H| 就是每条线会被乘上的倍数； 输出频谱就是两者逐点相乘的结果。想让哪根线消失，只要把截止频率压到它下面。

时域看不出来：左边图上，被滤掉的成分在时域里只是让波形"毛糙一点"。 把截止频率一路压到最低那根谱线以下，输出也不会变成一条平线——因为低通保留直流， 低频那根线仍然通过，只是幅度被削弱。想彻底归零，需要的不是低通而是带通（把低频也挡掉）。 总之：滤波干得对不对，在频域里一眼就看得清，在时域里往往看不出门道。

5. 理想滤波器做不到，于是有了巴特沃斯（实验 3）

回忆第 10 章的两条结论：理想低通在频域是一堵墙，在时域是 sinc，非因果、不可实时实现； 而任何实际滤波器都有过渡带。工程上要回答的就是一个新问题：

新问题：怎么用可实现的函数去"逼近"那堵墙？

最常用的答案是 巴特沃斯滤波器 （Butterworth filter）。它的幅度平方响应是：

|H(jω)|2 = 11 + (ω/ωc)2n (A-4)
推导（点开/收起）：从式 (A-4) 能读出什么

第 1 步：ω = 0 处，|H| = 1。

|H(j0)|2 = 1/(1+0) = 1

为什么：低频原样通过，直流不被衰减。这是低通滤波器必须满足的第一条。

第 2 步：ω = ωc 处，|H| = 1/√2，也就是 −3 dB。

|H(jωc)|2 = 1/(1 + 12n) = 1/2  ⇒  |H(jωc)| = 1/√2 ≈ 0.707

为什么：12n = 1 对任何 n 都成立，所以所有阶数的巴特沃斯曲线都在 ωc 处交于同一点，这就是"截止频率"的定义方式。 用 dB 表示：20log10(0.707) ≈ −3.01 dB。

第 3 步：看高频尾巴。ω ≫ ωc 时，分母里的 1 可以忽略。

|H(jω)|2 ≈ (ωc/ω)2n  ⇒  |H(jω)| ≈ (ωc/ω)n

为什么重要：频率每翻一倍（一个倍频程），幅度就乘 (1/2)n。 n=1 时是 −6 dB/倍频程；n=5 时是 −30 dB/倍频程。阶数 n 就是"墙能砌多陡"的旋钮。

第 4 步：为什么叫"最大平坦"？

在 ω=0 附近把式 (A-4) 展开：

|H|2 = 1 − (ω/ωc)2n + …

第 1 项是常数 1，后面的项从 2n 次幂才出现。 所以 1,2,…,2n−1 阶导数在原点全为 0——通带内没有任何波纹。代价是同阶数下过渡带比切比雪夫一类的逼近更宽。 这就是"平坦度"与"陡峭度"之间的交易。

第 5 步：阶数 n 和极点的关系。

把 1 + (s/jωc)2n = 0 解出来，得到 2n 个极点，均匀分布在半径 ωc 的圆上、彼此相隔 π/n。 取左半平面的 n 个（保证因果稳定），就得到 H(s)。

为什么必须是左半平面：因果 + 稳定 ⇔ 全部极点位于左半平面（第 12 章）。右半平面那 n 个极点属于 H(−s)，不能要。 课件里那个 3 阶巴特沃斯电路，对应的就是 H(jω) = 1/((jω)3 + 2(jω)2 + 2(jω) + 1)，三个极点在单位圆上相隔 120°。

为什么图像滤波里"巴特沃斯"比"理想"更受欢迎

课件把同一张图分别用理想低通和巴特沃斯低通（半径都取 5, 15, 30, 80, 230 像素）处理，比较两点： ① 巴特沃斯没有年轮效应——因为它的 H(u,v) 是光滑过渡的，不是一刀切，时域冲激响应衰减快、振荡小； ② 巴特沃斯保留的能量比例更平滑地随半径变化，不会出现"半径只差一点、结果突变"的情况。 理想低通保留能量的那组数据（半径 5/15/30/80/230 像素 → 保留 92% / 94.6% / 96.4% / 98% / 99.5%） 说明图像绝大部分能量都集中在极小的低频区域，这也是 JPEG 之类方法敢大胆丢高频的底气。

6. FIR 设计初步：窗函数法（实验 4）

理想低通的冲激响应是 hideal(t) = (sin ωct)/(πt)， 两边无限延伸、还对称（非因果）。想把它变成能用的数字滤波器，只有一招：

窗函数法（window method）三句话

① 截断：把 hideal[n] 只取 −M ≤ n ≤ M 这 2M+1 个点，得到长度为奇数的 FIR； ② 加窗：乘上一个两头平滑收敛到 0 的窗函数（汉明窗、汉宁窗、布莱克曼窗），而不是硬生生砍断； ③ 延时：把截断后的序列整体右移 M 个样点，得到 h[n] = hideal[n−M]w[n]。

代价：① 频响出现过渡带，宽度约等于窗函数主瓣宽度（窗越长主瓣越窄、过渡带越陡）； ② 阻带出现旁瓣波纹，最坏旁瓣高度只取决于窗的形状（下一节会给准确数字：矩形 21 dB、汉宁 44 dB、汉明 53 dB、布莱克曼 74 dB）。 这就是"理想滤波器做不到"的量化版本：过渡带宽度与阻带衰减互相拉扯。

别忘了第 4 章就学过的吉布斯现象：矩形窗截断 = 直接砍，一定产生约 9% 的过冲，而且 和取多少项无关——多取项只会让过冲变窄，不会变矮。汉明窗的作用就是让这个过冲矮下去。 实验 4 里你可以把窗长从 401 拖到 17，看过渡带是怎么变宽的。

7. PCA / K-L 变换：换一组基来做降维（实验 5）

这一节把第 3 章"正交分解"的思想推到一个新层次。傅里叶用的是固定的基 ejωt。但如果你有一堆数据（比如 300 张人脸图，每张拉成 10 万维的向量）， 能不能找到专门为这批数据定制的那组基，让能量集中在最少的几个方向上？

能。这就是 主成分分析 / K-L 变换 （PCA / Karhunen-Loève transform）。定义并不复杂：

yj = ujTx ,     x = ∞Σj=1 yjuj ,     uiTuj = δij (A-5)

第一式叫正变换（拿基向量 uj 去"量"数据 x，得到一个系数）， 第二式叫反合成（把系数乘回基向量再加起来，还原 x）。 只要基是完备正交归一系，两式互为逆运算、没有任何信息损失。 "降维"发生在中间那一步：只保留前 d 项，得到估计

x̂ = dΣj=1 yjuj   ⇒   误差 ε2 = E[(x − x̂)T(x − x̂)] (A-6)
推导（点开/收起）：为什么"取最大特征值对应的特征向量"就是最优

第 1 步：把均方误差写成"被丢掉的那些分量"。

定义相关矩阵（second-order statistics）R = E[xxT]。因为用完备基展开，

E[‖x‖2] = ∞Σj=1 E[yj2] = ∞Σj=1 ujT R uj

为什么第一个等号成立：正交归一基下能量可加——这就是第 3 章的 Parseval 关系在有限维向量上的样子。 第二个等号把 yj=ujTx 代进去： E[yj2] = ujTE[xxT]uj。

第 2 步：截断误差 = 被丢掉的那部分能量。

ε2 = ∞Σj=d+1 ujTRuj

为什么：保留的 d 项还原了它们自己的分量，误差只剩下 j>d 那些分量的能量和。

第 3 步：用拉格朗日乘子法求极值。

在约束 ujTuj=1 下求 ujTRuj 的极值，令导数为 0：

Ruj = λjuj

为什么这就是答案：这正是特征值方程。也就是说，"使二次型 uTRu 取极值的单位向量"就是 R 的特征向量； 极值本身等于对应的特征值 λj。

第 4 步：结论。

ε2 = ∞Σj=d+1 λj

要让这个和最小，只需把最大的 d 个特征值对应的方向保留下来，把小的丢掉。 这 d 个特征向量张成的坐标系就是 d 维 K-L 变换坐标系，系数向量 y 就是 x 的 K-L 变换。 一句话：K-L 变换把 R 对角化了（Ryy=UTRxxU=Λ）， 于是各分量之间不再相关，能量按 λ 从大到小排好队，从队尾开始丢最不心疼。

第 5 步：产生矩阵可以换。

课件特别指出，K-L 变换的"产生矩阵"可以取 R = E[xxT]（相关矩阵）、 C = E[(x−μ)(x−μ)T]（协方差矩阵），甚至样本总类内离散度矩阵 Sw。选哪个，取决于你想让"能量"在哪一种意义下最集中。

工程含义：如果数据的均值 μ 很大（比如人脸图整体都很亮）， 用相关矩阵 R 算出来的第一主成分往往只是"平均脸"方向，而不是"人与人之间的差异"方向。 所以人脸识别里通常先减掉均值再用协方差矩阵 C。

课件给了一个可以手算的完整例子：样本协方差矩阵 C = [[19.5, 9.5], [9.5, 7.5]]。 它的特征值是 λ1 = 24.736、λ2 = 2.263 （验证：λ1+λ2 = 26.999 = trace C， λ1λ2 = 55.98 = det C，都对得上）。 最大特征值对应的特征向量是 u1 = [0.875, 0.482]T， 于是最优的 2×1 特征提取器就是 y = u1Tx： 把二维数据压成一维，只丢掉 λ2/(λ1+λ2) ≈ 8.4% 的能量。

"特征脸"就是一组基向量

课件里的 (3559, 351, −256, …) 是一张人脸图在正交基上的展开系数—— 跟前 14 章的 ak、X[k] 是一回事， 只不过基函数不是余弦，而是从人脸库算出来的特征向量。把这些特征向量按图像尺寸摆回成一个方阵， 画出来就是所谓的特征脸（Eigenface）。 工程效果（课件数据）：XM2VTS 人脸库（295 人 × 8 张），取前 100 维 PCA 特征， 最近邻法识别率 76.02%、SVM 80.25%——用 100 个数代表一张人脸图，还能有八成识别率， 这就是"能量集中"的威力。

同样的技术也用在做手型模型上：每个手型由 72 个点构成，也就是 144 维向量； 用人工标注的一批手型做 PCA，前几个主成分就能刻画"张开/握拳/旋转"这些主要变化模式， 于是 144 维被压成几维，既省存储，又让"相似度"变得可算。

8. 调制、解调与频分复用：复习 + 工程细节

第 11 章已经推导过核心结论。这里只把工程上真正需要记住的三件事拎出来：

① 调制就是把频谱搬家

y(t) = x(t)cos ωct
Y(jω) = 12[X(j(ω−ωc)) + X(j(ω+ωc))]

这叫双边带抑制载波调制（DSB-SC）。工程条件：载频 ωc 必须大于基带最高频率 ωM， 通常还要求 ωc ≫ ωM，否则两个搬移后的副本会重叠、无法分开。

② 同步解调：再乘一次、再低通

y(t)cos ωct = 12x(t) + 12x(t)cos 2ωct

第一项是我们要的基带（幅度是原来的一半），第二项在 2ωc 附近， 用低通滤掉即可。所以接收端的低通截止频率要大于 ωM 且小于 2ωc−ωM。 接收端本地载波必须与发送端同频同相，否则会引入衰减与失真。

③ 频分复用（FDM）：把调制用到极致

把不同信号搬到不同载频 ωc1, ωc2, … 上， 只要搬完之后的频谱互不重叠，就能在同一根信道里同时传。接收端先用带通滤波器把属于自己那一路"捞"出来， 再乘本地载波 + 低通完成解调。这就是"滤波 + 调制"这对组合在通信系统里的标准姿势， 也是调幅广播、电视、以及课件里提到的 GPS 信号（以及被干扰时会发生什么）的底层机制。

9. 常见坑

坑 1：以为"低通滤波能去掉一切噪声"

低通只能去掉高频噪声。像椒盐噪声（随机撒的黑白点）是全频带的，低通会把它们糊成一片灰斑，反而更难看。 这类噪声要用中值滤波（非线性滤波）。课件里专门把"低通滤波后的图像"和"中值滤波后的图像"并排对比。

坑 2：以为中值滤波也是 LTI

中值滤波取的是邻域排序后的中间值，不是加权平均，所以不是线性系统， 不能用 H(jω) 描述，也就没有"频响"。它强在能干净地除掉脉冲噪声、同时保住边缘； 而线性滤波器的局限正是"要么糊边、要么留噪"。

坑 3：频谱图忘了中心化，把低频看成在四个角

DFT 的自然排列把 (u,v)=(0,0) 放在左上角，直接画会看到"四角亮、中间暗"。 必须做象限搬移（把四个象限对调，等价于乘 (−1)x+y）才能得到以中心为低频的频谱图。 本页的实验台已经内建了这一步。

坑 4：把"理想低通"当成工程目标

理想低通在时域是双边无限的 sinc，非因果，实时系统里造不出来。 更要命的是它的突变的频响带来"年轮效应"。工程上要的是巴特沃斯这类平滑逼近：牺牲一点陡峭度，换取可实现的因果系统与更小的时域振荡。

坑 5：拿循环卷积当线性卷积用（图像滤波尤其严重）

用 FFT 做滤波时，如果长度不够，卷积是循环的，图像右边的内容会"绕回来"污染左边（空间混叠）。 正确做法：把图像和滤波器都补零到 ≥ N1+N2−1（第 8 章）。 "零相位滤波"还要先把滤波器搬到图像中心再加窗，否则图像会整体平移。

坑 6：零相位 vs 线性相位，傻傻分不清

课件里"直接对时域求导"y(t)=dx/dt 是一种高通： 由第 6 章的微分性质，它对应 H(jω)=jω，幅度随频率线性增长、相位恒为 90°—— 这不是"线性相位"，它会改变波形形状。线性相位指的是 ∠H = −ωt0（纯延时），那才是"不失真"。

坑 7：PCA 之前忘记减均值

不减均值就用相关矩阵 R=E[xxT]，第一主成分通常正好是"平均方向"（平均脸）， 它携带的是"大家共有的东西"而不是"个体差异"。做人脸识别/PCA 降维时， 先减均值、再用协方差矩阵 C 才是常规做法。

坑 8：把 PCA 当万能降维

PCA 只保留方差大的方向，但方差大 ≠ 有判别力。 如果用于分类，可能有大方差的干扰方向（光照、姿态）盖过真正区分两类的小方差方向—— 这时要用类内离散度 Sw 做产生矩阵（LDA），或者换 SVM 之类的判别方法。 课件里 PCA 用最近邻法只有 76.02%，换 SVM 提到 80.25%，说的正是这件事。

坑 9：滤波后能量"凭空少了"，以为程序错了

低通砍掉高频，就是扔掉了那部分能量。由 Parseval， Σ|y[n]|2 < Σ|x[n]|2 是应该发生的。 实验台里"保留能量"那个读数会随截止频率单调上升，正好对应课件"半径 5→230 像素、保留能量 92%→99.5%"的那行数据。

坑 10：忘了做谱的对称/共轭处理，反变换出来是复数

对实图像做低通时，如果只处理了 u≥0 那一半，或者把共轭位置改得不一致， 反变换的结果会带虚部（出现莫名其妙的黑白反相）。实输入 → 频域必须共轭对称 → 输出才是实。 在本页实验台里，只要滤波器关于中心对称，结果自然满足。
