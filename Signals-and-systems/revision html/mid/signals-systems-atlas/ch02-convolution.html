LTI 系统与卷积

第 1 章把"系统"定义成"把输入变成输出的机器"。这一章要回答一个惊人的问题： 一台机器那么复杂，凭什么只要一个信号 h 就能把它描述得一字不差？ 答案分两步：任何信号都能拆成"加权平移的冲激"（第 1 章的表示性质）， 而"线性 + 时不变"让机器对每一根冲激的响应可以叠加起来。 把这两步合起来，得到的就是卷积——整门课第一次出现、也是贯穿始终的主角。

1. 核心思想：把信号拆成冲激

先记住第 1 章留下的两个工具。第一个是 筛选性质（sifting property）， 第二个是 表示性质（representation property）：

x[n] = +∞Σk=−∞ x[k] δ[n − k]       x(t) = ∫+∞−∞ x(τ) δ(t − τ) dτ (2-1)

用人话说：信号是由"一根根冲激"搭起来的积木塔。 离散情形最直白——第 k 层积木是"位置在 k、高度是 x[k] 的一根 δ"。 连续情形是它的极限版本：位置连续变化的无穷多根冲激，每根的"面积"是 x(τ)dτ。

为什么这个拆法能救命

因为系统如果是线性的，它对"一堆东西的和"的响应 = "各自响应的和"； 如果还是时不变的，它对"平移过的冲激"的响应就是"原来的响应平移同样的量"。 于是——只要知道系统对一根冲激的反应，所有输入的输出都能算出来。 这就是 LTI（Linear Time-Invariant，线性时不变）系统为什么这么特殊。

定义：单位冲激响应（impulse response）

给 LTI 系统输入 δ(t)（或 δ[n]），得到的输出叫 单位冲激响应， 记作 h(t) 或 h[n]：

δ(t)  ⟶  h(t)       δ[n]  ⟶  h[n]

它是系统的"指纹"。同一类系统里，两个系统的 h 一样 ⇔ 两个系统完全相同。

2. 卷积和：离散 LTI 系统的输出

把第 1 节的两条性质一步步用上去，只需要三行：

推导（点开/收起）：从 x[n]=Σx[k]δ[n−k] 到卷积和

第 1 步：把输入写成加权冲激之和。

x[n] = +∞Σk=−∞ x[k] δ[n − k]

为什么：表示性质（第 1 章式 1-10）。注意 k 是求和变量，它是"这根积木放在哪"的标签； 而 x[k] 是这根积木的高度，对求和来说它只是一个常数系数。

第 2 步：用线性和时不变，逐根算响应。

  • 时不变：输入 δ[n] 的响应是 h[n]， 所以把冲激推迟 k 拍，响应也推迟 k 拍：δ[n−k] ⟶ h[n−k]。
  • 线性（齐次）：把输入放大 x[k] 倍，响应也放大 x[k] 倍： x[k]δ[n−k] ⟶ x[k]h[n−k]。
  • 线性（叠加）：把无穷多项加起来，响应也加起来。

为什么这三条能同时用：LTI 的定义就是"线性 + 时不变"。 这里用的正是线性最原始的两条（齐次、叠加），而不是某个需要证明的推论——所以这个推导不需要额外条件。

y[n] = +∞Σk=−∞ x[k] h[n − k] (2-2)

第 3 步：给它起个名字，并注意它意味着什么。

式 (2-2) 叫卷积和（convolution sum），记作 y[n] = x[n] ∗ h[n]。

为什么这个式子威力巨大：右边只含 x 和 h，不含任何关于系统结构的信息。 也就是说——任何 LTI 系统，不管内部多复杂，它的输入输出关系都长这个样子。 这就是"h 完全决定系统"的真正含义。

求和的上限（考试常写错）

(2-2) 写的是 k 从 −∞ 到 +∞。 但实际算的时候只有有限几项非零：因为 x[k] 可能只在某段区间非零， 而 h[n−k] 只在 n−k 落在 h 的支撑区时才非零。 所以动手算之前先定"k 的公共非零区间"，这是卷积计算的第一动作。第 4 节会给具体做法。

3. 卷积积分：连续 LTI 系统的输出

把上面的推导逐字翻译成连续时间，求和换成积分：

y(t) = ∫+∞−∞ x(τ) h(t − τ) dτ   =   x(t) ∗ h(t) (2-3)

叫卷积积分（convolution integral）。 对照着看就一目了然：离散的 Σ ↔ 连续的 ∫， 离散的 k ↔ 连续的 τ，其余一模一样。

提醒：τ 是积分变量（一个哑变量，叫什么都行）， t 是"我们现在想看哪个时刻的输出"。所以卷积积分的输出是一个关于 t 的函数—— 这就是为什么卷积必须有"滑动"这个动作。

4. 手算口诀：翻转 → 平移 → 相乘 → 求和

式 (2-2) 里的 h[n−k] 看着别扭：为什么不是 h[k]？ 因为把 k 换成 −k 是时间反转，再加 n 是时间平移（第 1 章第 5 节的两个操作）。 这就给出了卷积的标准操作流程：

四步口诀（离散版；连续版把"求和"换成"求积分的面积"）
  1. 翻转（flip）：把 h[k] 关于 k=0 左右翻面，得到 h[−k]。
  2. 平移（shift）：把翻转后的序列整体右移 n，得到 h[n−k]。这一步让"现在看的是哪个输出时刻"变成看得见的滑动。
  3. 相乘（multiply）：把 x[k] 与 h[n−k] 逐点相乘（必须是同一个 k 上的两个值）。
  4. 求和（sum）：把乘出来的所有值加起来，就是 y[n] 这一个点。

然后让 n 动起来：n 每加 1，h[n−k] 就再右移一格，重做第 3、4 步， 得到下一个输出点。全部 n 走一遍，就画出了完整的 y[n]。 下面第 5 节的实验台就是把这四步画在屏幕上。

一个不用公式的类比

把 x[k] 想成"印在透明胶片上的图案"， 把 h[n−k] 想成"另一张翻转并滑动的卡片"。 两张卡叠在一起时，每个位置上的两个数相乘，再把所有乘积累加——那就是这一瞬间的输出。 卡片滑到不同位置，累加结果不同，于是画出一条关于滑动量 n 的曲线。卷积就是这条曲线。

手算两个完整例子（每个区间都交代"凭什么"）

例 1（离散，有限长）：x[n] = {1, 2, 1}（n=0,1,2），h[n] = {1, 1, 1}（n=0,1,2）。求 y[n]。

第一步：确定支撑区。x 非零要求 0 ≤ k ≤ 2；h 非零要求 0 ≤ n−k ≤ 2， 即 n−2 ≤ k ≤ n。两者的公共区间是 k ∈ [max(0, n−2), min(2, n)]。

为什么先做这一步：卷积和里"没写出来"的项都是 0，丢掉它们题目立刻就变成"最多 3 项相加"。 而且公共区间随 n 变化——n 太小时是"刚进来"，n 太大时是"快出去了"，这就是分段的原因。

逐个 n 算（h[n−k]=1 只要 n−k∈{0,1,2}，所以每项就是在算 x 的一段和）：

  • n=0：k∈[0,0] ⇒ y[0]=x[0]=1
  • n=1：k∈[0,1] ⇒ y[1]=1+2=3
  • n=2：k∈[0,2] ⇒ y[2]=1+2+1=4
  • n=3：k∈[1,2] ⇒ y[3]=2+1=3
  • n=4：k∈[2,2] ⇒ y[4]=1
  • n<0 或 n>4：公共区间为空 ⇒ y=0
y[n] = { 1, 3, 4, 3, 1 }（n = 0,1,2,3,4）

自检：输出长度 = N₁+N₂−1 = 3+3−1 = 5 ✓；总和 Σy = 4·3 = 12 = Σx·Σh = 4·3 ✓。 这两条是很好用的免费验算器。

例 2（离散，无限长，必须分段）：x[n]=αnu[n]（0<α<1），h[n]=u[n]。

先定公共区间：x[k] 非零要求 k ≥ 0； h[n−k]=u[n−k] 非零要求 n−k ≥ 0，即 k ≤ n。 所以有效求和范围是 0 ≤ k ≤ n——但只有 n ≥ 0 时这个区间才非空。

为什么要分 n<0 和 n≥0：因为

  • n<0：要求 k≥0 且 k≤n<0，无解 ⇒ y[n]=0。
  • n≥0：y[n]=Σk=0nαk = (1−αn+1)/(1−α)（等比求和公式）。
y[n] = 1 − αn+11 − α u[n]

直觉检查：α 很小时（输入衰减快），y[n]≈1（累加器很快攒满 1）； α→1 时（输入接近阶跃），y[n]≈n+1（线性增长，因为累加器在累加常数）。 两者都被公式正确覆盖，说明推导没问题。
数值复核：取 α=0.5, n=3：公式给 (1−0.5⁴)/0.5 = (1−0.0625)/0.5 = 1.875； 逐项加 1+0.5+0.25+0.125=1.875 ✓

例 3（连续，课件原题）：x(t)=e−atu(t)（a>0），h(t)=u(t)。

公共区间：x(τ) 非零要求 τ ≥ 0； h(t−τ)=u(t−τ) 非零要求 τ ≤ t。所以 0 ≤ τ ≤ t（t>0 才有意义）。

y(t) = ∫t0 e−aτ dτ = 1a(1 − e−at),    t > 0

为什么积分上限是 t 而不是 ∞：因为 u(t−τ) 在 τ>t 时为 0， 被积函数在那里直接消失。这就是"公共区间"在连续情形的作用。

y(t) = 1a(1 − e−at) u(t)

直觉检查：t→∞ 时 y→1/a（输入的"总面积"是 1/a）， 而累加器本来就会把总能量一点不剩地攒下来——吻合。
数值复核：a=1, t=1：公式给 1−e−1≈0.6321； 直接数值积分 ∫₀¹e−τdτ 也等于 0.6321 ✓

5. 动手（核心）：卷积滑动演示

这一节是本页的心脏。三张图同步看：左图是固定的 x[k] 与已翻转平移的 h[n−k] （橙色与青色阴影正好是翻转动作），中图是两者逐点乘积，右图是累加出来的 y[n]。 拖动 n 滑块，盯住青色曲线在往右走、绿色乘积累加值在变。

看懂了什么：每一格滑动 = 一个输出点

第 0 步（看图 1 的两条曲线）：青虚线是 h[n−k] 关于 k 的曲线， 它和橙色虚线 h[k] 关于竖直线 k=n/2 对称—— 这就是"翻转"。当 n 增大时，青色曲线整体右移——这就是"平移"。

第 1 步（看图 2）：绿色填充区域的高度就是 x[k]·h[n−k]， 它等于"红色圈圈的高度"乘"青色曲线在同一个 k 处的高度"。红圈个数 = 参与相加的项数。
第 2 步（看图 3）：黑色竖线标出当前 n，蓝色点就是这一格的累加结果。 把它和读出的"逐项相加"式子对照——y[n] 就是那个和。整个 y[n] 就是这么一格一格扫出来的。

为什么必须"翻转"？翻错了会怎样

很多人会问："直接把 x[k] 和 h[k] 相乘求和不行吗？" 不行。不翻转得到的叫"相关"（correlation），不是卷积，数值完全不同。 原因回到推导：输出 y[n] 要把"第 k 根冲激的贡献"在时刻 n 取出来， 而 δ[n−k] 的响应是 h[n−k]—— 参数里那个负号就是翻转的来源，它从 δ[n−k] 一路跟过来的，不是人为加的。第 6 节把它单独放大看。

6. 动手：翻转这一步单独看

把"翻转"从四步里拆出来单独演示。滑块 β 从 0 拉到 1： β=0 时看到的是原样的 h[k]，β=1 时它已经翻面成 h[−k]， 中间是"翻到一半"。再拖 n，翻转后的曲线整体平移。

为什么要费劲做这个"半翻转"

因为"翻转"是个瞬时动作，直接切换开关看不出所以然。 把 h(β k) 里的 β 从 1 连续降到 −1， 曲线会像一根被拧转的橡皮筋一样从"向右衰减"变成"向左衰减"，原点那一点始终不动。 看到这个过程，你就再也不会把 h[k] 和 h[n−k] 弄混了。
同时盯住蓝色/红色的峰值位置：翻转之后，原来"靠后"的部分跑到前面，这就是卷积里"回声先到"的数学解释。

7. 冲激响应与系统的六条性质

第 1 章那六条性质，在 LTI 系统上全都变成对 h 的简单条件。这张表是本页最值钱的部分。

性质对 h 的条件为什么
无记忆
memoryless		 h[n] = K δ[n]
h(t) = K δ(t)		 把 h=Kδ 代进卷积和：y[n]=Σx[k]·Kδ[n−k]=Kx[n]， 只用到同一时刻的输入。反过来，若 h 在某个 k≠0 处非零， 输出就会掺进别的时刻的输入 ⇒ 有记忆。所以"无记忆的 LTI 系统"只有 纯放大 一种。
可逆
invertible		 存在 h₁ 使
h ∗ h₁ = δ		 串联一个逆系统后要还原成原信号：x = x∗h∗h₁ 对一切 x 成立， 由结合律 x∗(h∗h₁)=x，而"卷积的单位元是 δ"（见下），故 h∗h₁=δ。 例：h=u[n]（累加器）的逆是 h₁[n]=δ[n]−δ[n−1]（一阶差分）， 因为 u[n]∗(δ[n]−δ[n−1])=u[n]−u[n−1]=δ[n] ✓

时不变
time-invariant		 （LTI 的定义已假设） 我们讨论的"LTI 系统"按定义就是时不变的。若一个系统时变，它没有单一的 h 来描述—— 这正是 LTI 特殊的地方。
线性
linear		 （LTI 的定义已假设） 同上。注意："用卷积描述"本身就等价于"线性 + 时不变"， 所以对非 LTI 系统谈 h 是没意义的。
稳定性判据的必要性（为什么"绝对可和"不能放松）+ 步响应关系

(a) 必要性：若 Σ|h[k]|=∞，则存在有界输入使输出无界。

构造一个"专门捣乱"的输入：

x[−n] = 1|h[n]| 若 h[n]≠0 且 |h[n]| ≤ 1；   否则 x = 0（并令 h[n]=0 的样点上 x=0）

这个输入满足 |x[n]| ≤ 1（有界）。把它代进卷积： y[0] = Σkx[−k]h[k] = Σk: h[k]≠0 h[k]/|h[k]| · …， 只要把 h[k] 的相位取共轭就能让每一项都是正的 |h[k]|， 于是输出 y[0] = Σ|h[k]| = ∞。

为什么这算证明：要否定"稳定"，只需要给出一个有界输入让输出无界。 上面这个构造对任意满足 Σ|h|=∞ 的 h 都成立，所以必要性得证。 记忆要点：绝对可和 ⇔ 稳定（对 LTI 系统）。

(b) 步响应 s 与冲激响应 h 的关系。

步响应定义为输入 u 时的输出，所以它本身就是一次卷积：

s[n] = u[n] ∗ h[n] = nΣk=−∞ h[k]      s(t) = ∫t−∞ h(τ)dτ

为什么上限变成 n（或 t）：u[n−k] 在 k≤n 时为 1，之后为 0， 所以求和自动截断到 n。人话：步响应就是冲激响应的"累计"。

s[n] = s[n−1] + h[n]  ⇔  h[n] = s[n] − s[n−1]      ds(t)dt = h(t)

为什么有用：实际测量系统时往往只能测步响应（阶跃比冲激好产生， 因为冲激要求无穷大能量）。测到 s 之后，上面这个差分/求导就还原出 h， 再用卷积就能算任意输入的输出。

8. 卷积的代数性质：交换、分配、结合

卷积像乘法一样老实。三条性质都能从定义式直接推出来：

性质公式对系统的意义
交换律
commutative		 x ∗ h = h ∗ x 翻转谁、平移谁都行。也意味着：把 x 当输入、h 当冲激响应， 和反过来的系统输出完全一样。计算时选"翻转后更好算的那个"。
分配律
distributive		 x ∗ (h₁+h₂) = x∗h₁ + x∗h₂ 两个系统并联（输出相加）等价于一个冲激响应为 h₁+h₂ 的系统。
结合律
associative		 x ∗ (h₁ ∗ h₂) = (x ∗ h₁) ∗ h₂ 两个系统级联（串联）等价于一个冲激响应为 h₁∗h₂ 的系统； 级联顺序不影响总体结果（对 LTI 成立）。
三条性质逐个证明（各两三行，都要会）

(a) 交换律：Σkx[k]h[n−k] = Σrh[r]x[n−r]

∞Σk=−∞ x[k]h[n−k]  令 r = n − k，则 k = n − r，k 跑遍 ℤ 时 r 也跑遍 ℤ  = ∞Σr=−∞ x[n−r]h[r]

为什么可以用同一个求和范围：k 取 −∞…+∞ 与 r=n−k 取 +∞…−∞ 是同一个集合， 只是遍历顺序反了；绝对收敛时（或有限长时）换序不改变结果。

(b) 分配律：Σ x[k](h₁[n−k]+h₂[n−k]) 拆成两个和

∞Σk=−∞ x[k] (h₁[n−k] + h₂[n−k]) = ∞Σk=−∞ x[k]h₁[n−k] + ∞Σk=−∞ x[k]h₂[n−k]

为什么能拆：有限项的分配律 a(b+c)=ab+ac 的无穷版。 每一步部分和被同一个收敛级数控制（绝对收敛），所以极限可以分开取。

(c) 结合律：两次卷积换次序

(x∗h₁)∗h₂ = ∞Σk₁=−∞ ( ∞Σk₂=−∞ x[k₁]h₁[k₂−k₁] ) h₂[n−k₂]  =  ∞Σk₁=−∞ x[k₁] ( ∞Σk₂=−∞ h₁[k₂−k₁]h₂[n−k₂] )

为什么能交换两个求和号：内层求和对外层只是"一个与 k₁ 有关的数"， 把 x[k₁] 提出来之后，两个求和号是独立指标的累加， 绝对收敛时次序可换（这是级数理论的"二重级数可交换次序"定理）。

= ∞Σk₁=−∞ x[k₁] (h₁∗h₂)[n−k₁] = x ∗ (h₁∗h₂)

为什么这个结果重要：它说明级联的总冲激响应就是两个 h 的卷积。 再配合交换律，级联可以任意调换顺序（第 9 节实验台会让你亲眼看两个顺序的结果完全重合）。

(d) 三个"单位元/恒等式"（卷积版的 0 与 1）

x ∗ δ = x      x(t) ∗ δ(t−t0) = x(t−t0)      u ∗ u = (n+1)u[n]（离散）,  u(t)∗u(t) = t·u(t)（连续）

为什么第一条成立：Σkx[k]δ[n−k] 里 δ 只在 k=n 处非零， 由筛选性质只剩 x[n]。δ 就是卷积的单位元—— 这也和第 1 章"表示性质"是同一件事的两种说法。

第二条为什么是"平移"：与位置在 t₀ 的冲激卷积，把信号整体推迟 t₀。 第 9 节实验台会把它画出来。

9. 动手：δ 平移、累加器、级联/并联

三条最常用的卷积恒等式，用同一个实验台轮流看。选 ① 看 δ 的平移作用，选 ② 看累加器（h=u）， 选 ③ 让两个系统级联并换顺序——你会看到两条曲线完全重合，这就是结合律 + 交换律的现场证据。

看懂了什么

① 与 δ[n−n₀] 卷积 = 平移。拖 n₀ 看输出整条往右走，形状一点不变。 这就是"纯延迟系统"的冲激响应是 δ[n−n₀] 的意思，也是回声、混响的模型。
② 与 u[n] 卷积 = 累加。输出是输入的累加和（离散积分）。输入是有限长脉冲，输出就一级级爬上去再一级级下来， 形状变成一个"梯形"——爬升段是输入的前半截在累加，平台段是全都在累加。
③ 级联 = h₁∗h₂。把两个顺序的最终输出画在一起，它们重叠到看不出差别。 结论：对 LTI 系统，级联顺序可以任意交换。

10. 用微分/差分方程描述 LTI 系统

前面都是从 h 出发。但工程上更常见的是反过来： 系统先用一个方程给出，要我们去找 h 和输出。最典型的方程形式是 线性常系数微分方程（CT）与 线性常系数差分方程（DT）：

NΣk=0 ak dky(t)dtk = MΣk=0 bk dkx(t)dtk       NΣk=0 ak y[n−k] = MΣk=0 bk x[n−k] (2-4)
最重要的一句话：方程本身不足以确定系统

方程只给出输入与输出之间的约束（隐式描述），不是一个显式公式。 要唯一确定输出，还必须补附加条件（auxiliary conditions）。 同一个方程配上不同的附加条件，就是不同的系统。

例：dy/dt + 2y = x 描述的是一个 RC 电路。只知道 10 秒内加了 1 伏， 算不出 10 秒后电容电压——还得知道初始电容电压。 本课程统一采用的条件是 初始静止条件（initial rest）： 输入为零多久，输出就为零多久；即 x[n]=0 (n<n₀) ⇒ y[n]=0 (n<n₀)。 在初始静止下，式 (2-4) 描述的系统是因果且 LTI 的。

h 长什么样：两类系统

FIR：有限冲激响应

当 N=0（方程左边只有 y[n]）时， y[n]=Σk=0M(bk/a₀)x[n−k]， 直接就是卷积和，所以

h[n] = bn/a0，  0 ≤ n ≤ M

非递归（不用历史输出）、h 有限长、不需要附加条件、天然稳定（若系数有界）。

IIR：无限冲激响应

当 N ≥ 1 时方程是递归的：要算 y[n] 得先知道 y[n−1],…,y[n−N]。在初始静止下，h 通常是无限长的。

y[n] − a y[n−1] = x[n] ⇒ h[n] = anu[n]

一句话记法：h 是"几何序列"（连续情形是"指数"）。 几何序列的 h 绝对可和 ⇔ |a| < 1 ⇔ 系统稳定。

怎么知道 h[n]=aⁿu[n]？（递归法 + 卷积法，两条路殊途同归）

路线一：递归代入（最直观）。取 x[n]=δ[n]，初始静止 y[−1]=0。

y[0] = δ[0] + a·y[−1] = 1 + 0 = 1 = a0
y[1] = δ[1] + a·y[0] = 0 + a·1 = a = a1
y[2] = δ[2] + a·y[1] = 0 + a·a = a2
⋮    y[n] = δ[n] + a·y[n−1] = an（n ≥ 0）

为什么 n=0 之后再没有"输入项"：δ[n] 只在 n=0 处为 1，n≥1 时输入是 0， 于是递推变成纯齐次式 y[n]=a·y[n−1]，每步乘一次 a —— 几何序列的来历。 这就是为什么说"h 由特征多项式决定"：a 就是这个一阶系统的特征根。

路线二：解方程（更通用）。把方程写成 y[n]=a y[n−1]+x[n] 的形式， 一般解 = 齐次解（自然响应，令输入为 0）+ 特解（受迫响应，与输入同形）。

齐次方程 y[n]−a y[n−1]=0 的解是 yh[n]=C an； 输入 δ[n] 时特解只在 n=0 起作用，最终（配合初始静止）得 C=1，仍是 anu[n]。

为什么两条路一致：递推法其实就是"逐点解方程"，而齐次解形式 an 正是 递推关系 y[n]=a y[n−1] 的形状。连续情形完全平行： dy/dt+ay=x 的 h 是 e−atu(t)—— 几何序列换成指数、差分换成微分，其他一模一样。

数值复核（和实验台里的数字对得上）。

取 a=0.5：递推得 h = 1, 0.5, 0.25, 0.125, 0.0625, … 与 (0.5)n 逐个吻合 ✓

顺带得到一个稳定性的现场判据：Σn≥00.5n = 1/(1−0.5) = 2 < ∞ ⇒ 稳定； 若取 a=1.2，Σ1.2n 发散 ⇒ 不稳定。 在实验台里把 a 拖过 1，看累加和读数怎么爆掉。

11. 动手：递归差分方程 → h → 卷积验证

这个实验台做一件很硬的事：同一个系统，用两条完全独立的路算输出，然后把结果叠在一起对比。 路线 A：按差分方程逐点递推；路线 B：先取 x=δ 得到 h， 再算卷积 x∗h。两条路若完全重合，就说明"h 完全决定系统"真的成立了。

读下面的"最大误差"

只要它显示 0（或 1e−15 量级的浮点噪声）， 就说明两条路线给出同一个答案——这就是定理的数值证据。 把 a 拖到 0.95 附近，h 衰减很慢（IIR 的"长记忆"），两条路仍然重合； 拖到 1.05，h 发散（不稳定系统），你会看到两条路一起爆炸——但依然重合。

13. 常见坑

坑 1：忘记翻转

不翻转 h 就相乘求和，得到的是相关，不是卷积。翻转来自 δ[n−k] 的参数负号，不能省。

坑 2：只算了一个 n

卷积的结果是一条关于 n 的函数曲线，不是一次求和得到的一个数。手算时必须 n 从 −∞ 扫到 +∞（实际只在有限区间）。

坑 3：忘了分段

只要 x 或 h 是"单边"的（含 u），公共非零区间就随 n 变，必须分段讨论 n<0 / 0≤n≤… / n>…。漏段是失分最多的地方。

坑 4：把求和变量和输出指标搞混

x[k] 里的 k 是哑变量（求和用完就没了）；n 是输出时刻，不能被求和消掉。写答案时若结果里还有 k，一定是错的。

坑 5：以为差分方程自己就能定系统

必须配附加条件。同一个 y[n]−ay[n−1]=x[n]，配"初始静止"是一个因果 LTI 系统，配别的条件就是另一个系统。

坑 6：把因果判据说成"h 的起点"

因果 ⇔ h 在 n<0 处全为 0。注意是 h 的下标，不是"h 的下标可以平移成 0"。h[n]=δ[n+1] 是非因果的。

坑 7：用 Σ|h|<∞ 去判非 LTI 系统

这套判据只对 LTI 有效。对非 LTI 系统，连"冲激响应"这个概念都不足以描述它。

坑 8：把级联当成"h 相加"

级联（串联）是 h 卷积；并联（输出相加）才是 h 相加。这两个方向的对应关系容易记反。
