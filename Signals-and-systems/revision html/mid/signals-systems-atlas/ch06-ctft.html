连续时间傅里叶变换（CTFT）

傅里叶级数只能对付周期信号。可现实里的信号大多不周期——一段话、一个脉冲、一次心跳。 这一章做一件事：让周期 T 趋于无穷，看傅里叶级数会变成什么。 答案就是傅里叶变换：离散的谱线挤成了连续的谱曲线，求和变成了积分。

1. 为什么非要"非周期"的版本

先回忆第 4 章的结论。一个周期为 T 的信号可以写成

x(t) = ∞Σk=−∞ ak ejkω0t,    ω0 = 2πT (6-1)

这里 ω0 叫基波角频率 （fundamental frequency）， kω0 是第 k 次谐波的频率。

级数卡在哪

回头看式 (6-1) 的频谱：谐波频率只能取 ω0, 2ω0, 3ω0, …， 而 ω0 = 2π/T。也就是说，谱线之间的间距等于 2π/T。 周期越长，谱线越密；一旦信号不周期，"周期 T"都不存在了，谱线间距无从谈起——离散谱线这套语言直接失效。

关键一招：把非周期信号"看成"周期无穷大的周期信号

取一个孤立的脉冲 x(t)，只在一个有限区间内不为零。现在把它每 T 秒复制一份，得到周期信号 x̃(t)（这个操作叫 周期延拓，英文 periodic extension）。

当 T 越来越大：延拓得到的波形彼此越离越远（在局部看和原信号越像）， 而谱线间距 2π/T 越来越小——离散谱线在变密。 取 T→∞，谱线间距 → 0，离散谱线就"挤成"了一条连续曲线。这就是傅里叶变换。

2. 核心推导：T→∞ 把级数变成变换

这段是本章的骨架。每一步都逐字解释了"为什么可以这样写"，不要跳。

推导（点开/收起）：从级数定义到变换对

第 1 步：写出周期信号的级数，并写出系数公式。

x̃(t) = ∞Σk=−∞ ak ejkω0t,    ak = 1T ∫T x̃(t) e−jkω0t dt

为什么：ak 的公式来自"用 e−jkω₀t 去乘两边再在一个周期内积分"， 利用不同谐波在一个周期内积分为 0（正交性），只剩 k 那一项。∫T 表示"在任意一个长度为 T 的区间上积分"。

第 2 步：定义一个"与 T 无关"的量 X(jω)。

注意到 ak 的积分区间只有一个周期，而 x̃ 在这一个周期里等于 x（只要你选的周期包含信号的非零部分）。于是令

X(jω) ≜ ∫+∞−∞ x(t) e−jωt dt (6-2)

把这个定义套回 ak 的公式：取 ω = kω0，得到

ak = 1T X(jkω0)
即   T·ak = X(jkω0)   (6-3)

为什么重要：T·ak 不随 T 变化。周期越拉越长，单个谱线的高度 ak 会被"摊薄"（乘 1/T）， 但 X(jkω0) 保持稳定——它才是真正的"频谱密度"。

第 3 步：把 ak = X(jkω0)/T 代回级数，凑出"求和 → 积分"的形状。

x̃(t) = ∞Σk=−∞ 1T X(jkω0) ejkω0t = 12π ∞Σk=−∞ X(jkω0) ejkω0t · ω0

为什么：因为 1/T = ω0/2π（用 T = 2π/ω0），把 1/2π 提到外面， 就凭空多出一个 ω0。这个 ω0 是故意留下的，下一步要用。

第 4 步：让 T→∞，把求和看成黎曼和。

令 ωk = kω0，相邻两点间距就是 Δω = ω0 = 2π/T。于是上式是

x(t) = 12π ∞Σk=−∞ X(jωk) ejωkt Δω   ⟶T→∞   12π ∫+∞−∞ X(jω) ejωt dω (6-4)

为什么能这样换：黎曼和的定义——把函数在等间距点上的取值乘以间距再求和，当间距趋于 0 时极限就是积分。 这里"函数"是 X(jω)ejωt，"间距"是 Δω=ω0→0。所以 T→∞ 的极限正好把求和变成积分。

结论：傅里叶变换对
分析式（正变换）　X(jω) = ∫+∞−∞ x(t) e−jωt dt
综合式（反变换）　x(t) = 12π ∫+∞−∞ X(jω) ejωt dω

记号：x(t) ⟷ X(jω)。 "分析"是把信号拆开、看清有哪些频率；"综合"是把各频率按权重拼回去。

3. 定义式里每个符号的含义

符号中文名 / 含义直观理解
t时间 / 自变量秒。信号在"哪一刻"的取值。
ω角频率（angular frequency）"振荡得多快"的连续量，单位 rad/s。
j虚数单位（j² = −1）工科习惯写 j（数学里写 i），避免和电流 i 混淆。
e−jωt分析用的"探针"用它乘信号再积分，等于"问：信号里 ω 这个频率的成分有多大"。
X(jω)频谱（复函数）在每个频率 ω 上放一个复数：大小 = 该频率有多强，角度 = 该频率的相位。
|X(jω)|幅度谱（magnitude spectrum）只看"哪个频率强、哪个弱"。
∠X(jω)相位谱（phase spectrum）只看"每个频率成分被推迟了多少"。
X(jω) 的写法为什么不是 X(ω)写成 X(jω) 是提醒你：它是复值函数，自变量本质是 s = jω（第 12 章拉普拉斯变换会把 jω 推广成复数 s）。
什么时候这个积分存在（收敛条件）

充分条件之一：绝对可积——∫−∞∞|x(t)|dt < ∞。 因为 |x(t)e−jωt| = |x(t)|（复指数的模恒为 1），所以只要 |x| 的面积有限，积分就不会爆。

更一般的（狄里赫利条件，Dirichlet conditions）： ① 绝对可积；② 任何有限区间内极大极小值的个数有限；③ 任何有限区间内不连续点的个数有限且都是有限值。 满足这些条件时，反变换积分在连续点处给出 x(t)，在跳变点处给出左右极限的平均值。

但要注意：δ(t)、1、cos ω0t 都不绝对可积，它们的傅里叶变换依然有意义——要用 广义傅里叶变换 （允许结果里出现 δ(ω)）。下面的变换对表就包含这些。

4. 五个必须记住的变换对（含推导）

把这五个当成"单词"。以后遇到复杂信号，都是先把它们拆成这几个基本词，再套性质表。

① 矩形脉冲 ⟷ sinc

rect(t/τ) ⟷ τ · sinc(ωτ/2)

这里 rect(u)=1（|u|<1/2），sinc(x)=sin x / x（且 sinc(0)=1）。

推导
X(jω) = ∫τ/2−τ/2 e−jωtdt = e−jωτ/2 − ejωτ/2−jω = 2 sin(ωτ/2)ω = τ·sin(ωτ/2)ωτ/2

为什么：积分区间有限，直接积；再用 e−jA−ejA = −2j sin A（欧拉公式的差），分子分母的 j 约掉。

② 单边指数 ⟷ 复有理函数

e−atu(t) ⟷ 1a + jω  (a > 0)
推导
X(jω) = ∫∞0 e−ate−jωtdt = ∫∞0 e−(a+jω)tdt = 1a + jω

为什么：把两个指数合并成一个指数；∫0∞e−ptdt = 1/p 在 Re{p} > 0 时成立，这里 p = a+jω，实部是 a，所以要求 a>0。

③ 冲激 ⟷ 常数

δ(t) ⟷ 1
推导

用 δ 的筛选性质 ∫x(t)δ(t−t0)dt = x(t0)：

X(jω) = ∫∞−∞ δ(t)e−jωtdt = e−jω·0 = 1

直觉：冲激把"所有频率"都同等程度地包含了（白噪声/理想脉冲的频谱是平的）。

④ 常数 ⟷ 冲激（对偶）

1 ⟷ 2π δ(ω)
推导

把 ③ 代入反变换：(1/2π)∫1·ejωtdω 这个积分不收敛成普通函数。 改用 δ 的第二种定义（频谱意义）：∫δ(ω−ω0)F(ω)dω = F(ω0)。直接验算：

12π ∫∞−∞ 2πδ(ω)ejωtdω = ej·0·t = 1 ✓

直觉：直流信号（不随时间变）只含一个频率 ω=0，谱就是原点处的一根冲激。

⑤ 余弦 ⟷ 一对冲激（第 11 章调制的全部秘密）

cos(ω0t) ⟷ π[ δ(ω−ω0) + δ(ω+ω0) ]
推导（两步）

先把余弦写成一对复指数（欧拉公式）：

cos(ω0t) = 12( ejω0t + e−jω0t )

再用频移性质（把 ④ 的谱搬移 ±ω0）：

ejω0t ⟷ 2πδ(ω−ω0),    e−jω0t ⟷ 2πδ(ω+ω0)
⇒ cos(ω0t) ⟷ πδ(ω−ω0) + πδ(ω+ω0)

直观：一个余弦只有"一个频率"，但谱上出现两根线（正负频率各一根）。 负频率不是玄学：它是把 cos 写成两个旋转复指数时的数学必然，两根线合起来才代表实信号。

附：阶跃函数的变换 u(t) ⟷ 1/(jω) + πδ(ω)（为什么不能只有 1/(jω)）

直觉推理：u(t) = (1/2)[1 + sgn(t)]。常数 1 贡献 πδ(ω)（注意 1/2 × 2πδ = πδ）； 奇部 sgn(t) 贡献 2/(jω) 的一半，即 1/(jω)。两者相加得 U(jω) = 1/(jω) + πδ(ω)。 少掉 πδ(ω) 会漏掉直流成分（u(t) 的平均值不为 0），这就是"为什么必须补这一项"。

5. 动手：时宽与带宽的取舍

这是傅里叶变换里最重要的一条"物理规律"：信号在时域越窄，在频域就越宽，反之亦然。 下面拖动脉宽 τ，盯着两个图的横轴刻度看。

看懂了什么

τ 从 1 调到 0.2：时域脉冲窄了 5 倍，频域主瓣宽度（第一个零点 2π/τ）就宽了 5 倍。 乘积 τ · (2π/τ) = 2π 是常数——这就是 时宽带宽积（time-bandwidth product）。

两个极端值特别值得推到底：τ→0 时脉冲缩成 δ(t)，频谱变成一条水平线（全频段都有，见变换对 ③）； τ→∞ 时脉冲变成常数 1，频谱缩成原点一根 δ(ω)（只有直流，见变换对 ④）。

六条关键性质的证明（时移 / 频移 / 尺度 / 卷积 / 相乘 / 帕塞瓦尔）

(a) 时移：x(t−t0) ⟷ e−jωt0X(jω)

∫∞−∞ x(t−t0)e−jωtdt  令 u = t − t0，则 dt = du，t = u + t0  = ∫∞−∞ x(u)e−jω(u+t0)du
= e−jωt0 ∫∞−∞ x(u)e−jωudu = e−jωt0X(jω)

为什么：换元只改积分变量，指数里的 t0 是常数，可以提到积分号外。幅度 |e−jωt₀| = 1，所以时移不改幅度谱。

(b) 频移：ejω0tx(t) ⟷ X(j(ω−ω0))

∫∞−∞ ejω0tx(t)e−jωtdt = ∫∞−∞ x(t)e−j(ω−ω0)tdt = X(j(ω−ω0))

为什么：两个指数合并，剩下的就是"把 X 的自变量整体换成 ω−ω0"，即频谱向右平移 ω0。

(c) 尺度：x(at) ⟷ (1/|a|)X(jω/a)

只推 a > 0 的情形（a < 0 时上下限会互换，多出一个负号，最终绝对值吸收掉）：

∫∞−∞ x(at)e−jωtdt  令 u = at ⇒ t = u/a, dt = du/a  = 1a ∫∞−∞ x(u)e−j(ω/a)udu = 1aX(jωa)

为什么：把时间轴压扁 a 倍（回放加速），频率轴就拉宽 a 倍，同时幅度被摊薄成 1/a —— 面积守恒。

(d) 卷积性质：x(t) ∗ h(t) ⟷ X(jω)H(jω)（最重要的一条）

Y(jω) = ∫∞−∞ ∫∞−∞ x(τ)h(t−τ)dτ · e−jωtdt

为什么能换积分次序：把卷积定义（第 2 章：y(t)=∫x(τ)h(t−τ)dτ）代进变换定义。两个积分都是在有限区间上绝对收敛的（狄里赫利条件保证），所以可以交换次序。

= ∫∞−∞ x(τ) [ ∫∞−∞ h(t−τ)e−jωtdt ] dτ  =  ∫∞−∞ x(τ) e−jωτ H(jω) dτ

为什么方括号里等于 e−jωτH(jω)：这正是刚证明的时移性质，把 t0 换成 τ。

= H(jω) ∫∞−∞ x(τ)e−jωτdτ = X(jω)H(jω)

为什么这条性质重要：它把"难算的卷积"变成"好算的乘法"。也让 LTI 系统的分析彻底改观——见第 9 节。

(e) 相乘性质：x(t)y(t) ⟷ (1/2π)X(jω) ∗ Y(jω)

把 x(t) 用反变换写出来，再交换次序：

∫∞−∞ x(t)y(t)e−jωtdt = ∫∞−∞ [12π ∫∞−∞ X(jθ)ejθtdθ ] y(t)e−jωtdt
= 12π ∫∞−∞ X(jθ) [ ∫∞−∞ y(t)e−j(ω−θ)tdt ] dθ = 12π ∫∞−∞ X(jθ)Y(j(ω−θ))dθ

为什么：又用了一次频移性质（内层积分等于 Y(j(ω−θ))）。外层的积分恰好是卷积的定义形式，只是变量名叫 θ。

(f) 帕塞瓦尔：∫|x(t)|²dt = (1/2π)∫|X(jω)|²dω

∫∞−∞ |x(t)|²dt = ∫∞−∞ x(t)x*(t)dt = ∫∞−∞ x(t) [12π ∫∞−∞ X*(jω)e−jωtdω ] dt

为什么：x*(t) 的反变换里指数是 e−jωt、频谱取共轭（因为反变换是 (1/2π)∫X e+jωt，取共轭后变号）。

= 12π ∫∞−∞ X*(jω) [ ∫∞−∞ x(t)e−jωtdt ] dω = 12π ∫∞−∞ |X(jω)|²dω

为什么有意义：方括号里就是 X(jω)（正变换）。所以"时域里的能量"和"频域里按 |X|² 积出来的能量"必然相等——能量守恒。这也说明 |X(jω)|² 的物理含义是能量谱密度。

实信号的对称性（考试常考）

若 x(t) 是实函数，由共轭性质可得 X(−jω) = X*(jω)，于是：

  • 幅度谱偶对称：|X(jω)| = |X(−jω)|；
  • 相位谱奇对称：∠X(−jω) = −∠X(jω)；
  • 实部偶对称、虚部奇对称。

所以画实信号的频谱时，只画 ω≥0 也够（负频部分是镜像）。这是"负频率"不吓人的原因。

看懂了什么

傅里叶级数是傅里叶变换的特例：周期信号的谱只在 kω0 这些离散点上取值， 而这些点正好落在非周期极限下的连续频谱包络上。离散谱 = 连续谱的采样——这个想法在第 8 章 DFT 会以另一种形式再出现一次。

9. 用 CTFT 分析 LTI 系统

这一节是本章的"出口"：为什么工程师偏爱频域。

三行推出系统分析的黄金公式

设 LTI 系统输入 x(t)、输出 y(t)、单位冲激响应 h(t)。由第 2 章，y = x ∗ h； 由本页的卷积性质，两边取变换：

Y(jω) = H(jω) · X(jω)

其中 H(jω) 叫 频率响应 （frequency response），就是 h(t) 的傅里叶变换。 时域的卷积难题，在频域变成了一次乘法。

由微分方程直接写出 H(jω)（不用求 h(t)）

设系统由线性常系数微分方程描述：

NΣk=0 ak dky(t)dtk = MΣk=0 bk dkx(t)dtk

两边取傅里叶变换。用微分性质 dk/dtk ⟷ (jω)k：

NΣk=0 ak(jω)k Y(jω) = MΣk=0 bk(jω)k X(jω)

为什么：Y(jω)、X(jω) 都是常数（对 t 而言），可以提到求和号外。

于是

H(jω) = Y(jω)X(jω) = MΣk=0 bk(jω)k NΣk=0 ak(jω)k

为什么好：把 jω 直接代进特征多项式，就能得到频响，完全不必先解微分方程求 h(t)。这就是"频域分析省事"的具体体现。

例：dy/dt + 2y = x ⇒ H(jω) = 1/(jω+2)。 低频处 |H|≈1/2（通过），高频处 |H|→0（衰减）——一个一阶低通滤波器。

10. 常见坑

坑 1：忘记 1/2π

正变换没有系数，反变换才有 1/2π。不同教材会把 2π 放在正变换或两边各放 1/√(2π)，我们的约定是"反变换带 1/2π"。

坑 2：sinc 的定义不统一

有人定义 sinc(x)=sin(πx)/(πx)（归一化），有人定义 sin x / x。本页统一用 sinc(x) = sin x / x（Oppenheim 约定）。

坑 3：把 T·ak 和 ak 混了

级数系数 ak 随 T 变化；真正稳定、能过渡到变换的是 T·ak = X(jkω0)。写谱线高度时要想清楚画的是哪一个。

坑 4：以为幅度谱就能完全描述信号

相位谱同样重要。同样两个幅度谱，相位不同，波形可以完全不同（第 10 章还会看到：相位决定"延时"）。

坑 5：对含 δ 的信号硬用绝对可积

常数、正弦、阶跃都不绝对可积，但它们的变换存在（含 δ）。判收敛时不要直接判"不存在"。

坑 6：卷积性质用错域

是"时域卷积 = 频域相乘"。反过来"时域相乘 = 频域卷积"要多带 1/2π。两者不要互相替代。
