拉普拉斯变换

傅里叶变换有个门槛：信号必须"绝对可积"。可现实中一大批信号过不了这道门槛—— e2tu(t) 越涨越高、u(t) 永远不衰减、 t·u(t) 更是涨到无穷。这一章只做一件事：给信号乘上一个"衰减旋钮" e−σt，把野信号按下去，再去做傅里叶变换。 旋钮一加，能分析的信号范围立刻扩大；代价是结果不再是"一条频率曲线"， 而是整个复平面 s 上的一个函数——你必须同时说清"这个函数在哪块区域里才算数"。 那块区域叫收敛域（ROC）， 它是本章的主角。

1. 动机：傅里叶变换的三个"漏网之鱼"

先复盘第 6 章的收敛条件：傅里叶变换 X(jω) = ∫x(t)e−jωtdt 收敛的充分条件是绝对可积： ∫−∞∞|x(t)|dt < ∞。 原因是 |e−jωt| = 1，探针不放大也不缩小，所以积分能不能收敛完全取决于 |x(t)| 的面积。

下面这三个信号很有代表性，它们都被傅里叶变换挡在门外：

信号∫|x(t)|dt傅里叶变换问题出在哪
e−atu(t)（a>0）1/a，有限1/(a+jω) ✓ 存在会衰减，没问题
eatu(t)（a>0）∞不存在t→+∞ 时指数爆炸
u(t)∞1/(jω)+πδ(ω)（广义）不衰减，只能靠 δ 帮忙
t·u(t)∞不存在线性增长，更没救
cos ω0t∞一对 δ（广义）不衰减，但只有两根谱线
关键一招：先"压住"再变换

拿 x(t) = e2tu(t) 举例，它在 t→+∞ 时爆炸。 现在给它乘一个衰减因子 e−σt（σ 是实数，自己挑）：

x(t)e−σt = e2te−σtu(t) = e−(σ−2)tu(t)

只要挑 σ > 2，这个新信号就是衰减的、绝对可积的——它有傅里叶变换！ 也就是说：原来那个野信号，虽然自己没有傅里叶变换，但"乘上合适的衰减因子之后有"。 拉普拉斯变换要做的，就是把这件事系统化：把 σ 当成参数，看它在哪些取值下能救活这个积分。 能救活的那一片 σ（连同 ω）就是 ROC。

2. 定义：给信号装一个衰减旋钮

一句话人话版

拉普拉斯变换 = 先乘 e−σt 压住信号，再做傅里叶变换，最后把 σ 和 ω 打包成一个复数 s 记下来。 所以它不是新东西，是傅里叶变换"加了旋钮"的版本。

推导（点开/收起）：从"压住再变换"到拉普拉斯变换的定义式

第 1 步：写出傅里叶变换，说清它为什么有时不收敛。

X(jω) = ∫+∞−∞ x(t) e−jωt dt (12-1)

为什么：e−jωt 的模恒为 1，它只"转相"不"变大小"。 于是积分收不收敛，全看 |x(t)| 在无穷远处的衰减够不够快。不衰减或增长的信号就卡在这里。

第 2 步：引入实数 σ，给信号乘上 e−σt，对乘积做傅里叶变换。

∫+∞−∞ [ x(t) e−σt ] e−jωt dt = ∫+∞−∞ x(t) e−(σ+jω)t dt

为什么：两个指数相乘，指数相加——这是幂运算最基本的规则。 这一步把"衰减"和"转相"合并进了同一个指数里。

第 3 步：把 σ+jω 打包成一个复变量 s，得到定义。

拉普拉斯变换：　X(s) = ∫+∞−∞ x(t) e−st dt, 　s = σ + jω (12-2)

为什么可以这样打包：因为确定一个复指数 e−st 只需要两个实数（衰减率 σ 与振荡率 ω）， 而这两个实数恰好就是复数 s 的实部与虚部。所以 X(s) 是"复频率 s 的函数"， 而不是两个独立变量的函数——它住在s 平面上。

第 4 步：把傅里叶变换也写进同一个记号里。

X(s)|s = jω = X(jω) (12-3)

为什么：令 σ = 0（旋钮不衰减），e−st 就退化成 e−jωt， 这不就是式 (12-1) 吗。所以 傅里叶变换 = 拉普拉斯变换在虚轴上的取值。 但请把前提刻在脑子里：只有当虚轴 σ=0 这条线落在 ROC 里，这个等式才成立。 这正是后面"稳定性"要反复用的一句话。

第 5 步：反变换（怎么把 x(t) 拼回去）。

既然 X(σ+jω) 是 x(t)e−σt 的傅里叶变换，那就用傅里叶反变换公式先还原它：

x(t)e−σt = 12π ∫+∞−∞ X(σ+jω) ejωt dω

两边同乘 eσt，并把 σ 吸收进指数：

x(t) = 12π ∫+∞−∞ X(σ+jω) e(σ+jω)t dω   把积分变量从 ω 换成 s = σ+jω（σ 固定，故 ds = j dω）
x(t) = 12πj ∫σ+j∞σ−j∞ X(s) est ds (12-4)

为什么这一步很关键：积分路径是一条平行于虚轴的竖直线 Re{s}=σ， 而且这条线必须整条落在 ROC 里（否则 X(σ+jω) 根本不存在，还原无从谈起）。 这就是"反变换必须先知道 ROC"的数学根源。
好在实际算题时你不会真去算这个复变积分：只要 X(s) 是有理函数， 用第 6 节的部分分式展开加查表就够了。

结论：拉普拉斯变换对（完整写法必须带 ROC）
正变换　X(s) = ∫+∞−∞ x(t) e−st dt, 　s = σ + jω
反变换　x(t) = 12πj ∫σ+j∞σ−j∞ X(s) est ds （路径 Re{s}=σ 在 ROC 内）

记号：x(t) ⟷ X(s)，ROC = …。 只写 X(s) 不写 ROC，是不完整的答案——第 7 节的实验台会让你亲眼看到原因。

3. 收敛域 ROC 的三条铁律

ROC 看着抽象，其实只有三条"铁律"需要背。它们全部来自同一个事实： 收敛只看 ∫|x(t)|e−σtdt 是否有限—— 这个条件只和 σ 有关，和 ω 完全无关。

铁律 1：ROC 是"竖条"

因为收敛条件只依赖 σ = Re{s}，所以只要某个 s 能收敛， 所有与它同 σ、不同 ω 的点也都能收敛。于是 ROC 必定是 平行于虚轴的竖直条带（半平面是它退化到无穷的情形）。

铁律 2：ROC 里没有极点

定义 极点（pole）： 让 X(s)→∞ 的 s，也就是分母多项式的根（图上画 ×）。 积分在极点处不可能收敛（被积函数在那儿发散），所以极点一律被 ROC 排除在外。 与之相对的 零点（zero） 是分子的根（图上画 ○）：它不破坏收敛，但会让频响在该处凹陷。

铁律 3：有理变换的 ROC 由极点划界

对有理 X(s)，ROC 的左右边界只能落在极点上，或者延伸到无穷。 于是"极点位置 + 时域信号是右边还是左边"就能唯一确定 ROC。

三条铁律的由来 + 四种信号的 ROC 形状（右边 / 左边 / 双边 / 有限长）

(a) ROC 只依赖 σ：为什么它一定是竖条。

把 s = σ+jω 代进定义，取模：

|x(t)e−st| = |x(t)| · |e−σt| · |e−jωt| = |x(t)| e−σt

为什么：|e−jωt|=1，ω 在取模时直接消失了。 所以"绝对可积"这件事只跟 σ 有关：一个 σ 行，整条竖线要么全收敛、要么全不收敛。 这就是 ROC 是竖条的证明——一句话说完。

(b) 右边信号（right-sided）→ ROC 是最右极点右边的半平面。

所谓右边信号，指存在某个 T1 使得 t < T1 时 x(t)=0（例如所有 u(t) 乘出来的信号）。

设某条线 σ0 在 ROC 内，即 ∫|x(t)|e−σ0tdt < ∞。 现在取更大的 σ1 > σ0，在 t→+∞ 方向压得更狠， 而在 t→−∞ 方向 x(t) 本来就是 0，压不压都无所谓：

∫∞T1 |x(t)|e−σ1tdt = ∫∞T1 |x(t)|e−σ0t · e−(σ1−σ0)t dt ≤ e−(σ1−σ0)T1 ∫∞T1 |x(t)|e−σ0tdt

为什么能这样放缩：在积分区间 t ≥ T1 上， e−(σ1−σ0)t 是减函数，最大值在左端点 t=T1， 把它提出来即可。右边是有限数乘以有限数，所以仍然有限。 结论：σ 越大越容易收敛 → ROC 向右无限延伸，被最右边的极点挡住。

(c) 左边信号（left-sided）→ ROC 是最左极点左边的半平面。

对称地，左边信号指某个 T2 之后 x(t)=0（例如 u(−t) 那类）。 这次危险方向是 t→−∞：σ 越小（越负），e−σt 在负时间轴压得越狠。 所以 ROC 向左延伸，被最左边的极点挡住。

为什么和学生常犯的直觉相反：不是"σ 越大越好"，而要看信号往哪边跑。 右边信号怕 +∞ 爆炸（要用大 σ 压），左边信号怕 −∞ 爆炸（要用小 σ 压）。

(d) 双边信号 → 条带；有限长信号 → 整个 s 平面。

双边信号 = 右边部分 + 左边部分，两部分同时收敛才算数，所以 ROC 是两者的交集 = 竖直条带 σR < Re{s} < σL。如果这个交集是空的（σR ≥ σL）， 那这个信号的拉氏变换根本不存在。

而有限长信号（只在一段有限区间内非零、且绝对可积）最省事： 它在两个方向上都是 0，e−σt 在有限区间上一定有界， 所以 ROC = 整个 s 平面。典型例子就是 δ(t) ⟷ 1。

为什么"有限区间上有界"就够了：积分区间有限 + 被积函数有界 ⟹ 积分有限。 这就是有限长信号不需要任何旋钮帮助的原因。

记法提醒

习惯上"信号右边/左边"说 x(t) 的时间支撑，"因果/反因果"说的是系统（因果 ⟺ h(t)=0, t<0）。 两者形状相同，但语境不同：本章第 11 节讨论系统时会换成后者。

5. 常用变换对（含推导）

和傅里叶一样：先把这几对当"单词"背熟，复杂信号都能拆成它们的组合。

① 单边指数（本章的万能积木）

e−atu(t) ⟷ 1s + a, 　Re{s} > −a
推导
X(s) = ∫∞0 e−ate−stdt = ∫∞0 e−(s+a)tdt = 1s + a （上限代入 t→∞ 时为 0）

为什么上限是 0：只有当 Re{s+a} > 0 时， e−(s+a)t 才随 t→∞ 衰减到 0；否则积分发散。 这个不等式 Re{s} > −a 就是 ROC。注意：a 可以取负值—— 这时极点 −a 跑到右半平面，信号本身就是增长的，但只要 σ 足够大仍能收敛。

② 阶跃（它就是 a = 0 的特例）

u(t) ⟷ 1s, 　Re{s} > 0

把 a = 0 代进 ① 就得到它。ROC 是 Re{s}>0——虚轴不在 ROC 内， 这正是第 6 章里 u(t) 的傅里叶变换要额外加 πδ(ω) 的原因。 同一个 u(t)，在 s 域里反而干净得多。

③ 冲激（ROC = 全平面）

δ(t) ⟷ 1,　全 s 平面

用筛选性质：∫δ(t)e−stdt = e−s·0 = 1， 对任何 s 都成立，所以 ROC 是整个平面。时移版本 δ(t−T) ⟷ e−sT（由时移性质得到）。

④ 幂次（重极点的来源）

tn−1(n−1)! e−atu(t) ⟷ 1(s + a)n, 　Re{s} > −a

n=1 就是 ①；n=2, a=0 给出 t·u(t) ⟷ 1/s2。 记忆法：s 域里的重极点 ⟺ 时域里多乘一个 t（对应关系由 s 域微分性质给出： t x(t) ⟷ −dX(s)/ds）。

⑤ 正弦与余弦

cos(ω0t)u(t) ⟷ ss2 + ω02,　Re{s} > 0
sin(ω0t)u(t) ⟷ ω0s2 + ω02,　Re{s} > 0
推导（用欧拉公式 + s 域平移）

先把余弦拆成一对复指数：

cos(ω0t) = 12 (ejω0t + e−jω0t)

为什么：这是欧拉公式的逆用。拆开之后每一项都是①的形式（a = ∓jω0）。

用 ① 分别变换再相加：

12 [ 1s − jω0 + 1s + jω0 ] = ss2 + ω02

为什么可以直接相加：拉氏变换是线性运算（积分是线性的）， 而且两个 ROC 的交集 Re{s}>0 就是结果的 ROC。 通分就是最后那一步，纯代数。

带衰减的版本（用到 s 域平移 e−atx(t) ⟷ X(s+a)）： e−atcos(ω0t)u(t) ⟷ (s+a)/((s+a)2+ω02)。

⑥ 左边信号：同一个式子，另一个 ROC

−e−atu(−t) ⟷ 1s + a,　Re{s} < −a

代数表达式和 ① 一模一样，ROC 却完全相反。 这不是印刷错误，是拉氏变换最重要的性格：X(s) 的代数式 + ROC 才等于一个信号。 第 7 节的实验台会把这件事演给你看。

6. 反变换：部分分式 + 查表（完整算例）

式 (12-4) 那条复变积分在实际计算里几乎用不上。对有理 X(s)，标准流程只有四步， 而且第 4 步往往是初学者丢分的地方：

反变换四步法（请按顺序执行）
  1. 检查真分式：分子次数必须小于分母次数。不是的话先做多项式长除，除出来的整数多项式对应 δ 及其导数。
  2. 因式分解分母，找出所有极点（含重数）。
  3. 部分分式展开，定出每个系数：Ai = [(s+ai)X(s)]|s=−ai。
  4. 逐项按 ROC 决定方向：极点 s=−a 若在 ROC 的左边，该项是右边信号 Ae−atu(t)； 若在 ROC 的右边，该项是左边信号 −Ae−atu(−t)。
系数公式 Ai = [(s+ai)X(s)]|s=−ai 是怎么来的

假设 X(s) 已经拆成了这个样子（分母是三个互不相同的单实极点）：

X(s) = A1s + a1 + A2s + a2 + A3s + a3

想求 A1，就把两边同乘 (s+a1)：

(s+a1)X(s) = A1 + A2s+a1s+a2 + A3s+a1s+a3

为什么：这一步是纯粹的代数操作，左边等于右边恒成立（只要 s ≠ −a1）。 而我们要的就是 s = −a1 这个"本来不能代"的点。

现在令 s → −a1：后两项的分子都是 (s+a1) → 0，而分母不为 0，于是后两项一起消失，只剩 A1。

A1 = [(s + a1)X(s)]|s = −a1 (12-5)

为什么"消失"就安全：直接代 s=−a1 时 (s+a1)X(s) 是 0/0 型， 但这个 0/0 有极限，极限值就是 A1。所以实际操作时你先约分再代入，不会真的遇到 0/0。

如果有重极点 (s+a)n 呢？就要多留几项，系数用求导公式：

Ak = 1(n−k)! dn−kdsn−k [(s+a)nX(s)]|s=−a

为什么要求导：把两边乘 (s+a)n 之后，只有求 n−k 次导才能把挂在 Ak 前面的 (s+a)n−k 消成常数（其它项的 (s+a) 因子会保留下来，代入 s=−a 后归零）。

完整算例（请跟着算一遍，这是本章最重要的一次练习）

题目：已知

X(s) = 1(s + 1)(s + 2)

分别在三种 ROC 下求 x(t)：(i) Re{s} > −1；(ii) Re{s} < −2； (iii) −2 < Re{s} < −1。

算例全过程：拆项 → 定系数 → 按 ROC 决定左右 → 写出 x(t)（三种情形）

第 1 步：检查真分式。分子是常数（0 次），分母是 2 次，0 < 2 ✓ 是真分式，可以直接拆。

第 2 步：因式分解，写出待定形式。极点是 s = −1 与 s = −2（都是单极点），于是

1(s+1)(s+2) = As + 1 + Bs + 2

第 3 步：定系数（"盖住法"）。

A = [(s+1)·1(s+1)(s+2)]|s=−1 = 1s + 2|s=−1 = 1−1 + 2 = 1
B = [(s+2)·1(s+1)(s+2)]|s=−2 = 1s + 1|s=−2 = 1−2 + 1 = −1

为什么"盖住法"能用：先把 (s+1) 约掉再代入，等价于"把 (s+1) 盖住、把 s=−1 代进剩下的部分"。 两个系数都算完，代回去可以快速验证： 1/(s+1) − 1/(s+2) = [(s+2)−(s+1)]/((s+1)(s+2)) = 1/((s+1)(s+2)) ✓。

所以代数部分是（三问共用）：

X(s) = 1s + 1 − 1s + 2 (12-6)

第 4 步（i）：ROC 是 Re{s} > −1 —— 两个极点都在 ROC 左边，两项都是右边信号。

极点 −1 在 ROC 左侧 ⟹ 1/(s+1) ⟷ e−tu(t)； 极点 −2 也在左侧 ⟹ −1/(s+2) ⟷ −e−2tu(t)。

x(t) = ( e−t − e−2t ) u(t), 　Re{s} > −1 (12-7)

为什么：这两项查表都是①（a=1 与 a=2），ROC 条件 Re{s}>−1 与 Re{s}>−2 的交集正好是 Re{s}>−1，与题目一致。 这是因果（右边）信号，而且虚轴在 ROC 内，所以它的傅里叶变换存在。

第 4 步（ii）：ROC 是 Re{s} < −2 —— 两个极点都在 ROC 右边，两项都是左边信号。

极点 −1 在 ROC 右侧 ⟹ 1/(s+1) ⟷ −e−tu(−t)； 极点 −2 也在右侧 ⟹ −1/(s+2) ⟷ +e−2tu(−t)。

x(t) = ( −e−t + e−2t ) u(−t), 　Re{s} < −2 (12-8)

为什么系数会变号：左边信号那一对是 −e−atu(−t) ⟷ 1/(s+a)（Re{s}<−a）。 反推时每项都要乘一个 −1。ROC 不含虚轴 ⟹ 这个信号没有普通意义下的傅里叶变换， 因为它随 t→−∞ 指数发散。

第 4 步（iii）：ROC 是 −2 < Re{s} < −1 —— 一条竖条带，两个极点一边一个，于是两项一右一左。

极点 −1 在 ROC 右边 ⟹ 该项是左边信号 −e−tu(−t)； 极点 −2 在 ROC 左边 ⟹ 该项是右边信号 −e−2tu(t)。

x(t) = −e−tu(−t) − e−2tu(t), 　−2 < Re{s} < −1 (12-9)

为什么必须"一边一个"：ROC 是交集，要凑出竖条带，只能让一项贡献左半平面、另一项贡献右半平面。 这就是双边信号的典型长相：t>0 有自己的形状，t<0 也有自己的形状。

本例题的结论（务必记住这句话）

同一个 X(s) = 1/((s+1)(s+2))，配三种 ROC，就是三个完全不同的信号。 所以"求反变换"这道题的完整答案永远是两件东西：代数表达式（这里三问相同）+ ROC 决定的分支。 只写代数式等于只答了一半。

两个跟着算一遍的小陷阱

陷阱 1：不是真分式就硬拆。例如 X(s) = (s2 − 3)/(s + 2)。 分子 2 次 ≥ 分母 1 次，先做多项式长除：

s2 − 3s + 2 = s − 2 + 1s + 2   验算：(s−2)(s+2)+1 = s²−4+1 = s²−3 ✓

于是 x(t) = δ′(t) − 2δ(t) + e−2tu(t)（用到 s ⟷ δ′(t)）。 如果直接对 (s²−3)/(s+2) 硬套"盖住法"，你会得到完全错误的结果。

陷阱 2：重极点的项数。 分母 (s+1)2(s+3) 时必须写成 A11/(s+1) + A12/(s+1)2 + A21/(s+3)—— 两种幂次都要有。少写 A11/(s+1) 这一项，通分回去就凑不出原式。

7. 动手：同一个 X(s)，三种 ROC，三个不同的信号

上面那个算例（12-7）(12-8) (12-9)，我们用实验台画出来。 切换 ROC 下拉框，你会看到时域波形完全变样——而 X(s) 的代数表达式一个字母都没改。

看懂了什么

右边支（ROC 在最右极点右侧）在 t>0 活蹦乱跳、t<0 全是 0； 左边支正好反过来，而且在 t→−∞ 时往上冲（图中很快冲出画框， 这不是画错了，是它真的发散）；竖条带这一支两边都有，且两支都不含虚轴对应的收敛性。 一句话：ROC 不是"技术细节"，它是答案的一半。

8. 动手：把极点推向虚轴会怎样

这一节专门盯住最简单的信号 x(t) = e−atu(t) ⟷ 1/(s+a)， 唯一极点 s = −a。拖动 a，观察三件事同时发生： 极点位置移动、ROC 边界跟着移动、|X(jω)| 的形状变化。

a → 0 的临界讨论（这里最容易出错）

当 a > 0：极点在左半平面，ROC 是 Re{s}>−a，包含虚轴， 所以 X(jω) = 1/(a+jω) 存在，就是第 6 章那个单边指数的傅里叶变换。 a 越小，峰值 1/a 越高、峰越尖——极点正在朝虚轴逼近。

当 a = 0：信号变成 u(t)，X(s) = 1/s，ROC 是 Re{s}>0， 虚轴整条被排除在 ROC 之外！于是不能在 s=jω 上直接取值， u(t) 的傅里叶变换必须写成 1/(jω) + πδ(ω)（第 6 章）。 极点"落在虚轴上"= 临界状态：傅里叶变换要么不存在、要么多出一个 δ。 这也是"临界稳定"这个词的来历。

9. 几何法：用向量长度直接读出 |H(jω)|

有理 X(s) 可以写成极零点形式 X(s) = K·∏(s − zi) / ∏(s − pj)， 这种"只画极点零点、再涂上 ROC"的图叫 零极点图（pole-zero plot）。 把 s = jω 代进去，每一项 (jω − pj) 在几何上就是从极点 pj 指向虚轴上 jω 那个点的向量。于是：

几何读数法（不用算，看图就能定性）
|X(jω)| = |K| · 所有零点向量长度之积所有极点向量长度之积

辐角 = 零点向量夹角之和 − 极点向量夹角之和。 推论特别有用：当 jω 走到某个极点正上方时，那条极点向量最短 ⟹ |H(jω)| 出现尖峰； 走到零点正上方时出现凹陷（零点在虚轴上就是"零陷"）。

为什么"极点向量最短 = 频响峰值最高"（含一阶系统的 3 dB 点推导）

先看一阶系统 H(s) = 1/(s + 1/τ)，唯一极点在 s = −1/τ。

从极点 (−1/τ, 0) 指向虚轴上的点 (0, ω) 的向量， 其长度是 √(1/τ2 + ω2)，所以

|H(jω)| = 1√( (1/τ)2 + ω2 )

为什么：分母里只有一个极点因子，取模就是这条向量的长度； 分子的常数 1 长度是 1。这就是"向量长度读数法"里最简的一例。

找 3 dB 点。令 ω = 1/τ（正好在极点正上方）：

|H(j/τ)| = 1√( (1/τ)2 + (1/τ)2 ) = 1√2 · 11/τ = |H(0)|√2

为什么叫 3 dB 点：20log10(1/√2) ≈ −3.01 dB， 功率降到一半。极点离虚轴的距离 1/τ 就是这条低通滤波器的带宽， 而它同时又等于时域的时间常数倒数——时域响应越快（τ 小），频带越宽，这是同一件事的两面。

初值/终值定理的来历（为什么是 sX(s) 而不是 X(s)）

用单边拉氏的微分性质起手（单边拉氏见第 12 节，定义域从 0− 开始）：

∫∞0− dx(t)dte−stdt = sX(s) − x(0−)

为什么：分部积分得到。这个式子是两条定理的唯一出发点。

初值定理：让 s→∞。此时左边被 e−st 压得只剩原点附近一小段， 而导数在原点附近是一个冲激（跳变）；右边 sX(s) − x(0−) 取极限就得到 x(0+) − x(0−)，于是

x(0+) = lims→∞ sX(s) (12-10)

为什么必须写 sX(s)：X(s) 本身在 s→∞ 时通常趋于 0， 永远得不到有限值；乘一个 s 才能"把无穷大处的信息提出来"。

终值定理：让 s→0。s→0 时左边变成整个导数的积分 x(∞) − x(0−)，右边是 lims→0sX(s) − x(0−)，两边消去 x(0−)：

limt→∞ x(t) = lims→0 sX(s) (12-11)

为什么有前提"极点全在左半平面"：如果 x(t) 本身不收敛（例如 e2tu(t)）， 左边压根不存在，右边却可能算出个数——那就成了假答案。所以用之前先检查 sX(s) 的极点。 例：X(s)=1/(s−1) 时 lims→0sX(s)=0，但 x(t)=etu(t) 发到无穷，终值定理不适用。

11. 系统函数 H(s)：因果、稳定与方框图

这是拉氏变换在工程上最大的用处。设 LTI 系统冲激响应 h(t)， 输入 x(t)、输出 y(t)。由卷积性质：

Y(s) = H(s) · X(s), 　 H(s) = Y(s)X(s)

H(s) 叫系统函数 （system function，也叫传递函数 transfer function）。它是 h(t) 的拉氏变换， 所以也带着自己的 ROC——这正是判断因果与稳定的钥匙。

两条判据（考试必考）

① 因果性：h(t)=0（t<0） ⟹ ROC 是最右极点右边的右半平面。 反过来，对有理 H(s)，"ROC 在最右极点右侧"也等价于因果。

② 稳定性：稳定 ⟺ h(t) 绝对可积 ⟺ H(s) 的 ROC 包含整条虚轴。把①②合起来： 因果且稳定 ⟺ 全部极点都在左半平面（Re{p}<0）。 注意这句话对"因果"是必需的：一个非因果系统即使稳定，也可能有右半平面极点（靠一条夹在两极点之间的竖条带走虚轴）。

由微分方程直接写出 H(s)（不必先求 h(t)）+ 用 s 域解微分方程

设系统由线性常系数微分方程描述：

NΣk=0 ak dky(t)dtk = MΣk=0 bk dkx(t)dtk

两边取双边拉氏变换，用微分性质 dk/dtk ⟷ sk：

NΣk=0 aksk Y(s) = MΣk=0 bksk X(s)   ⟹   H(s) = MΣk=0 bksk NΣk=0 aksk

为什么能把 sk 直接代进去：双边变换下，微分就是"乘 s"， 而且这里的 s 对时间 t 来说是常数，可以提到求和号外。于是把 s 往特征多项式里一代就得到系统函数， 完全不用解微分方程——这就是频域/复频域分析的省事之处。

例：dy/dt + 3y = x ⟹ H(s) = 1/(s+3)，极点 s=−3 在左半平面， 取 ROC Re{s}>−3（因果）⟹ 因果且稳定。 再取 x(t)=u(t)，则 Y(s) = 1/(s(s+3))， 部分分式 = (1/3)/s − (1/3)/(s+3)， y(t) = (1/3)(1 − e−3t)u(t)。 终值 lims→0sY(s) = 1/3 ✓ 与 t→∞ 的极限一致。

为什么可以直接把 Y(s) 部分分式反变换：因为输入 u(t) 与系统都因果， 所以 y(t) 的每项 ROC 都取"最右极点右侧"，全部是右边信号。

11.1 系统互联：方框图与系统函数代数

方框图 把"系统怎么拼起来的"画成图，而 s 域里每种拼法都对应一个简单的代数式：

互联方式时域s 域记忆法
级联（串联）h₁ ∗ h₂H₁(s)·H₂(s)乘起来
并联h₁ + h₂H₁(s) + H₂(s)加起来
反馈复杂的卷积H₁/(1 + H₁H₂)负反馈时分母变 1+H₁H₂

反馈公式为什么长这样：设 Y = H₁E、E = X − H₂Y， 把第二个式子代进第一个得 Y = H₁(X − H₂Y)，移项 Y(1 + H₁H₂) = H₁X，除过去就是 H₁/(1+H₁H₂)。 分母上的 1 + H₁H₂ = 0 就是闭环极点方程——它决定反馈系统稳定不稳定，第 15 节之后你会反复见到它。

顺带一提：把极点全都按同一个"最大平坦"的目标摆放，就得到了巴特沃斯（Butterworth）滤波器； 二阶系统的极点 −ζωn ± jωn√(1−ζ²) 与阻尼比 ζ 的关系， 在第 10 章已经讨论过，这里用极零点图能一眼看出来：ζ 越小，极点离虚轴越近，谐振峰越尖。

12. 单边拉氏变换：带初始条件解微分方程

到这里为止我们都用积分下限 −∞，这叫双边拉氏变换。 工程上还有一种更常用的版本：积分从 0− 开始，只看 t ≥ 0 的部分。

单边拉氏变换：　 𝒳(s) = ∫∞0− x(t) e−st dt

比双边多出来的唯一区别就是下限。由此产生三条使用须知：

① 只看 t ≥ 0

两个信号只要 t≥0 部分一样，单边变换就一样。 所以单边变换无法还原 t<0 的波形——它天生只服务因果问题。

② ROC 永远是右半平面

因为被积信号是右边信号，ROC 必然是最右极点右边的右半平面， 所以单边变换不用特别讨论 ROC（反变换时全部取右边信号）。

③ 微分会带出初值

dx/dt ⟷ s𝒳(s) − x(0−)， 二阶则 s²𝒳(s) − sx(0−) − x′(0−)。 正是这些项让"初始条件"自动进入方程。

单边微分性质 s𝒳(s) − x(0⁻) 的推导（分部积分）
∫∞0− dx(t)dte−stdt  取 u = e−st, dv = x′(t)dt，则 du = −s e−stdt, v = x(t)
= [x(t)e−st]0−∞ + s∫∞0−x(t)e−stdt = (0 − x(0−)) + s𝒳(s)

为什么下限写 0−：这样才把 t=0 处的冲激也算进积分区间里 （如果 x 在原点有跳变，它的导数在原点有一个冲激，必须被包含）。 为什么上限代入为 0：积分收敛要求 Re{s} 足够大， 此时 e−st→0。

单边拉氏的标准用法：全响应 = 零输入响应 + 零状态响应

以 y″ + 3y′ + 2y = x 为例，输入 x(t) = a·u(t)， 初始条件 y(0−) = β、y′(0−) = γ。 两边取单边变换：

[s²𝒴 − sβ − γ] + 3[s𝒴 − β] + 2𝒴 = as
𝒴(s) = β(s + 3) + γ(s+1)(s+2) + as(s+1)(s+2)

第一项只含初值 β、γ（不含输入）→ 零输入响应； 第二项只含输入 a（不含初值）→ 零状态响应。分别部分分式展开： yzi(t) = [(2β+γ)e−t − (β+γ)e−2t]u(t)， yzs(t) = a[1/2 − e−t + (1/2)e−2t]u(t)。 两者相加就是全响应。下面的实验台把这三条曲线同时画出来。

拖动三个滑块：初值 β、初值斜率 γ、输入幅度 a，看三条曲线怎么互相"叠加"。

13. 常见坑

坑 1：求了 X(s) 却忘了写 ROC

同一个 X(s) 配不同 ROC 是完全不同的信号（第 6、7 节的两个实验台都在演示这件事）。 答题时把 ROC 写在 X(s) 后面，是基本礼貌也是采分点。

坑 2：以为 X(jω) 总能从 X(s) 代出来

前提是虚轴落在 ROC 内。u(t) ⟷ 1/s（Re{s}>0）就不能直接把 s=jω 代进去得到傅里叶变换——真实的 U(jω) 还要多一个 πδ(ω)。

坑 3：非真分式直接部分分式

分子次数 ≥ 分母次数时，先做多项式长除，除出来的多项式对应 δ 及其各阶导数。 忘了这步，结果会整体错。

坑 4：重极点只写一项

分母有 (s+a)2 时，必须写 A/(s+a) + B/(s+a)2 两项；少一项就凑不出原式。

坑 5：稳定性判据张冠李戴

"极点全在左半平面 ⟹ 稳定"只对因果系统成立。 非因果系统可能带着右半平面极点却照样稳定（ROC 是夹在两极点之间的竖条带，照样包含虚轴）。

坑 6：单边/双边混用初值

单边拉氏里 dx/dt ⟷ s𝒳(s) − x(0−)； 双边里就是 sX(s)，没有初值项。 用哪个变换决定公式长什么样。

坑 7：终值定理不看前提就套

lims→0sX(s) 只有在信号真的收敛时才是终值。 先检查 sX(s) 的极点是否都在左半平面，再动手算。

坑 8：把"极点靠近虚轴"和"极点落在虚轴上"混为一谈

靠近（Re{p}<0）：傅里叶变换存在，只是峰值又高又尖。 落在虚轴上（Re{p}=0）：虚轴不在 ROC 内，傅里叶变换要么不存在、要么多一个 δ 项。第 8 节的实验台专门演示这条。

14. 自测
