第二段 · 傅里叶家族 · 第 7 章

离散时间傅里叶变换（DTFT）

第 5 章告诉我们：离散周期信号只有 N 个独立谐波，谱线是离散的 N 根。 现在把 N 推向无穷，那 N 根谱线会挤成一条连续的曲线—— 这就是离散时间傅里叶变换。它和连续时间的 CTFT 长得几乎一样，只有一个地方绝对不能忘： 频谱以 2π 为周期，画完一个 2π 区间就等于画完了全部。

1. 这一章在回答什么问题

第 6 章我们把连续时间的周期 T 推向无穷，把 CTFS 变成了 CTFT。 本章用同一招处理离散时间：取一个有限长的序列 x[n]， 把它以 N 为周期反复复制得到 x̃[n]，然后让 N→∞。

回忆第 5 章的两个结论，它们决定了本章会出现什么：

  • DTFS 系数满足 ck = (1/N)·X(ejkω0)， 其中 ω0 = 2π/N——系数是某个连续函数的等间隔采样；
  • 采样间隔是 2π/N，N→∞ 时间隔 → 0：离散谱线挤成连续曲线。

最后我们会得到一个很对称的变换对：正变换是一个无穷级数（对样本求和）， 反变换是一个有限区间上的积分（区间长度恰好 2π）。 反变换积分区间有限这件事，是离散时间独有的福气——它带来一个和 CTFT 完全不同的结论： 频谱必须、也只能以 2π 为周期。

2. 核心推导：N→∞，级数变成变换

这段是本页的骨架，每一步都交代了"凭什么可以这样写"。

推导（点开/收起）：从 DTFS 到 DTFT

第 1 步：拿一个有限长序列，做周期延拓。

设 x[n] 在 −N1 ≤ n ≤ N2 之外全为 0。把它每 N 个样本复制一次，得到周期为 N 的 周期延拓 （periodic extension）x̃[n]，并且 N 取得足够大，让一个周期里完整地包含原序列。

为什么可以这样做：第 5 章的 DTFS 只适用于周期信号。延拓是"把非周期信号伪装成周期信号"的唯一手段； 而 N 越大，伪装得越像（在一个周期内 x̃[n] = x[n]）。

第 2 步：写出 x̃[n] 的 DTFS。

x̃[n] = Σk=<N> ck ejkω0n,    ck = 1N Σn=<N> x̃[n] e−jkω0n,    ω0 = 2πN

为什么：这是第 5 章式 (5-1)(5-2) 的照抄。别忘了这里 k 只有 N 个不同的值。

第 3 步：把求和范围扩到整个时间轴（因为原序列有限长）。

在一个周期内 x̃[n] = x[n]，而周期外 x[n] = 0，所以

ck = 1N +∞Σn=−∞ x[n] e−jkω0n = 1N X(ejkω0)

其中我们定义了一个新函数：

X(ejω) ≜ +∞Σn=−∞ x[n] e−jωn (7-1)

为什么可以把有限区间换成无穷区间：区间外的 x[n] 全是 0， 加上去等于没加。这一步的意义在于：X(ejω) 的定义里不再有 N， 它是只跟 x[n] 有关的函数——这正是我们想要的"与 N 无关的频谱"。

第 4 步：把 ck = X(ejkω0)/N 代回综合式，凑出"求和 → 积分"的形状。

x̃[n] = Σk=<N> 1N X(ejkω0) ejkω0n = 12π Σk=<N> X(ejkω0) ejkω0n · ω0

为什么：因为 1/N = ω0/2π（把 N = 2π/ω0 代进去）。 把 1/2π 提到外面，就凭空多出一个 ω0。 这个 ω0 是故意留下的，下一步要用它当"矩形宽度"。

第 5 步：让 N→∞，把求和看成黎曼和。

令 ωk = kω0，相邻两点的间距就是 Δω = ω0 = 2π/N。于是上式是"高 × 宽"的求和：

x[n] = 12π Σk=<N> X(ejωk) ejωkn Δω   ⟶N→∞   12π ∫2π X(ejω) ejωn dω (7-2)

为什么极限是积分：这就是黎曼和的定义——函数在等间距点上的取值乘以间距再求和， 间距趋于 0 时极限就是积分。这里"函数"是 X(ejω)ejωn， "间距"是 Δω = 2π/N → 0。

第 6 步：为什么积分区间只有 2π 长——这一步是本章的关键。

k 从 0 走到 N−1， ωk 就走过 N 个小格， 总宽度是

N · Δω = N · 2πN = 2π   （与 N 无关！）

为什么这条最重要：无论 N 取多大，积分区间永远是 2π 长。 连续时间里那个区间是 (−∞, +∞)（CTFT 的反变换要对所有频率积分）， 离散时间里却只有 2π 宽，因为 N 个谐波频率只散布在 2π 的范围内。 区间有限还有一个附带好处：反变换的积分不会有收敛问题（有限区间上连续函数的积分必然收敛）， 只有正变换那个无穷级数需要考虑收敛。

第 7 步：写成标准的变换对。

x[n] = 12π ∫2π X(ejω) ejωn dω   （综合式，区间是任意长度 2π 的区间）
X(ejω) = +∞Σn=−∞ x[n] e−jωn   （分析式）

为什么积分区间写"2π"而不是具体数字：因为被积函数 X(ejω)ejωn 本身以 2π 为周期（下一步就证明）， 所以取 [0, 2π) 还是 [−π, π) 结果都一样。 这一点在计算时非常方便。

结论：DTFT 变换对
分析式（正变换）   X(ejω) = +∞Σn=−∞ x[n] e−jωn
综合式（反变换）   x[n] = 12π ∫2π X(ejω) ejωn dω

记号：x[n] ⟷ X(ejω)。 写成 X(ejω) 而不是 X(ω)，是为了提醒你： 它本质上是把 z = ejω（单位圆上的点）代进 z 变换（第 13 章）。

3. 定义对、符号表与收敛条件

X(ejω) 叫 离散时间傅里叶变换 （discrete-time Fourier transform），也常被叫作序列的 频谱 （spectrum）。

符号中文名 / 含义直观理解
n离散时间序号整数，第几个样本。
ω离散角频率（rad/样本）每个样本相位前进的角度。
e−jωn分析用的"探针"用它乘序列再求和，等于问"序列里 ω 这个频率有多强"。
X(ejω)频谱（复值函数）每个频率放一个复数：模=强度，角=相位。
|X(ejω)|幅度谱哪个频率强、哪个弱。
∠X(ejω)相位谱每个频率成分被推迟了多少。
∫2π任意长度 2π 的区间上的积分可以取 [0,2π) 或 [−π,π)，结果相同。
正变换什么时候收敛

条件一：绝对可和   Σn=−∞∞|x[n]| < ∞。 因为 |x[n]e−jωn| = |x[n]|（复指数的模恒为 1）， 所以只要"绝对值之和"有限，级数就绝对收敛。这是最常用的判断标准。

条件二：有限能量   Σn=−∞∞|x[n]|² < ∞。 这时级数可能不是绝对收敛，但均方收敛（误差的能量趋于 0）， 例如理想低通的冲激响应 sin(ωcn)/(πn) 就属于这一类。

反变换没有这个问题：积分区间是有限的 2π， 只要 X(ejω) 在一个周期上可积就行。 （对照第 6 章：CTFT 的反变换是无穷区间积分，收敛是必须操心的事。）

4. 灵魂：频谱以 2π 为周期

这是本章最重要的一条，也是 DTFT 和 CTFT 之间最本质的差别。它不需要复杂的证明， 只需要把 ω+2π 代进定义式，然后数一数 e−j2πn 等于几。

推导（点开/收起）：X(e^{jω}) 的 2π 周期性，以及它的三个推论

第 1 步：把 ω 换成 ω+2π。

X(ej(ω+2π)) = +∞Σn=−∞ x[n] e−j(ω+2π)n = +∞Σn=−∞ x[n] e−jωn · e−j2πn

为什么：指数相加可以拆成相乘（eA+B=eAeB）。

第 2 步：认出 e−j2πn = 1。

e−j2πn = cos(2πn) − j sin(2πn) = 1 − 0 = 1   (n 是整数)
⟹    X(ej(ω+2π)) = X(ejω)   （对所有 ω、所有序列成立）

为什么这条"对任何序列都成立"：推导中没有用到 x[n] 的任何性质—— 不需要周期、不需要实、也不需要收敛。只要 n 是整数， e−j2πn 就必然是 1。这是离散时间与生俱来的性质。

第 3 步：推论一——只需要画 2π 宽的一段。

ω ∈ [0, 2π) 或 [−π, π) 这一段里 已经包含了频谱的全部信息，其余部分都是复制品。 工程习惯用 [−π, π)，因为"正频率"和"负频率"看起来对称。

为什么方便：画图和存储都省一半以上的力气， 这也解释了为什么第 8 章的 DFT 只需要算出 N 个频率点。

第 4 步：推论二——频率是一根"绕起来的圆"。

把 z = ejω 看成复平面单位圆上的点： ω 就是"从正实轴出发转过的角度"。 转一整圈是 2π，回到原点——所以 ω 和 ω+2π 是同一个位置，同一个频率。

为什么低频和高频的"位置"要重新认识：在单位圆上， ω = 0 附近（以及 ±2π, ±4π, …）是低频， 信号变化最慢；ω = π 附近（以及 ±3π, …）是最高频， 因为 cos(πn) = (−1)n 每个样本都换符号，是离散时间能"抖"得最快的节奏。 再高频就绕回来了：ω = 1.9π 与 ω = −0.1π 是同一个频率， 它其实很"慢"。

第 5 步：推论三——实序列的频谱共轭对称。

X(e−jω) = X*(ejω)   （x[n] 为实序列）

为什么：把定义式里的 ω 换成 −ω，再对每一项取共轭即可看出。 于是 |X(ejω)| 是偶函数、 ∠X(ejω) 是奇函数； 再结合 2π 周期性可知：画实序列的频谱时，只画 ω ∈ [0, π] 就足够了 （负频段是镜像，而 π 以上的部分是这段的重复）。

一句话记住

离散时间的频谱是"周期的"；连续时间的频谱一般"不是周期的"。 这不是数学技巧，而是物理事实：离散信号的最高频率是有限的（ω=π）， 再往上没有"新频率"可用，于是频率轴只能循环。

5. 动手：亲眼看见 2π 周期的重复

看一个最常见的序列：x[n] = anu[n]（|a|<1）。 它的频谱有闭式 X(ejω) = 1/(1 − ae−jω)。 下面同时画三条曲线：

  • 蓝实线：|X(ejω)|，横轴取 [−2π, 2π]（也就是两个周期）；
  • 红虚线：|X(ej(ω+2π))|——独立算一遍、不做任何"周期假设"的结果。它会和蓝线严丝合缝地重合，这就是周期性的可视证据；
  • 灰点线：把无穷级数只取前 N 项（截断）的结果。N 越大越贴近闭式，这就是收敛条件 |a|<1 的实际含义。
看懂了什么

① 曲线以 2π 为周期：在 ω=0 处有一个峰，在 ω=±2π 处有一模一样的峰；[0,π] 的形状在 [2π,3π] 上原样重演。读数栏里"2π 周期性的最大偏差"在 1e−14 以内（纯浮点误差）， 说明这不是"看起来像"，而是恒等。

② a 的符号决定能量在哪里：a > 0（如 0.8）时峰在 ω = 0, ±2π——序列是缓慢衰减的正值，属于低频； 把 a 拖成负数（如 −0.8），序列变成正负交替、快速振荡， 峰立刻跑到 ω = ±π——那正是离散时间的最高频。

③ 截断与收敛：把 N 拉到很小（比如 4），灰线在 ω=0 附近明显低于闭式； N 拉大，灰线贴上去。读数栏还顺手验证了帕塞瓦尔： Σ|x[n]|² 与 (1/2π)∫2π|X(ejω)|²dω 相等。

6. 常用变换对（含推导）

把这几个当成"单词"。复杂序列先拆成它们，再套性质表。

① 单位冲激 ⟷ 常数 1

δ[n] ⟷ 1
推导

用 δ[n] 只在 n=0 非零：

X(ejω) = +∞Σn=−∞ δ[n]e−jωn = e−jω·0 = 1

直觉：冲激在时间上最"集中"，频谱就最"平坦"——所有频率等强度，而且这个常函数当然以 2π 为周期。

② 单边指数 ⟷ 复有理函数（本节主角）

anu[n] ⟷ 11 − ae−jω  (|a| < 1)
推导（几何级数）
X(ejω) = ∞Σn=0 ane−jωn = ∞Σn=0 (ae−jω)n = 11 − ae−jω

为什么：这是公比为 q = ae−jω 的等比级数， 和为 1/(1−q)，条件是 |q| < 1。 而 |q| = |a|·|e−jω| = |a|，所以要求 |a| < 1——这就是本序列的绝对可和条件 （Σ|a|n = 1/(1−|a|)）。

模长：|1 − ae−jω|² = 1 − 2a cos ω + a²，所以

|X(ejω)| = 1√(1 − 2a cos ω + a²)

它的分母里只有 cos ω，而 cos 以 2π 为周期—— 于是模长自动以 2π 为周期。这就是实验 1 里那条曲线的来历。

③ 矩形脉冲 ⟷ Dirichlet 核

x[n] = 1 (|n| ≤ N1) ⟷ sin[ω(N1+½)]sin(ω/2)
推导（等比求和 + 半角公式）
X(ejω) = N1Σn=−N1 e−jωn

把求和起点挪到 0（把 ejωN1 提取出来）， 得到首项 1、公比 e−jω、共 2N1+1 项的等比数列：

= ejωN1 · 1 − e−jω(2N1+1)1 − e−jω

分子分母同乘 ejω(2N1+1)/2 与 ejω/2，用 ejA − e−jA = 2j sin A：

= ejωN1 · sin[ω(N1+½)]sin(ω/2)

为什么这叫 Dirichlet 核 （Dirichlet kernel）：它是连续时间 sinc 函数的离散表亲。区别在于 sinc 不周期、Dirichlet 核以 2π 为周期。第 9 节会用它把 DTFS 和 DTFT 焊在一起。

④ 更一般的"双边"与"反因果"

−anu[−n−1] ⟷ 11 − ae−jω  (|a| > 1 时才收敛)

同一个闭式 1/(1−ae−jω)，收敛条件不同就对应不同的序列—— 第 13 章 z 变换会用 ROC（收敛域）把这件事讲得更清楚。

(−1)n x[n] ⟷ X(ej(ω−π))

频移性质的直接应用：乘 (−1)n = ejπn 就把频谱搬半圈，把低通变高通（第 10 章会用这条设计滤波器）。

周期信号的 DTFT 为什么是"冲激串"

因为频谱必须以 2π 为周期，所以一个周期信号的每根谱线都必须在 ω0 + 2πl（l = 0, ±1, ±2, …）上各出现一次—— 同一个频率在每个周期里都要冒出来一根，于是就成了一串等间距的冲激。 这一点和第 6 章很不一样：CTFT 里 cos(ω0t) 只有两根冲激，DTFT 里是无穷多根（每 2π 重复一次）。

8. 六条关键性质的推导

性质表不用死背，但下面这六条必须会推——考试的推导题基本都从它们里出。

推导（点开/收起）：时移 / 频移 / 时间反转 / 卷积 / 相乘 / 帕塞瓦尔

(a) 时移：x[n−n0] ⟷ e−jωn0X(ejω)

+∞Σn=−∞ x[n−n0]e−jωn  令 m = n − n0，则 n = m + n0  = +∞Σm=−∞ x[m]e−jω(m+n0) = e−jωn0X(ejω)

为什么：换元只改求和变量名，指数里的 n0 是常数，可以提出求和号。 幅度 |e−jωn0| = 1，所以纯延时只改相位、不改幅度谱。 另外 e−jωn0 是 ω 的线性相位（相位随频率线性下降）， 这正是"延时"在频域里的指纹（第 10 章的线性相位=不失真）。

(b) 频移：ejω0nx[n] ⟷ X(ej(ω−ω0))

+∞Σn=−∞ ejω0nx[n]e−jωn = +∞Σn=−∞ x[n]e−j(ω−ω0)n = X(ej(ω−ω0))

为什么：两个指数合并，剩下的就是"把频谱的自变量整体换成 ω−ω0"， 即整条曲线向右平移 ω0。 离散时间的特殊之处：因为原曲线以 2π 为周期，搬出右端的部分会从左端"绕回来"， 所以平移永远是循环的。

推论（很实用）：取 ω0 = π，即 ejπn = (−1)n，频谱就左右搬半圈： 理想低通 Hlp(ejω) 变成 Hlp(ej(ω−π))，也就是一个截止频率为 π−ωc 的理想高通，对应冲激响应 hhp[n] = (−1)nhlp[n]。

(c) 时间反转：x[−n] ⟷ X(e−jω)

+∞Σn=−∞ x[−n]e−jωn  令 m = −n  = +∞Σm=−∞ x[m]e−j(−ω)m = X(e−jω)

为什么求和限没变：m 从 −∞ 走到 +∞ 与 n 的走向正好相反，但把这个"反向"吸收进 m = −n 之后，求和范围仍是全体整数。

(d) 卷积：x[n] ∗ y[n] ⟷ X(ejω)Y(ejω)

+∞Σn=−∞ [ +∞Σk=−∞ x[k]y[n−k] ] e−jωn = +∞Σk=−∞ x[k] [ +∞Σn=−∞ y[n−k]e−jωn ]

为什么能交换次序：两个级数在绝对可和的前提下都绝对收敛，可以逐项相乘后重排。 （极限情况下（均方收敛）这一步要用更细的论证，结论不变。）

= +∞Σk=−∞ x[k] · e−jωkY(ejω) = X(ejω)Y(ejω)

为什么方括号等于 e−jωkY(ejω)： 这正是刚证的时移性质（把 n0 换成 k）。

这就是 频率响应 的理论基础：LTI 系统输出 y = x ∗ h，所以 Y(ejω) = H(ejω)X(ejω)—— 时域卷积在频域变成一次乘法。

(e) 相乘：x[n]y[n] ⟷ (1/2π)∫2πX(ejθ)Y(ej(ω−θ))dθ

把 y[n] 用反变换写开（积分变量用 θ），再交换求和与积分：

+∞Σn=−∞ x[n]y[n]e−jωn = +∞Σn=−∞ x[n] [ 12π ∫2π Y(ejθ)ejθndθ ] e−jωn
= 12π ∫2π Y(ejθ) [ +∞Σn=−∞ x[n]e−j(ω−θ)n ] dθ = 12π ∫2π X(ej(ω−θ))Y(ejθ)dθ

为什么方括号里是 X(ej(ω−θ))：它就是 DTFT 的定义，只是把 ω 换成了 ω−θ。 整个结果就是"两个周期函数在 2π 上的 周期卷积"。 注意与卷积性质的方向相反：时域相乘 ⟷ 频域（周期）卷积。

(f) 帕塞瓦尔：Σ|x[n]|² = (1/2π)∫2π|X(ejω)|²dω

+∞Σn=−∞ |x[n]|² = +∞Σn=−∞ x[n] [ 12π ∫2π X*(ejω)e−jωndω ]

为什么：|x[n]|² = x[n]x*[n]， 而 x*[n] 就是反变换两边取共轭（指数符号翻转、频谱取共轭）。

= 12π ∫2π X*(ejω) [ +∞Σn=−∞ x[n]e−jωn ] dω = 12π ∫2π |X(ejω)|²dω

为什么有意义：方括号里正是 X(ejω)。 左边是序列的总能量，右边是按 |X|² 积出来的频域能量—— 能量守恒，所以 能量谱密度 （energy density spectrum）就是 |X(ejω)|²（还差 1/2π 这个单位换算）。 实验 1 的读数栏会当场把这两个数算给你看。

9. 动手：DTFS 系数就是 DTFT 的采样

这一节把第 5 章和第 7 章焊在一起，也正是本章第 2 节推导的图形版。 取一个宽度为 2N1+1 的矩形脉冲， 灰蓝曲线是它的 DTFT（Dirichlet 核，连续曲线）； 把它以 N 为周期复制后，红点就是 DTFS 系数放大 N 倍后的位置。

为什么红点的纵坐标画的是 N|ck|？因为 ck = (1/N)X(ejk2π/N)， 乘上 N 才能和连续曲线落在同一把尺子上。它们必然落在曲线上——这正是推导第 3 步的结论。

看懂了什么

① 红点永远不会跑出曲线：不管怎么改 N 和 N₁，DTFS 系数永远落在 DTFT 曲线上。 这就是"级数系数 = 变换的采样"。

② 采样间隔是 2π/N：一个 2π 周期里正好有 N 个点。 把 N 从 8 拉到 24，点变密、间距变小；N→∞ 时这些点就"挤成"了连续曲线—— 这就是第 2 节那个推导的逆向阅读：DTFS 是 DTFT 的采样，DTFT 是 DTFS 的极限。

③ 频率轴的位置也印证了周期：在 [−2π, 2π] 上你能看到同样的点阵重复了两遍， 因为 X(ejω) 本身就是 2π 周期的。

10. 动手：用 DTFT 分析 LTI 系统

频域分析最实用的地方：输入是两个余弦的叠加，系统是一阶低通 h[n] = anu[n]（即 H(ejω) = 1/(1−ae−jω)）。 因为复指数是 LTI 系统的特征函数（第 3 章），输出可以直接写出来：

x[n] = cos(ω1n) + 0.6cos(ω2n)   ⟹   y[n] = |H(ω1)|cos(ω1n + ∠H(ω1)) + 0.6|H(ω2)|cos(ω2n + ∠H(ω2))

（为了书写方便，把 H(ejω) 简写成 H(ω)。）

看懂了什么

① 每个频率各乘各的：输入里 ω1 的成分被放大 |H(ω1)| 倍，ω2 的成分被放大 |H(ω2)| 倍，互不干扰。这就是 Y = H·X 的物理含义。

② 低通把高频"削"掉：把 a 往 1 推，通带变窄， |H(ω2)| 迅速变小，输出里就只剩慢的那一路—— 波形变得平滑。注意 a 只能取正、系统才稳定 （|a|<1 才是绝对可和）。

③ 读数栏里做了双重验证：直接用特征函数公式算的 y[n]， 与用差分方程 y[n] = x[n] + ay[n−1] 逐点仿真出来的结果， 最大偏差通常在 1e−15 ~ 1e−9 之间（残差是仿真起点留下的瞬态，与 a 的大小有关）。 公式和时域仿真给出同一个答案，这说明频域那套推导没有耍花招。

11. 差分方程直接写出 H(ejω)

实际系统常常是用差分方程给出的。好消息是：不需要先求 h[n] 再变换，直接把 ejω 代进去就行。

推导（点开/收起）：由差分方程直接读出 H(e^{jω})

设系统由线性常系数差分方程描述：

NΣk=0 ak y[n−k] = MΣk=0 bk x[n−k]

第 1 步：让输入是复指数 x[n] = ejωn。

由特征函数性质（第 3 章），输出必定是同一频率的复指数乘以一个复数常数：

y[n] = H(ejω) · ejωn

为什么：ejωn 经过 LTI 系统只会被"乘一个复数"—— 模长被放大、相位被推迟，波形形状（频率）不变。

第 2 步：把两边的时移都用 e−jkω 表示。

y[n−k] = H(ejω)ejω(n−k) = e−jkω · H(ejω)ejωn,    x[n−k] = e−jkωejωn

为什么：延时 k 个样本 ⟹ 乘以 z−k 其中 z = ejω。这是"时移性质"在特征函数上的直接体现。

第 3 步：代入方程，两边约掉公因子 ejωn。

NΣk=0 ake−jkω · H(ejω)ejωn = MΣk=0 bke−jkωejωn

为什么能约掉：ejωn 与 k 无关、对每一项都一样， 而且永远不为 0（模恒为 1）。

第 4 步：移项得到频率响应。

H(ejω) = MΣk=0 bke−jkω NΣk=0 ake−jkω

为什么好：把方程里"x 的系数放分子、y 的系数放分母"，再把每个延时 k 换成 e−jkω，H 就写出来了。 分子分母都是 e−jω 的多项式。

例：y[n] − ay[n−1] = x[n] ⟹ H(ejω) = 1/(1 − ae−jω)， 与上面第 6 节的变换对 ② 完全一致，所以冲激响应就是 h[n] = anu[n]（要求 |a| < 1）。 这就是本页实验 1 和实验 3 里那个系统的来历。

12. 它和其它变换的关系

三条关系，背下来

① DTFS → DTFT（本章）：把 DTFS 的 N 推向无穷，离散谱线挤成连续曲线。 反过来：ck = (1/N)·X(ejk2π/N)—— DTFS 系数是 DTFT 的等间隔采样（实验 2 就是这个等式）。

② DTFT → DFT（第 8 章）：计算机算不了连续曲线，只能算有限个频率点。 在 ω = 2πk/N 上采样得到 X[k]， 就是 DFT。代价是"时域被当成周期的"（隐含周期延拓），于是有了循环卷积。

③ DTFT → z 变换（第 13 章）：DTFT 只在单位圆 z = ejω 上看频谱； 允许 z 跑遍整个复平面，就得到 z 变换 X(z) = Σx[n]z−n。 前提是单位圆落在 ROC（收敛域）里，才有 X(ejω) = X(z)|z=ejω。

顺带说一句对偶性

连续时间有一个漂亮的对称：时域的矩形 ⟷ 频域的 sinc。 离散时间里这份对称被"周期化"改写了： DTFT 与 CTFS（连续时间傅里叶级数）之间存在对偶关系—— "时域离散 ⟷ 频域周期"、"时域周期 ⟷ 频域离散"。 记住这条口号，第 14 章的总对照表就会变得很好记： 一个域里的离散，对应另一个域里的周期。

13. 常见坑

坑 1：忘记频谱以 2π 为周期

这是本章第一大坑。X(ejω) 是周期函数， ω 只能算到 ±π（或 0…2π）。 把 ω=3π 处的值当成"新信息"就错了。

坑 2：以为 ω=2π 是"更高的频率"

ω=2π 就是直流（和 ω=0 一样）。 离散时间的最高频率是 ω=π；再往上"频率"反而在下降 （1.9π 与 −0.1π 是同一个频率）。

坑 3：漏掉反变换的 1/2π

正变换没有系数，反变换才有 1/2π。 这和 CTFT 的约定一致；但要注意反变换的积分区间是 2π，不是 (−∞,∞)。

坑 4：绝对可和条件写错

是 Σ|x[n]| < ∞（绝对值之和）， 不是 Σx[n] < ∞。对 anu[n] 来说，条件就是 |a| < 1，闭式 1/(1−ae−jω) 也正是在这个前提下推出来的。

坑 5：周期信号的 DTFT 只画一根冲激

因为频谱必须 2π 周期，周期信号的谱是冲激串： Σlδ(ω−ω0−2πl)。 每个周期里都要有一根，漏掉重复项是常见错误。

坑 6：把时域相乘也当成"频域相乘"

卷积性质是"时域卷积 ⟷ 频域相乘"。 反过来"时域相乘 ⟷ 频域周期卷积（带 1/2π）"，两者不能互相替代。

坑 7：以为"有限长 ⟹ 频谱平坦"

频谱平坦（等于常数 1）的是 δ[n]，不是"任何有限长序列"。 比如矩形脉冲的频谱是 Dirichlet 核，有一堆旁瓣（实验 2 里看得很清楚）。

坑 8：忘了 H(ejω) 是 h[n] 的 DTFT

频率响应不是别的什么函数，它就是冲激响应的 DTFT： H(ejω) = Σh[n]e−jωn。 所以 H 也以 2π 为周期，也要满足实序列的共轭对称。
