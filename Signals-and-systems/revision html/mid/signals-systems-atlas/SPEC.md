## 2. 写作风格（这是质量线，不是建议）

* **读者假设**：完全没学过信号与系统的大一物理/工科生。他只看这一页，不能查别的资料。
* **每个符号、每个术语首次出现时**必须给中文名 + 一句话直观含义，用术语气泡：
  ```html
  <span class="term" data-def="spectrum，中文含义：频谱。X(jω) 是复数，模长=该频率成分的强度，辐角=相位。">频谱</span>
  ```
  （`data-def` 里写：英文名，中文含义，一句直观解释。工具会自动做悬停气泡。）
* **公式不跳步**：用 `<details class="deriv">` 折叠推导，每个 `.step` 后面用 `<p class="why">为什么：…</p>`
  交代"这一步凭什么成立"（换了什么元、用了什么性质、为什么能交换积分次序/求和次序）。
* **直觉先行**：先给"这公式在说什么人话"，再上数学。多用类比（卷积=翻转平移相乘积分；
  采样=谱的周期延拓；z 变换=e^{sT} 的离散版）。
* **不做无出处的断言**：数值例子要在页面里真的能算/或能在实验台里看到。
* **鼓励式语气**，可以出现"别慌""这一步很关键"这类话，但不要卖萌，不要空喊口号。
* 中文排版：中英文之间可以不加空格，但**数学符号用 `<i>` 或 `.mono` 包起来**；不要出现错别字。
* **不要写"略""显然""留作练习"**（除非是真正的自测题）。

### 3.2 互动实验台 `SSC.lab(opts)`

> **约定（踩过坑）**：`draw(cv, vals, api)` 里的 `cv` 是**画布映射**、`vals` 是**控件值映射**，
> 两者是不同对象但键名容易混淆。请让**画布的 `id` 与控件的 `id` 永不同名**
> （例如画布用 `accplot`/`time`/`freq`，控件用 `n`/`a`/`tau`），避免自己写出 `cv.n` 却以为拿到滑块值。


```js
SSC.lab({
  mount: '#lab-xxx',                 // 页面上先放 <div id="lab-xxx"></div>
  title: '实验 · 标题',
  hint: '一句操作提示',
  columns: 2,                        // 画布并排（默认多画布并排 2 列）
  canvases: [                        // 不给就自动一个 id='main' 的画布
    { id: 'time', label: '时域', height: 200 },
    { id: 'freq', label: '频域', height: 200 }
  ],
  controls: [
    { id: 'a', label: '参数 a', min: 0.1, max: 5, step: 0.1, value: 1, unit: ' s' },
    { id: 'mode', label: '模式', options: [{ v: 'x', t: '选项一' }, { v: 'y', t: '选项二' }], value: 'x' }
  ],
  buttons: [{ label: '重置', onClick: function (vals, api) { api.set('a', 1); } }],
  draw: function (cv, vals, api) {   // 每次改参数都会重新调用
    SSC.plot(cv.time, { /* 见 3.3 */ });
    api.readout('<div class="stat"><div class="k">标签</div><div class="v">42</div></div>');  // 可选
  },
  note: function (vals) { return '随参数变化的说明文字（支持 HTML）'; }
});
```

## 5. 每章内容 brief（照这个写，可以更详细，不要更少）

> 通用要求：每章都要有"这章在回答什么问题"的引子、**至少一个能改参数的实验台**、

### ch01-signals.html（信号与系统基本概念）
* 信号是什么（定量描述物理现象的函数）、CT/DT 记号约定 `x(t)` vs `x[n]`。
* 能量与功率：`E=∫|f|²dt`，`P=lim(1/2T)∫|f|²dt`；三类信号（有限能量/有限功率/都不是）。
* 自变量变换：平移、反转、尺度（含组合 `f(αt+β)` 的顺序陷阱：先翻转/缩放再平移）。
* 周期信号、偶/奇信号、奇偶分解 `Ev{x}=(x(t)+x(−t))/2`。
* 复指数与正弦：`e^{jω₀t}`、`e^{αt}`、`e^{jω₀n}` 的周期条件（离散要 `ω₀/2π` 为有理数）。
* δ 与 u：定义、筛选性质、`u(t)=∫δ`、`δ(at)=δ(t)/|a|`、离散 δ[n] 与 u[n]。
* 系统与六条性质：记忆性、可逆性、因果性、稳定性、时不变性、线性（齐次+叠加）。
* **实验台**：`f(αt+β)` 的 α/β 滑块，同时显示理想结果与"错误顺序"结果（教学效果强）。
* **实验台 2（可选）**：能量/功率判定（给几种信号，切换看 E/P 与是否收敛）。

### ch02-convolution.html（LTI 与卷积）
* 为什么 LTI 系统只需 h(t)：任意信号拆成 δ 的加权和 → 叠加原理 + 时不变性。
* 卷积和 `y[n]=Σ x[k]h[n−k]` 与卷积积分 `y(t)=∫x(τ)h(t−τ)dτ`；步骤：翻转→平移→相乘→积分/求和。
* 卷积性质：交换律、分配律、结合律、`x(t)*δ(t−t₀)=x(t−t₀)`、级联/并联。
* 记忆性/因果性/稳定性与 h 的关系（`h[n]=0, n<0`；`Σ|h|<∞`）。
* 微分/差分方程描述的系统；特征多项式与 h 的关系（h 是指数/几何序列）。
* **实验台（核心）**：两个有限长序列卷积——用滑块移动 n，实时显示 x[k]、h[n−k]（翻转平移后的）与乘积求和，
  并显示已累加的结果。必须能直观看到"翻转"和"滑动"。

### ch03-eigenfunction.html（复指数：频域分析为什么可行）
* 特征函数/特征值定义（先给有限维线性代数的类比：矩阵 × 特征向量 = 标量 × 特征向量）。
* 严格验证：`e^{st} → H(s)e^{st}`（CT，s 可复）；`z^n → H(z)z^n`（DT）。
* 由此得到频率响应 `H(jω)`、`H(e^{jω})` 的含义：每个频率的复数增益（模=放大，辐角=相移）。
* 正交分解的普遍思想：用一组正交基把信号表示出来；傅里叶基、勒让德多项式、哈尔小波、K-L/PCA 各自的基与用途。
* **实验台（核心）**：输入 `z^n`（滑块调 |z| 和 ∠z）经过 `h[n]=α^n u[n]` 系统，显示输出与"输入×H(z)"完全重合；
  再把 |z| 推过 1 看输出发散（引出 ROC 的直觉）。

### ch04-ctfs.html（连续时间傅里叶级数）
* 最小二乘/正交投影的直觉：用 cos/sin 去"量"信号的成分。
* 三角形式与指数形式两种写法、`a_k` 的公式与推导（正交性 + 两边乘 e^{−jkω₀t} 积分）。
* 收敛与吉布斯现象（过冲约 9%，与谐波个数无关，只看跳变量）。
* 性质：线性、时移、频移、共轭、尺度（周期变）、相乘、共轭对称；Parseval（各谐波功率和）。
* 典型例子：方波、三角波（谐波衰减速度 1/k vs 1/k²）。
* **实验台（核心）**：谐波数 N + 波形选择（方波/三角/锯齿）→ 时域合成 + 线谱，实时看吉布斯。

### ch05-dtfs.html（离散时间傅里叶级数）
* 离散周期信号只有 **N 个**独立谐波（因为 `e^{j(2π/N)n}` 以 N 为周期）——与 CT 的无穷多个形成对比。
* `c_k = (1/N)Σ_{n=<N>} x[n]e^{−jk(2π/N)n}`，`x[n]=Σ_{k=<N>} c_k e^{jk(2π/N)n}`。
* 周期性、偶奇对称性、Parseval。
* 与 DFT 的关系（DFT 就是 DTFS 在有限长序列上的算法化）。
* **实验台（核心）**：周期 N（3–16）与波形（脉冲序列/方波）→ 时域 + `|c_k|` 线谱；改 N 看"独立谐波个数 = N"。

### ch07-dtft.html（离散时间傅里叶变换）
* 由 DTFS 取 N→∞ 得到 `X(e^{jω})=Σ_{n=−∞}^{∞} x[n]e^{−jωn}`，反变换 `x[n]=(1/2π)∫_{2π}X(e^{jω})e^{jωn}dω`。
* **频谱以 2π 为周期**（离散时间的必然），只在 ω∈[0,2π) 或 [−π,π) 内独一份；ω=π 是最高频率。
* 收敛条件：绝对可和 `Σ|x[n]|<∞`。
* 性质表（与 CTFT 对照）：时移、频移、共轭、时间反转、卷积、相乘、差分、Parseval。
* 常用对：`δ[n]↔1`、`a^n u[n]↔1/(1−ae^{−jω})`（|a|<1）、矩形序列↔Dirichlet 核。
* **实验台（核心）**：序列长度 N 与 a（`a^n u[n]`）→ 时域 stem + `|X(e^{jω})|`，并把 ω 推到 −π/π 边界看周期性（2π 平移重合）。

### ch08-dft.html（DFT 与 FFT）
* 为什么计算机只能算有限长：`X[k]=Σ_{n=0}^{N−1}x[n]e^{−j2πkn/N}`，隐含"x[n] 以 N 为周期"。
* DFT 是 DTFT 在 N 个等间隔频率上的采样；**时域周期延拓 ↔ 频域采样**的对偶关系。
* 循环卷积（循环 vs 线性，何时相等：补零到 N≥N₁+N₂−1）。
* 栅栏效应、泄漏（不加窗时的截断效应）、补零的作用（只加密频域采样点，不提高真实分辨率）。
* FFT 是算法（`N log N` vs `N²`）；实序列可以用一个 N 点 FFT 算两个实序列。
* **实验台（核心）**：N=4/8/16 滑块 → 显示 `x[n]`、`|X[k]|`，并与 DTFT 连续曲线叠加（看"采样"关系）；
  另一个实验台做循环卷积 vs 线性卷积的对比。

### ch09-sampling.html（采样定理与重建）
* 采样 = 乘冲激串；频域 = **频谱以 ω_s 为周期延拓并叠加**（推导完整给出）。
* 奈奎斯特率 `ω_s > 2ω_M`；混叠（aliasing）的产生与判断；把混叠后的频率算出来（`ω_alias = |ω − kω_s|` 取最小）。
* 理想重建：sinc 内插公式及其推导；为什么实际用零阶保持（平顶采样）。
* 离散时间处理连续时间信号（C/D → 离散 LTI → D/C），`H_d(e^{jω})=H_c(jω/T)`。
* 内插（上采样）与抽取（下采样）：频域发生了什么（压缩/展宽），为什么需要抗混叠滤波。
* **实验台（核心）**：正弦频率 f 与采样率 fs 两个滑块 → 显示原信号、采样点、重建曲线，
  以及"混叠后的表观频率"；把 fs 推到 f 以下看混叠。第二个：频域周期延拓图。

### ch10-filters.html（时频特性与滤波器）
* 幅度—相位表示：`H(jω)=|H|e^{j∠H}`；相位决定延时（群延迟 `−d∠H/dω`），线性相位=不失真。
* 理想滤波器（低通/高通/带通/带阻）的频域定义与**非因果**的时域形状（sinc 双边无限）→ 不可实时实现。
* 非理想滤波器：过渡带、通带波纹、阻带衰减；巴特沃斯（最大平坦）等逼近思想。
* 一阶/二阶系统：时间常数、阻尼比 ζ 与谐振峰、上升时间与带宽的反比关系。
* **实验台（核心）**：`SSC.pzLab`（z 或 s 域）拖极零点看频响与滤波类型 + 阶跃响应；
  第二个：截止频率滑块 + 输入含多频率成分 → 看输出波形变化。

### ch11-modulation.html（调制、解调与通信）
* 为什么需要调制（天线尺寸、频分复用）。
* 复指数/正弦幅度调制：`y=x·cos ω_c t` → `Y=(1/2)[X(j(ω−ω_c))+X(j(ω+ω_c))]`（完整推导）。
* 解调：同步解调（再乘 cos 后低通）、为什么需要低通与 2 倍放大；载波相位/频率误差的后果。
* 频分复用（FDM）与单边带（SSB）思想；脉冲载波调制与 PAM、TDM。
* 离散时间调制。
* **实验台（核心）**：`ω_c` 滑块 + 基带频谱 → 搬移；再加"接收端再乘 cos 并低通"的完整链路演示（时域+频域各一张图）。

### ch12-laplace.html（拉普拉斯变换）
* 动机：傅里叶变换要求绝对可积，很多信号（`e^{at}u(t)`、`u(t)`）不满足 → 乘衰减因子 `e^{−σt}`。
* 定义 `X(s)=∫x(t)e^{−st}dt`，`s=σ+jω`；`X(jω)=X(s)|_{s=jω}`（**前提：ROC 含虚轴**）。
* ROC 的性质（三条铁律）：右边信号 → `Re{s}>σ_max`；左边 → `<σ_min`；双边 → 条带；有理变换的 ROC 由极点界定、不含极点。
* 常用对（`δ`、`u`、`e^{−at}u`、`t^n`、`cos/sin`）与性质表（时移、s 域平移、尺度、卷积、微分、积分、初值/终值定理）。
* 反变换：部分分式 + 查表；极点位置与信号形状（右边/左边）的对应。
* 用 s 域解微分方程（含初始条件，单边拉氏）；系统函数 `H(s)=Y/X`、零极点图、稳定性判据（ROC 含虚轴 ⇔ 稳定；极点全在左半平面 ⇔ 因果且稳定）。
* **实验台（核心）**：`SSC.pzLab({domain:'s'})` 拖极点 → ROC/虚轴关系 + `|H(jω)|`；第二个：`e^{−at}u(t)` 的 a 滑块 → 看 `X(s)` 的极点移动与 `|X(jω)|` 变化。

### ch13-ztransform.html（z 变换）
* 定义 `X(z)=Σ x[n]z^{−n}`，z 为复数；与拉氏的关系 `z=e^{sT}`（s 左半平面 ↔ 单位圆内，虚轴 ↔ 单位圆）。
* 几何意义：`z=re^{jω}`，r 是衰减旋钮、ω 是频率；`DTFT = z 变换在单位圆上的取值`（前提 ROC 含单位圆）。
* ROC 三条铁律（右边/左边/双边/有限长）+ 有理变换 ROC 由极点划分；同一 X(z) 不同 ROC = 不同序列（举 `1/(1−az^{−1})` 的两种读法）。
* 常用对：`δ[n]↔1`（全平面）、`u[n]↔1/(1−z^{−1})`（|z|>1）、`−u[−n−1]↔1/(1−z^{−1})`（|z|<1）、`a^n u[n]↔1/(1−az^{−1})`（|z|>|a|）、`na^n u[n]↔az^{−1}/(1−az^{−1})²`、`cos(ω₀n)u[n]`。
* 性质表（线性、时移、z 域尺度、时间反转、卷积、差分、累加、z 域微分、初值定理、Parseval）。
* 反变换三法：部分分式展开（含 ROC 定左右）、幂级数长除、留数法（`x[n]=Σ 留数`）。必须给完整算例。
* 系统函数 `H(z)=B(z)/A(z)`，零极点图，稳定性（因果 + 极点全在单位圆内），FIR/IIR 区别，差分方程 ↔ 方框图。
* **实验台（核心）**：`SSC.pzLab({domain:'z'})`（拖极零点看 ROC/单位圆/|H|/稳定性）；
  第二个：因果/反因果开关，同一 `X(z)` 看两种序列的时域波形差别；
  第三个（可选）：逆变换留数法数值验证（给部分分式系数，用 `diffEq` 生成序列与公式对比）。
