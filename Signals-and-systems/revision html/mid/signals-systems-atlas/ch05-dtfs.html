离散时间傅里叶级数（DTFS）

第 4 章里，连续时间的周期信号要用无穷多条谱线才拼得出来。换成离散时间，情况突然变了： 一个周期为 N 的序列只有 N 个真正独立的谐波， 第 N+1 条就是第 1 条的复制品。 这一章就做一件事：把"为什么只有 N 个"讲透，并给出 ck 的计算公式和它的性质。

1. 这一章在回答什么问题

第 4 章我们给连续时间的周期信号找到了"原子"：复指数 ejkω0t。 任何周期信号都能写成这些原子的加权和，权重就是 傅里叶级数系数。 这一章对离散时间的周期信号做同一件事，但你会看到两处根本差别：

  • 时间轴只剩整数点：n = 0, ±1, ±2, …，中间没有"半个点"可踩。
  • 频率轴卷起来了：在离散时间里，ω 与 ω+2π 代表同一个振荡 （因为 ej(ω+2π)n = ejωn·ej2πn = ejωn，而 n 是整数）。 频率不是一条无限长的直线，而是"绕圈"的角度。
先把结论说出来

这两点合在一起，逼出一个漂亮的结果：周期为 N 的离散信号， 它的"原子集合" ejk(2π/N)n 里只有 N 个是互不相同的。 所以 DTFS 是一个有限项的级数——这和第 4 章的无穷级数形成鲜明对照，也顺手消灭了收敛问题和吉布斯现象。

2. 灵魂：离散周期信号只有 N 个独立谐波

设 x[n] = x[n+N]，最小的正整数 N 叫 基波周期 （fundamental period），而 ω0 = 2π/N 是 基波角频率 （fundamental frequency，单位是 rad/样本，不是 rad/s）。 我们想用的"原子"是这些：

φk[n] = ejkω0n = ejk(2π/N)n,    k = 0, ±1, ±2, …

每个 φk[n] 都是一个周期为 N 的序列， 它们就是离散时间的 谐波 （harmonic）。 关键问题是：这无穷多个 k 里，有多少个是不同的序列？

推导（点开/收起）：为什么只剩 N 个，以及 k 与 k+N 的关系

第 1 步：把 k 换成 k+N，直接算一算。

φk+N[n] = ej(k+N)(2π/N)n = ejk(2π/N)n · ejN(2π/N)n = ejk(2π/N)n · ej2πn

为什么：指数相加可以拆成两个指数相乘（eA+B = eAeB）。

第 2 步：认出 ej2πn = 1。

ej2πn = cos(2πn) + j·sin(2πn) = 1 + j·0 = 1   （n 是整数）

为什么这里必须强调"n 是整数"：cos 的周期是 2π， 只有在自变量是 2π 的整数倍时它才等于 1。连续时间里 ej2πt 随 t 连续变化，永远消不掉；离散时间里 n 只能取整数，它必然等于 1。 这就是"离散"两个字的全部威力。

第 3 步：得出结论——第 k 个和第 k+N 个谐波是同一个序列。

φk+N[n] = φk[n]   (对所有 n 成立)

为什么这条这么重要：它说明 k 只在模 N 的意义下有意义。 于是 k = 0, 1, …, N−1 这 N 个值就已经穷尽了所有不同的谐波； k = N 与 k = 0 是同一个， k = N+1 与 k = 1 是同一个，依此类推。

第 4 步：系数也跟着周期重复。

由分析式（下一节给出），把 k 换成 k+N：

ck+N = 1N Σn=<N> x[n] e−j(k+N)(2π/N)n = 1N Σn=<N> x[n] e−jk(2π/N)n · e−j2πn = ck

为什么：又是 e−j2πn = 1。这一条你可以立刻在下面的实验台里亲眼验证： 一个周期内那 N 根谱线，会在 k 轴上每 N 个点一模一样地重复一遍。

本页最重要的一句话

周期为 N 的离散周期信号，只有 N 个独立谐波；DTFS 是 N 项的有限和，而不是无穷级数。 因此它没有第 4 章那种收敛讨论，也不会有吉布斯过冲（第 9 节会用实验证明这一点）。

几何直觉：频率是"圆上的刻度"

把复指数想成在单位圆上以每步 ω0 = 2π/N 的角度往前走的点。 走 N 步正好回到出发点（转满一圈）。 所以"每步 2π/N"和"每步 2π/N + 2π"是同一件事，只是你多绕了一圈； 频率轴于是卷成了一个周长 2π 的圆。

圆上均匀刻 N 个刻度，走 k 步和走 k+N 步落在同一个刻度上—— 这就是 φk+N = φk 的几何版本。 记住这个圆，第 7 章"频谱以 2π 为周期"就是它的直接后果。

3. 定义对与符号表

把 x[n] 写成 N 个谐波的加权和，权重记作 ck， 就得到离散时间傅里叶级数的一对公式：

DTFS 定义对（离散时间傅里叶级数，discrete-time Fourier series）
综合式（合成）   x[n] = Σk=<N> ck ejk(2π/N)n (5-1)
分析式（求系数）   ck = 1N Σn=<N> x[n] e−jk(2π/N)n (5-2)

记号 <N> 读作"任意连续的 N 个整数"。 可以取 k = 0, 1, …, N−1，也可以取 k = 3, 4, …, N+2—— 因为谐波和系数都以 N 为周期，取哪一段都一样（这是离散时间独有的方便）。

这里的 ck 叫 频谱系数 （spectral coefficients），复数，把它的模长和辐角分开看就是两张图：

  • |ck| 叫 幅度谱（magnitude spectrum）：哪次谐波强、哪次弱；
  • ∠ck 叫 相位谱（phase spectrum）：每次谐波被推迟了多少。
符号中文名 / 含义直观理解
n离散时间序号只能取整数：第几个样本。
N周期（period）波形每 N 个样本重复一次。
ω0 = 2π/N基波角频率单位 rad/样本；每个样本上相位前进的角度。
k谐波序号（harmonic index）第几号谐波。只有 N 个不同的值。
<N>任意连续 N 个整数"取一个周期那么长"的求和范围。
ck频谱系数（复数）第 k 次谐波的复振幅：模=强度，角=相位。
两个 1/N 的位置别记反

分析式（求 ck）带 1/N，综合式不带。 这和 CTFS 的习惯一致（那里分析式带 1/T），但和 DFT 的习惯相反 （第 11 节会说清 DFT 差在哪里）。记法："量"信号的一方要平均一下，所以要除以长度。

4. 推导：ck 是怎么被"量"出来的

为什么式 (5-2) 能正确地把第 k 次谐波的权重抠出来？靠的是谐波之间的 正交性 （orthogonality）。先证明一条引理，再套公式。

推导（点开/收起）：正交性引理 + c_k 公式的完整来历

第 1 步（正交性引理）：对一个周期求和，不同谐波互相抵消。

Σn=<N> ejq(2π/N)n = ｛ N，若 q 是 N 的整数倍；  0，其它情况 ｝

为什么：若 q 是 N 的整数倍，则每一项 ejq2πn/N = 1， N 项相加得 N。若不然，令 r = ejq(2π/N) ≠ 1， 这是一个等比数列，公比 r，所以 Σn=0N−1 rn = (1−rN)/(1−r)， 而 rN = ejq2π = 1，分子为 0，故和为 0。

第 2 步：在综合式两边乘上"探针" e−jr(2π/N)n，再对 n 求和。

Σn=<N> x[n] e−jr(2π/N)n = Σn=<N> [ Σk=<N> ck ejk(2π/N)n ] e−jr(2π/N)n

为什么这么做：这就像用"频率为 r 的筛子"去筛信号。若 x[n] 里含有频率 r 的成分， 它会在这一步被留下；其它频率会被筛掉（下一步就看到了）。

第 3 步：交换两个求和的次序，把指数合并。

= Σk=<N> ck Σn=<N> ej(k−r)(2π/N)n

为什么可以换次序：两边都是有限和（各 N 项），有限项的求和随便交换都不会出问题—— 这一点比连续时间省心得多，那里要靠绝对收敛才能交换积分次序。

第 4 步：用第 1 步的引理，内层和只在 k = r（模 N）时非零。

左边 = N · cr   （其它 k 的项全被筛掉，剩下 cr 乘以 N）

为什么剩下的是 cr：把引理里的 q 换成 k−r， 只有当 k−r 是 N 的整数倍时内层和才等于 N。而在 k 的一个周期范围内， 满足这个条件的 k 只有一个，就是 k = r。

第 5 步：两边除以 N，得到分析式。

cr = 1N Σn=<N> x[n] e−jr(2π/N)n

为什么除以 N 而不是别的数：因为引理给出的是 N，我们要的是"平均一个样本贡献了多少"， 所以要除掉长度 N。这个 1/N 就是"平均"两个字的来源。

第 6 步（顺带一个结论）：N 个系数唯一确定 N 个样本值。

把综合式在 n = 0, 1, …, N−1 上写出来，就得到 N 个方程、N 个未知数 c0, …, cN−1 的线性方程组；由正交性可以证明这组方程线性无关， 因此有且仅有一组解。

为什么这条决定了"没有吉布斯现象"：一个周期里只有 N 个数字要记， 傅里叶级数把这 N 个数字换成另外 N 个数字，信息量完全相等，不存在"永远逼近不到"的问题。 第 9 节的实验会让你看到：取满 N 项之后误差是机器精度的 0。

5. 动手：改 N，看"独立谐波个数 = N"

下面这张实验台是本页的核心。左图是周期序列（画了三个周期，深色带是一个基波周期）， 右图是它的幅度谱 |ck|：红色是"基础周期内"的 N 根谱线， 灰色是它们在 k 轴上每 N 个点重复一次的样子。

怎么玩：先把 N 在 3 和 16 之间来回拖，盯住红线的根数；再比对任意一对 k 与 k+N 的高度（读数栏里直接给了数值）。

看懂了什么

灰色谱线不是"另一批谐波"，它们就是红色的那 N 根，只是被搬到了每隔 N 个格子的位置上。 换句话说：给出 k = 0, 1, …, N−1 这 N 个数，你就知道了全部； ck+N = ck 对任何整数 k 都成立。 把波形换成单脉冲 δ[n] 还会有个惊喜：所有 |ck| 一样高， 是一条水平线——这和第 6 章"冲激的频谱是常数"是同一件事的离散版本。

最容易搞错的一点

"只有 N 个独立谐波"≠"ck 只有 N 个值"。 ck 对任意整数 k 都有定义， 只不过第 k+N 个和第 k 个必然相等。 写综合式时只取其中 N 个（取哪一段都行，不能重复取）。

五条关键性质的推导（时移 / 频移 / 周期卷积 / 相乘 / 帕塞瓦尔）

(a) 时移：x[n − n0] ⟷ ck e−jk(2π/N)n0

把 x[n−n0] 代进分析式：

1N Σn=<N> x[n−n0] e−jk(2π/N)n  令 m = n − n0，则 n = m + n0  = 1N Σm=<N> x[m] e−jk(2π/N)(m+n0)
= e−jk(2π/N)n0 · 1N Σm=<N> x[m] e−jk(2π/N)m = ck e−jk(2π/N)n0

为什么求和范围不变：n 走一个周期时 m = n−n0 也正好走一个周期（只是起点挪了），而被求和的东西本身以 N 为周期，所以换起点不影响结果。 指数里的 n0 是常数，可以提出求和号外。 由此立刻看出：|e−jk(2π/N)n0| = 1， 所以时移完全不改幅度谱，只给相位谱加一条随 k 线性增长的斜坡。

(b) 频移：ejM(2π/N)n x[n] ⟷ ck−M

1N Σn=<N> ejM(2π/N)n x[n] e−jk(2π/N)n = 1N Σn=<N> x[n] e−j(k−M)(2π/N)n = ck−M

为什么：两个指数合并后，剩下的正好是"把分析式里的 k 换成 k−M"。 注意这里的平移是循环的：k−M 按模 N 取， 搬出边界的谱线会从另一头绕回来——这正是"频率轴卷成圆"的又一个后果。

(c) 周期卷积：Σr=<N> x[r] y[n−r] ⟷ N ck dk

记 w[n] = Σr=<N> x[r]y[n−r]，直接算它的系数：

Wk = 1N Σn=<N> [ Σr=<N> x[r] y[n−r] ] e−jk(2π/N)n = Σr=<N> x[r] [ 1N Σn=<N> y[n−r] e−jk(2π/N)n ]

为什么能交换次序：两个都只是各 N 项的有限和，再次强调——有限和随便换。

= Σr=<N> x[r] · dk e−jk(2π/N)r = dk · Σr=<N> x[r] e−jk(2π/N)r = N ck dk

为什么方括号里等于 dke−jk(2π/N)r：这正是刚证过的 时移性质（把 n0 换成 r）。 最后一步注意：Σ x[r]e−jk(2π/N)r = N ck（分析式两边乘 N）。 那个 N 就是这样冒出来的，别漏。

这就是 周期卷积 （periodic convolution / circular convolution）。第 8 章讲 DFT 时它会以"循环卷积"的名字再出现一次， 并与普通卷积的差别成为考试重点。

(d) 相乘：x[n] y[n] ⟷ Σl=<N> cl dk−l

把 y[n] 用综合式写开，再交换求和次序：

1N Σn=<N> x[n] y[n] e−jk(2π/N)n = 1N Σn=<N> x[n] [ Σl=<N> dl ejl(2π/N)n ] e−jk(2π/N)n
= Σl=<N> dl [ 1N Σn=<N> x[n] e−j(k−l)(2π/N)n ] = Σl=<N> dl ck−l

为什么是"系数做卷积"：方括号里就是 ck−l（分析式）。 于是时域的逐点相乘，变成频域里两个系数序列的周期卷积。 注意这里的对偶方向和连续时间相反：连续时间里"时域相乘 ⟷ 频域（非周期）卷积"， 离散时间里频域的卷积是周期卷积——因为系数本身就周期。

(e) 帕塞瓦尔：(1/N)Σn=<N>|x[n]|² = Σk=<N>|ck|²

1N Σn=<N> |x[n]|² = 1N Σn=<N> x[n] [ Σk=<N> ck ejk(2π/N)n ]*

为什么可以取共轭：|x[n]|² = x[n]x*[n]， 而 x*[n] 就是综合式两边取共轭，指数上的符号翻过来。

= Σk=<N> c*k [ 1N Σn=<N> x[n] e−jk(2π/N)n ] = Σk=<N> |ck|²

为什么有意义：左边是 平均功率 （一个周期内的平均能量），右边是各次谐波功率之和。功率守恒： 时域算还是频域算，结果一样。这也是把 |ck|² 解释为 "第 k 次谐波贡献的平均功率"的依据。

8. 实信号的对称性

若 x[n] 是实序列（工程中绝大多数情况），由共轭性质 x*[n] ⟷ c*−k 配合 x*[n] = x[n] 可得：

c−k = c*k

把它翻译成两张图上的话：

  • 幅度谱偶对称：|c−k| = |ck|；
  • 相位谱奇对称：∠c−k = −∠ck；
  • 进一步：实且偶的序列 ⟹ ck 是实且偶的； 实且奇的序列 ⟹ ck 是纯虚且奇的。
小心 −k 在离散时间里的意思

因为 ck 以 N 为周期，c−k 其实就是 cN−k（对 k = 1, …, N−1）。 所以在画"一个周期内的 N 根谱线"时，负频率那半边被折到了 k 轴的高端。 换句话说：第 1 根和第 N−1 根是一对（±1 次谐波），第 2 根和第 N−2 根是一对， 而 k = 0（直流）自成一类。

9. 动手：N 项谐波就能精确重建（没有吉布斯）

取一个 ±1 的对称方波，只用 k = −M, …, M 这些谐波把它拼回去。改动 M，看误差怎么变。

看懂了什么

当 M 加到 (N−1)/2 时，你正好用满 2M+1 = N 个谐波，重建误差立刻变成 0（读数栏显示的是 1e−15 上下，那是浮点误差，不是真实偏差）。 这不是"近似得足够好"，而是完全相等：N 个谐波携带的信息量和 N 个样本值一模一样。

把这件事和第 4 章的方波对比一下：连续时间的方波不管用多少项，跳变处永远有约 9% 的过冲（吉布斯现象）； 离散时间根本不会出现这种过冲，因为它的级数是有限的，压根没有"项数不够多"这种事。

10. 动手：时移改相位、频移搬谱线

性质表里的"时移"和"频移"两条，用图看最清楚。设基准波形是一个对称的衰减脉冲串 x[n] = ad(n)（d(n) 是 n 到 0 的环形距离，a = 0.7）， 它的系数恰好都是正实数，所以相位谱看起来最干净。

看懂了什么

时移 n0：幅度谱两根曲线完全重合（读数栏里"时移前后 |ck| 最大差"在 1e−16 ~ 1e−15 之间）， 而相位谱变成一条斜率 −2πn0/N 的直线——只是被折进了 (−π, π] 这个区间，所以看起来是锯齿状。这就是"时移 ⟹ 线性相位"的本来面目。

频移 M：幅度谱整体沿着 k 轴循环平移 M 格， 搬出右端的谱线从左端绕回来。因为离散频率是"圆上的刻度"，平移天然是循环的。

11. DTFS 与 DFT、DTFT 是什么关系

你以后在 MATLAB / Python 里敲的 fft，算出来的正是本章的 ck， 只差一个 1/N 和写法：

X[k] = N−1Σn=0 x[n] e−j2πkn/N = N · ck     ⟹     ck = X[k] / N

也就是说，ck 和 DFT （Discrete Fourier Transform）是同一批数字，只是"归一化位置"不同： DTFS 把 1/N 放在分析式里（数学家的写法），DFT 把它省在正变换里、放在反变换里（工程师的写法）。 第 8 章会专门讲 DFT，以及让计算量从 N² 降到 N log N 的 FFT 算法。

通往下两章的桥

与 DTFT（第 7 章）：如果把一个有限长序列以 N 为周期延拓，那么它的 DTFS 系数满足 ck = (1/N)·X(ejk2π/N)—— DTFS 系数就是 DTFT 在等间隔频率点上的采样，采样间隔 2π/N。 N 越大，采样点越密，N→∞ 时离散的 ck 就"挤成"连续的 X(ejω)。这正是第 7 章开头的推导思路。

与 DFS 的别名：有的教材把本章内容叫 DFS（discrete Fourier series），和 DTFS 是一回事。

12. 常见坑

坑 1：把 k 写成 −∞ 到 +∞

离散周期信号的谐波只有 N 个不同的。综合式写成 Σk=−∞∞ 会把同一根谱线加很多遍，结果是原信号的无穷多倍。

坑 2：1/N 的位置记反

分析式（求 ck）带 1/N，综合式不带。 写反了会让所有系数整体差 N 倍。

坑 3：以为 ck 只有 N 个值

ck 对任意整数 k 都有定义，只是以 N 为周期。 "只有 N 个不同值"和"只在 N 个 k 上有定义"是两件事。

坑 4：把 2π/N 写成 2π/T

离散时间的周期是样本个数 N，不是秒。基频 ω0 = 2π/N 的单位是 rad/样本， 别和连续时间的 rad/s 混用。

坑 5：把 DTFS 的 ck 当成 DFT 的 X[k]

两者差一个因子 N：X[k] = N ck。 用 fft 算出结果后想得到 ck，记得除以 N。

坑 6：以为离散方波也有吉布斯过冲

离散时间傅里叶级数是有限项（N 项），取满就精确相等，不存在过冲。 看到"过冲"两个字，先确认在讨论连续时间还是离散时间。

坑 7：忘记周期卷积里的 N

Σr=<N>x[r]y[n−r] ⟷ N ckdk。 这个 N 来自分析式的归一化，少写它是最常见的丢分点。

坑 8：负频率当成"不存在的频率"

对实信号，c−k = c*k，负频率那半边是冗余的。 但它不是错误：它是把余弦拆成两个复指数时的必然产物。而且在离散时间里 c−k 就写在 k = N−1, N−2, … 的位置上。
