四大变换总对照：级数 / 变换 / 拉氏 / z

关于"四大"这个名字（先把口径说清楚）

这一章传统上叫"四大变换"，指的是四个族： 族①傅里叶级数（CTFS / DTFS，处理周期信号）、 族②傅里叶变换（CTFT / DTFT / DFT，处理非周期与有限长信号）、 族③拉普拉斯变换（连续复频域）、 族④z 变换（离散复频域）。 但落到具体工具是 7 个。所以本页的图、表、选择器一律按七个具体变换来列， 同时用颜色标出它们分别属于哪个族——这样"四大"和"七个"就不再打架： 四个族，七个工具。

1. 一句话记住全部关系

所有关系都出自两个问题的组合：信号是连续的还是离散的？ 它的频率（复频率）是实数还是复数？ 把这两问画成十字，七种变换就各就各位了。

三条"变形规则"（背这三句就够）
  1. 周期 → 非周期：把周期推向无穷（T→∞ 或 N→∞）。 离散的谱线间距趋于 0，线谱"挤成"连续谱。于是级数变成变换： CTFS → CTFT、DTFS → DTFT。
  2. 实数频率 → 复数频率：让衰减旋钮自由。 傅里叶是"旋钮固定在 σ=0（或 |z|=1）"的特例：CTFT = X(s)|s=jω、 DTFT = X(z)|z=ejω。代价是多出一个 ROC。
  3. 连续 ↔ 离散：采样（z = esT）。 时域离散化会让频谱周期延拓；反过来，频域采样（DFT）会让时域周期延拓。 这一条是第 8、9 章的全部内容。
越往下越"能打"，但也越"贵"

傅里叶变换要求信号绝对可积/可和；拉普拉斯与 z 变换只要求"乘上某个衰减因子后可积"， 所以能处理 eatu(t)、u(t) 这类发散信号， 还能顺手判断系统的因果性与稳定性。代价是：答案里必须多写一个 收敛域（ROC）， 而且不能像画频谱那样直接"看曲线"，要在复平面里读区域。

2. 关系总图（每个方框都能点）

箭头方向 = "特例 → 推广"：箭头起点是箭头的终点在某个特殊取值下的样子。 蓝色实线箭头是极限或取值关系，灰色虚线箭头是"同一件事的两种说法"。

图上还有两条容易漏掉的边

① 级数 = 变换的特例，不是另一种东西。周期信号的谱线永远长在那个"非周期极限"的连续包络上 （第 6 章实验 2 亲手验证过）：ak = X(jkω0)/T。 所以"级数"和"变换"之间只差一个"周期有多长"。

② 连续与离散之间只隔一个采样器。 采样把连续信号的频谱按 ωs=2π/T 周期延拓， 这就是离散信号频谱一定以 2π 为周期的根源（第 7、9 章）。 反过来 DFT 把 DTFT 在 ω 上采样，等价于把时域按 N 周期延拓（第 8 章）。

看表时最容易看错的三处
  • "离散谱 / 连续谱"说的不是信号离散还是连续，而是谱本身长什么样。 连续时间周期信号的谱是离散线谱；离散时间非周期序列的谱是连续的（还以 2π 为周期）。
  • ROC 只有拉普拉斯与 z 变换才有。傅里叶级数/变换的条件叫"收敛条件"，写成一个积分（求和）是否有限， 没有"复平面上的区域"这回事。DFT 是有限求和，永远收敛。
  • Parseval 左边是能量还是功率，取决于信号类型。 周期信号（级数）用的是 功率（除以一个周期）； 非周期（变换）用的是能量。

4. s 平面 ↔ z 平面：同一件事的两种坐标

拉普拉斯和 z 变换的关系只有一行：z = esT （T 是采样周期）。把 s = σ + jω 代进去：

z = e(σ+jω)T = eσT · ejωT   ⟹   |z| = eσT,　∠z = ωT

一句话读法：s 的实部 σ 决定"离原点多远"（模），s 的虚部 ω 决定"转角"（辐角）。 于是整个 s 平面被"卷"成了 z 平面——这就是下面这张映射图。

s 平面里的东西z 平面里的像公式 / 理由
虚轴（σ = 0）单位圆 |z| = 1|z| = e0 = 1；角度仍随 ω 走
左半平面（σ < 0）单位圆内 |z| < 1|z| = eσT < 1：包络衰减
右半平面（σ > 0）单位圆外 |z| > 1|z| = eσT > 1：包络增长
竖线 σ = c半径 ecT 的同心圆σ 只管模，不管角
横线 ω = c角度 cT 的射线ω 只管角，不管模
高 2π/T 的条带绕单位圆整整一圈ejωT 以 2π/T 为周期 ⟹ 映射是多对一的
虚轴是否在 ROC 内单位圆是否在 ROC 内两者都等价于"傅里叶变换/DTFT 存在"
因果且稳定：极点全在左半平面因果且稳定：极点全在单位圆内由 z = esT 直接把左半平面搬到圆内
这张映射图顺手解释了"离散频谱为什么以 2π 为周期"

ejωT 每走 ωT = 2π（即 ω 走 2π/T） 就转回原处。所以 DTFT 一定满足 X(ej(ω+2π)) = X(ejω)—— 频率轴上"多出来的那些圈"不是新信息，只是同一根单位圆在反复被走。 这也是混叠的复平面解释：不同的 ω 被卷到了同一个 z。

推导：区域与边界的对应关系是怎么来的（含"为什么是多对一"）

第 1 步：把 s 拆成实部与虚部，代进 z = esT。

z = esT = e(σ+jω)T = eσT · ejωT

为什么：指数相加对应幂相乘（ea+b = eaeb）。 这一步把 s 的两个自由度分离成了"模"和"角"两件事。

第 2 步：取模、取角，得到两条互相独立的对应关系。

|z| = eσT（只与 σ 有关），　∠z = ωT（只与 ω 有关）

为什么可以分开看：ejωT 的模恒为 1，所以模只由 eσT 贡献；而 eσT 是个正实数，不改变角度。 两个自由度各管一件事，这正是"竖线 → 同心圆、横线 → 射线"的原因。

第 3 步：把三个区域分别代进去。

σ = 0 ⟹ |z| = 1（虚轴 → 单位圆）； σ < 0 ⟹ |z| = eσT < 1（左半平面 → 单位圆内）； σ > 0 ⟹ |z| > 1（右半平面 → 单位圆外）。

为什么稳定性判据能整体"搬家"：因果系统的 ROC 是最右极点右侧的半平面， 而"稳定"要求虚轴在 ROC 内，也就是所有极点 Re{p} < 0； 经 eσT 映射后左半平面变成单位圆内，判据就变成 "极点全部落在单位圆内"（第 13 章）。两条判据是同一句话的两种坐标写法。

第 4 步：为什么这个映射是"多对一"？顺带解释频谱的 2π 周期。

让 ω 增加 2π/T，角度 ωT 就增加 2π：

ej(ωT+2π) = ejωT · ej2π = ejωT

为什么：ej2π = 1，转一整圈回到原处。 所以高度为 2π/T 的一条水平条带就映满整张 z 平面，其余条带只是重复。 换到离散频率轴上，就是 X(ej(ω+2π)) = X(ejω)—— 第 7 章那条"频谱以 2π 为周期"的结论，本质是复平面上单位圆只有一圈。

切换时请专门盯这四处
  • 谱的横轴：是离散的 k（级数/DFT）还是连续的 ω？
  • 谱有没有周期：离散时间的两个变换（DTFT、以及 x[n] 周期延拓后的 DFT）一定以 2π 为周期。
  • 变量空间：一旦换成 s 平面或 z 平面，就会出现绿色的 ROC；前五个则完全没有 ROC 这回事。
  • 易错点：七个变换的"坑"高度雷同（忘 ROC、忘周期、忘 1/2π 或 1/N），说明它们真的是同一件事。

7. 跨变换的常见坑

坑 1：把"级数系数"和"变换频谱"直接对比

ak 是"第 k 次谐波的复振幅"，量纲是信号本身； X(jω) 是密度，量纲是"信号 × 时间"。两者由 T·ak = X(jkω0) 联系。混用会差一个 T。

坑 2：忘了离散谱以 N 为周期 / 连续谱以 2π 为周期

DTFS 只有 N 个独立谐波（ck 以 N 为周期）， DTFT 以 2π 为周期。写"唯一一段"时要指明范围（如 k=0…N−1、ω∈[−π,π)）。

坑 3：常数因子放错位置

CTFT/DTFT 的反变换才带 1/2π；DFT 的反变换带 1/N； 级数的正变换带 1/T 或 1/N。正变换一般不需要系数。

坑 4：拉氏/z 的答案不写 ROC

同一个 X(s) 或 X(z) 配不同 ROC，对应完全不同的信号。 ROC 是答案的一部分，不是备注。

坑 5：无条件地把 s = jω / z = e^{jω} 代进去

前提是虚轴（单位圆）落在 ROC 内。u(t) ⟷ 1/s（Re{s}>0） 就是标准反例：直接代会丢掉 πδ(ω)。

坑 6：把 s↔z 当成一一对应

z = esT 是多对一：ω 与 ω + 2π/T 映到同一个 z。多出来的那些"圈"就是混叠的来源。

坑 7：循环卷积当线性卷积用

DFT 做乘法等价于 循环卷积。 要等于线性卷积，必须把两个序列都补零到长度 ≥ N1+N2−1。

坑 8：以为 DFT 的 X[k] 就是"第 k 个频率"

X[k] 是 DTFT 在 ω=2πk/N 上的采样值。 分辨率由观测时长决定，补零只能加密采样点、不能让两条靠得很近的谱线分开。
