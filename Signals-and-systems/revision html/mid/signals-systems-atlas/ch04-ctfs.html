1. 这一章要回答的四个问题

先讲个故事，因为傅里叶级数不是从"信号"里长出来的，而是从热里长出来的。 1807 年，傅里叶（Joseph Fourier，1768–1830）向巴黎科学院提交了关于热传播的论文。 他研究的问题很具体：一根均匀的金属条，初始温度分布是 f(x)， 温度随时间怎么变？答案满足偏微分方程（热传导方程）

∂f∂t = κ ∂2f∂x2 (4-1)

κ 是导热系数。对一般的初始分布，这个方程没有解析解。但傅里叶发现： 如果初始分布能写成

f(x) = B0 + B1cos ω0x + B2cos 2ω0x + ⋯ + C1sin ω0x + C2sin 2ω0x + ⋯

也就是"一族正弦余弦的线性组合"，那么方程立刻可解（每一项按指数衰减，高频衰减得更快）。 于是他更进一步提出一个当时被认为很激进的主张： 任何一个周期函数都能展成三角函数的无穷级数。这就是 傅里叶级数 （Fourier series）。

最直观的一眼：方波是被正弦"叠"出来的

取一个方波。用 1 个正弦去近似——完全不像；用 2 个——有点意思了； 用 4 个、10 个、100 个——它越来越像矩形。 只要努力，弯的也可以掰成直的。这个"叠加"过程就是本页实验 1 要让你亲手拖的那根滑块。

当时有三条反对意见，恰好构成本页的主线： ① 等号成立吗（收敛性，见第 6、7 节）； ② 系数怎么算（计算量，见第 4 节，今天有计算机不成问题）； ③ 跳变附近为什么总在抖（吉布斯现象，见第 7 节，它至今仍在提醒你"用有限项表示无限细节"的代价）。

所以本章要回答四件事：

  1. 周期信号怎么拆成一族谐波（第 3 节）；
  2. 每个谐波的系数 ak 怎么算（第 4 节，一个积分）；
  3. 这个无穷和真的收敛到原信号吗、跳变处会怎样（第 6、7 节）；
  4. 拆开之后有什么用（第 9～12 节：性质、功率、滤波）。

2. 直觉：用 cos / sin 去"量"信号

先别看公式，先想一个更朴素的问题：怎么知道一个信号里"3 倍频"的成分有多少？

办法是"拿 3 倍频去量它"：把信号和 cos(3ω0t) 逐点相乘，再在一个周期上积分（平均）。 如果信号里真的含有 3 倍频成分，两者同号的部分多，乘积的平均值不为 0； 如果信号里没有 3 倍频，乘积正负各半，积分恰好抵消成 0。

和向量投影是同一件事

回忆线性代数：想知道向量 v 在 e1 方向上有多少， 就做内积 v·e1。因为基向量互相垂直（正交）， 所以问 e1 方向的分量时，别的方向不会来打扰。

函数也一样。定义两个信号的内积 ⟨f,g⟩ = ∫T f(t)g*(t)dt， 那么"用 g 去量 f"就是算 ⟨f,g⟩。 接下来要做的事只有一件：找到一族互相正交的 g，让每次测量只测到一个成分。

为什么偏偏选复指数当基

因为它们在任何一个周期上正交。取 φk(t) = ejkω0t， ω0 = 2π/T 叫 基波角频率。 则对任意整数 m, n：

∫T ej(m−n)ω0t dt = { T  (m = n)   ;   0  (m ≠ n) (4-2)

这种"自己和自己积不为 0、和别的积为 0"的性质，就叫 正交性 （orthogonality）。它的用处是：求哪个系数，就乘哪个基函数再积分，其它项自动消失。 第 4 节整个推导就是这句话的执行过程。

顺带一提：这正是第 3 章那套语言的另一面。第 3 章说"用复指数当输入，系统只乘一个复数"， 本章说"用复指数当基，信号能被唯一地拆开"。两件事合起来，频域分析才能成立。

3. 两种写法：三角形式与指数形式

三角形式（傅里叶当年的写法）

x(t) = B0 + ∞Σk=1 Bkcos(kω0t) + ∞Σk=1 Cksin(kω0t)

B0 是 直流分量（平均值）； Bk, Ck 都是实数。

指数形式（我们以后一直用这个）

x(t) = ∞Σk=−∞ ak ejkω0t

一个和号从 −∞ 到 ∞，把正频率和负频率统一处理； ak 一般是复数，叫 频谱系数。

推导：两种写法怎么互相换算

从指数形式出发，把第 k 项和 −k 项配对写在一起：

akejkω0t + a−ke−jkω0t

为什么可以这样配对：求和号从 −∞ 到 ∞，正负频率成对出现。当 x(t) 是实信号时， 由第 9 节的共轭性质有 a−k = ak*， 于是这两项互为共轭，加起来等于 2Re{}。

设 ak = (Bk − jCk)/2（Bk, Ck 为实数），代入并取实部：

(Bk − jCk)(cos kω0t + j sin kω0t) = (Bkcos kω0t + Cksin kω0t) + j(⋯)

为什么：把复数的乘法展开，实部正好是 Bkcos + Cksin。 再乘 2 取实部（两项相加），就还原成三角形式的那一项。

于是换算关系是：

a0 = B0,    ak = Bk − jCk2,    a−k = Bk + jCk2   (k ≥ 1)

为什么 k≥1 的系数要除以 2：三角形式里一个 cos 项在指数形式里被拆成了两项（+k 和 −k）， 幅度被平分成两半。所以指数形式的系数只有三角形式幅度的一半——这是最容易记错的一个 2 倍（见第 13 节坑 1）。

把 Bkcos + Cksin 合并成"单一余弦"更好读：

Bkcos θ + Cksin θ = Ak cos(θ + φk),    Ak = √(Bk2+Ck2) = 2|ak|

为什么：这是"两个同频正弦合成一个正弦"的三角恒等式（和角公式反过来用）。 所以第 k 次谐波的真实振幅是 2|ak|：画频谱时若画 |ak|，实际波形的振幅要乘 2。

4. 核心推导：ak 是怎么被"挑"出来的

现在做本章最重要的一件事。假设周期信号 x(t)（周期 T，ω0=2π/T） 可以写成一族谐波之和：

x(t) = ∞Σm=−∞ am ejmω0t (4-3)

求和指标故意写成 m（不写 k），因为马上要引入一个 k 来"挑项"。 目标：把 ak 单独解出来。

推导（点开/收起）：分析式 ak = (1/T)∫T x(t)e−jkω0tdt

第 1 步：两边同乘 e−jkω0t。

x(t) e−jkω0t = ∞Σm=−∞ am ejmω0t e−jkω0t = ∞Σm=−∞ am ej(m−k)ω0t

为什么乘这个：e−jkω0t 是"针对第 k 次谐波的探针"。 乘进去之后，原来指数是 jmω0t，现在变成 j(m−k)ω0t—— 这一步把"第 k 项"变成了常数项（m=k 时指数为 0），其余项仍带振荡。

第 2 步：两边在一个周期上积分（区间取任意长度为 T 的区间，记作 ∫T）。

∫T x(t) e−jkω0t dt = ∫T ∞Σm=−∞ am ej(m−k)ω0t dt = ∞Σm=−∞ am ∫T ej(m−k)ω0t dt

为什么可以把求和号提到积分号外面（交换次序）：因为对收敛的级数可以逐项积分 （级数在周期上一致收敛；你也可以理解为"先取前 N 项的部分和，积分后再让 N→∞"，两种做法极限相同）。 这是允许"逐项处理"的合法性依据，不是想当然。

第 3 步：算那个关键的积分（这就是正交性）。分两种情况。

用欧拉公式把它拆成实部和虚部：

∫T ej(m−k)ω0tdt = ∫T cos((m−k)ω0t) dt + j ∫T sin((m−k)ω0t) dt

为什么用欧拉公式：把复指数变成实三角函数后，"积分为 0"就能用"整周期内正弦余弦的正负面积相消"这个直观事实说清楚，不必依赖复数的几何直觉。

m ≠ k 时：cos((m−k)ω0t) 与 sin((m−k)ω0t) 的周期是 T|m−k|， 而这个积分区间长度恰好是 T = |m−k| 个整周期  ⟹  两项积分都是 0（正负面积相消）
m = k 时：指数变成 ej0 = 1，被积函数恒为 1  ⟹  积分 = T

为什么"整数个周期积分等于 0"：在长度等于周期的区间上，正弦余弦正半周与负半周的面积完全相等，代数和为零。 写成一行就是式 (4-2)：∫Tej(m−k)ω0tdt = T·δmk （δmk 是克罗内克 δ：m=k 时为 1，否则为 0）。

这就是"其它谐波项为 0"的那一步：右边无穷多项里，只有 m=k 那一项活下来。

第 4 步：右边只剩一项，解出 ak。

∫T x(t)e−jkω0tdt = ∞Σm=−∞ am · T·δmk = T ak
ak = 1T ∫T x(t) e−jkω0t dt (4-4)

为什么两边可以除以 T，以及为什么积分区间随便取：T 是正常数，直接除即可。 而"任意长度为 T 的区间都行"是因为整个被积函数（x 与复指数都是周期 T 的）以 T 为周期， 把区间左右平移不会改变积分值。实用上就取最方便的那个区间（例如 −T/2 到 T/2）。

结论：傅里叶级数对（周期信号专用）
综合式　x(t) = ∞Σk=−∞ akejkω0t
分析式　ak = 1T ∫T x(t)e−jkω0tdt

记号：x(t) ⟷ ak。 "分析"是拆开看清有哪些频率，"综合"是按系数把频率拼回去。 两个式子都只用到 x 在一个周期上的信息——这正是周期信号的特殊之处。

特殊情况 k = 0：

a0 = 1T ∫T x(t) dt = x(t) 在一个周期上的平均值

为什么：e0=1，积分退化成"求平均"。所以 a0 就是前面说的直流分量， 它和 k≠0 的公式形式一样，只是没有振荡。

这个推导的逻辑方向，别弄反

上面是"假设它能写成级数，那么系数必须等于式 (4-4)"。 也就是说，(4-4) 是必要条件。至于"这样算出来的系数代回去真的能还原 x(t) 吗"， 是收敛性问题，第 6 节用狄里赫利条件回答。这个顺序很重要： 先有唯一的候选系数，再问它是否收敛到原信号。

5. 完整算例：方波的谐波系数

方波是傅里叶级数的"Hello World"。它同时是间断信号，所以能顺便把收敛与吉布斯问题一起带出来。 定义（周期 T，ω0 = 2π/T）：

x(t) = {  1,  |t| < T1      0,  T1 < |t| < T/2    （在长度 T 的区间内定义，然后周期延拓）

习惯上用占空比 占空比 d = 2T1/T 描述它。下面这个实验台里，方波取 ±1 两个电平（教材常见约定）， 所以 a0 = 2d−1；若改用 0/1 电平，则所有 ak 减半、a0 = d。 这层区别请留意，第 13 节还会再点一次。

推导：方波的 ak（含 a0、偶数谐波为 0 的来历）

选对称积分区间 [−T/2, T/2]，方波在其中只有 |t|<T1 处不为 0：

ak = 1T ∫+T1−T1 e−jkω0tdt

为什么可以只积 [−T1,T1]：其余区间上被积函数是 0（乘 0 还是 0），积分可分段相加。 这就是"选区间要挑方便的那个"的实际用处。

先算 k = 0：

a0 = 1T ∫+T1−T1 1·dt = 2T1T = d

为什么合理：a0 是平均值，等于"一个周期里有多长时间等于 1"，正是占空比。 （若取 ±1 电平，平均值就是 d·1 + (1−d)·(−1) = 2d−1。）

再算 k ≠ 0：直接积指数函数，

ak = 1T [ e−jkω0t−jkω0 ]−T1+T1 = 1T · ejkω0T1 − e−jkω0T1jkω0 = 2 sin(kω0T1)T kω0

为什么分子会变成 2j·sin：用 ejA − e−jA = 2j sin A （欧拉公式两式相减），分母的 j 正好约掉， 所以结果自动是实数——这跟"方波是偶函数、其系数应为实偶"是同一件事（见第 9 节）。

再用 ω0T = 2π 与 ω0T1 = πd 化简：

ak = sin(kπd)kπ,    k ≠ 0（0/1 电平）；   ak = 2 sin(kπd)kπ（±1 电平） (4-5)

为什么 ω0T1 = πd：T1 = dT/2， 所以 ω0T1 = (2π/T)(dT/2) = πd。

当 d = 0.5 时（对称方波）：ak = sin(kπ/2)/(kπ)。

因为 sin(kπ/2) 在 k 为偶数时等于 0、在 k 为奇数时等于 (−1)(k−1)/2：

a0 = 0,   a±1 = ±1π,   a±3 = ∓13π,   a±5 = ±15π,  …   （偶次谐波全为 0）

为什么偶次谐波为 0：偶次谐波在方波的正半周与负半周上各占半个周期，被积函数正负相消。 也可以从式 (4-5) 看出：sin(kπ/2)=0（k 偶数）。这解释了"方波听起来明亮刺耳"——它只含奇次高频。

6. 有限项最优与收敛条件

实用上只能取有限项：xN(t) = Σk=−NN ckejkω0t。 系数 ck 怎么选最好？答案出人意料地干脆：就取傅里叶系数。

推导：为什么"截断的傅里叶级数"是能量意义下最佳的 N 项近似

定义误差能量（在一个周期上）：

EN = ∫T |x(t) − xN(t)|2 dt

为什么用"能量"当误差标准而不是"逐点最大误差"：逐点最大误差在跳变点附近无法压到 0（第 7 节的吉布斯）。 而能量是物理上真正有意义的量（第 1 章），并且能量意义下误差确实能趋于 0。这是"最小二乘"思想在函数上的版本。

把被积函数展开成四项并逐项积分：

|x − xN|2 = |x|2 − x xN* − x* xN + |xN|2

为什么：|z|² = zz*，把 z = x − xN 代进去展开即可。

用正交性算交叉项（这又是"其它项为 0"）：

∫T x xN* dt = NΣk=−N ak ck* · T,     ∫T |xN|2 dt = NΣk=−N |ck|2 · T

为什么每一项只剩同名项：把 x = Σmamejmω0t 与 xN* = Σkck*e−jkω0t 相乘， 只有 m=k 的那一项积分不为 0（式 4-2），其余全部消失。

于是误差能量可以"配方"成一个完全平方：

EN = ∫T|x|2dt − TNΣk=−N|ak|2 + TNΣk=−N|ck − ak|2

为什么可以这样配：把上一步的两式代回，得到 ∫|x|²dt − TΣ(akck*+ak*ck) + TΣ|ck|²， 再在中间加减 TΣ|ak|²， 利用 |ck−ak|² = |ck|² − ckak* − ck*ak + |ak|² 合并同类项。

第三项是"平方和"，恒 ≥ 0，最小值 0 当且仅当每一项都为 0：

ck = ak  ⟹  EN 取最小

为什么这个结论重要：它把"求级数系数"变成了"做投影"—— 任何其他系数选择都不会更好。这也顺便给出了 Bessel 不等式 TΣ|k|≤N|ak|² ≤ ∫T|x|²dt， 令 N→∞ 取等号就是第 10 节的 Parseval 等式。

收敛的保证：狄里赫利条件

只要信号在一个周期内满足下面三条（实际工程信号几乎都满足），傅里叶级数就收敛：

  • 条件 1：绝对可积，∫T|x(t)|dt < ∞（保证每个 ak 有限）；
  • 条件 2：在任何有限区间内，极大值与极小值的个数有限（不许无穷次振荡）；
  • 条件 3：在任何有限区间内，间断点个数有限，且每个间断处的取值是有限的。

这叫 狄里赫利条件（Dirichlet conditions）。

收敛的三层含义，别混： ① 在 x(t) 连续的点上，级数逐点收敛到 x(t)； ② 在间断点处，级数收敛到左右极限的平均值（方波的跳变点收敛到 0，正是 ±1 的平均）； ③ 无论有没有间断点，误差能量 EN → 0（均方收敛）—— 所以从 LTI 系统（只对能量敏感）的角度看，两者没有区别。

7. 吉布斯现象：那个不消失的 9%

1898 年，美国物理学家迈克尔逊（Albert Michelson）造了一台"谐波分析仪"，能对任意周期信号算出前 80 项的部分和。 他试了很多函数，结果都和预期一致。但试到方波时，他看到了怪事： 部分和在跳变点附近上下抖动，而且增加项数时，抖动的高度竟然不变。 他以为仪器坏了，写信给数学家吉布斯（Josiah Gibbs），后者在 1899 年给出了解释。

吉布斯现象（Gibbs phenomenon）

用截断的傅里叶级数去逼近有跳变的信号时，在跳变点附近必然出现过冲（overshoot）与振铃（ripple）。 对于高度为 1 的跳变，部分和的最大值约为 1.09， 也就是过冲约为跳变高度的 9%，而且与项数 N 无关—— N 增大只是把波纹压缩到离跳变点更近的地方。

怎么理解（这是本节最该带走的一句话）： 跳变意味着信号在该点"无限快"地变化，要精确表示它需要无穷多的高频成分。 你砍掉 |k|>N 之后，缺的正是"把尖角磨平"的能力， 于是波形只能"冲过头再拉回来"。N 越大，这个"冲过头"发生的位置离跳变点越近，但幅度不变。 注意这不与第 6 节矛盾：误差能量仍然 →0（过冲占的宽度在变窄）， 只是"逐点最大误差"不会趋于 0。

8. 实验 1（核心）：谐波数、波形与吉布斯

这个实验台把第 5 节算出来的系数真的加起来画出来。左边是时域部分和，右边是它对应的离散线谱。 读数栏里的"实测过冲"是把一个周期扫一遍取最大值算出来的——不是写死的数字。

建议这样玩（每一步都对应一个知识点）
  • 方波，N 从 1 拖到 61：看跳变处的过冲读数怎么稳定在 8.9% 左右再也不降——这就是吉布斯。
  • 切到三角波：读数里过冲变成 0%，而且几条谐波就能贴得很紧——因为它没有跳变（第 11 节解释 1/k²）。
  • 切到锯齿波，再切回方波：比较线谱衰减（锯齿每根都有、方波只有奇次）。
  • 方波，改占空比 d：线谱的零点位置移动，偶次谐波不再为 0——这正是 sin(kπd) 的零点在跑。

线谱画的是 |ak|（指数形式系数）。要还原波形振幅需乘 2， 所以图上 |a1| = 0.637 对应波形里振幅 1.27 的基波。

关键性质的证明（时移 / 频移 / 微分 / 相乘 / 共轭对称）

(a) 时移：x(t−t0) ⟷ e−jkω0t0ak

bk = 1T ∫T x(t−t0)e−jkω0tdt  令 τ = t − t0，dt = dτ  = 1T ∫T x(τ)e−jkω0(τ+t0)dτ
= e−jkω0t0 · 1T ∫T x(τ)e−jkω0τdτ = e−jkω0t0ak

为什么换元后积分区间长度还是 T：t 跑遍任意长度 T 的区间，τ=t−t0 也跑遍一个长度 T 的区间； 而被积函数以 T 为周期，所以换成哪个长度 T 的区间都一样。e−jkω0t0 与 τ 无关，可以提出。 取模长得 |bk|=|ak|：时移不改幅度谱。

(b) 频移：ejMω0tx(t) ⟷ ak−M

bk = 1T ∫T x(t)ejMω0te−jkω0tdt = 1T ∫T x(t)e−j(k−M)ω0tdt = ak−M

为什么：两个指数合并成 e−j(k−M)ω0t， 而按定义 a 的下标就是指数里的那个整数，所以结果是 ak−M—— 等于把整条线谱向右搬 M 格。这是调制（第 11 章）的数学根源。

(c) 微分：dx/dt ⟷ jkω0ak（用分部积分）

bk = 1T ∫T x′(t)e−jkω0tdt = 1T [x(t)e−jkω0t]T + jkω0T ∫T x(t)e−jkω0tdt

为什么边界项 [x e−jkω0t]T = 0： 积分区间取一个完整周期，x 是周期 T 的、e−jkω0t 也是周期 T 的， 所以上下限处的值完全相等，相减为 0。剩下第二项正是 jkω0ak。

读法：|jkω0| = kω0 随 k 线性增长， 所以微分对高频"加权"——这就是图像处理里用微分算子增强边缘、以及方波微分后会出现尖脉冲的原因。

(d) 相乘：x(t)y(t) ⟷ hk = Σl albk−l

把两个级数直接相乘，再按频率归类：

x(t)y(t) = ( Σl alejlω0t) ( Σm bmejmω0t) = Σk ( Σl albk−l)ejkω0t

为什么按 l+m=k 归类：两个指数相乘时指数相加，ejlω0tejmω0t = ej(l+m)ω0t。 令 m = k−l，把所有产生同一频率 kω0 的项加起来即可。 右边的求和形式正是离散卷积（第 2 章的求和是"翻转平移相乘"，这里完全一样）， 所以"时域相乘 ↔ 频域（系数序列）卷积"。

(e) 共轭对称：x 为实信号时 a−k = ak*

a−k = 1T ∫T x(t)e+jkω0tdt = [ 1T ∫T x(t)e−jkω0tdt ]* = ak*

为什么能这样取共轭：因为 x(t) 是实函数，x = x*， 所以对积分整体取共轭时，只有复指数被共轭（指数上的符号翻转）。 推论：|a−k|=|ak|（幅度谱偶对称）、∠a−k=−∠ak（相位谱奇对称）。 再结合时间反转性质：若 x 还是偶函数，则 ak=a−k=ak*， 即系数为实数——这就是方波系数全是实数的原因。

10. Parseval：各谐波功率之和

推导：平均功率 = Σ|ak|2

从定义出发（周期信号的平均功率，第 1 章）：

P = 1T ∫T |x(t)|2dt = 1T ∫T x(t)x*(t)dt

为什么写成 xx*：|z|² = zz*，这样就能把两个级数代进去相乘了。

把 x = Σmamejmω0t 与 x* = Σkak*e−jkω0t 代进去：

P = 1T Σk Σm amak* ∫T ej(m−k)ω0tdt

为什么可以把两个求和号都提到积分外：与第 4 节第 2 步同样的理由——级数可逐项积分。

积分又是正交性：只有 m=k 时为 T，其余为 0。于是

P = 1T Σk |ak|2 · T = ∞Σk=−∞ |ak|2 (4-6)

为什么 |ak|2 就叫"第 k 次谐波的平均功率"： 单个复指数成分 akejkω0t 的模长恒为 |ak|， 所以它的功率（模平方的平均）就是 |ak|2。 Parseval 说的就是：总功率等于各次谐波功率之和，一块钱都没丢。

三个可以自己验的例子（±1 电平）：

  • 方波 d=0.5：每点都等于 ±1，所以 P = 1；而 Σ|ak|2 = 2Σk 奇(2/(kπ))2 = 8/π2 · π2/8 = 1 ✓ （用了 Σk 奇1/k2 = π2/8）。
  • 三角波（峰值 ±1）：P = (1/T)∫(1−4|t|/T)2dt = 1/3； 而 Σ|ak|2 = 2Σk 奇(4/(π2k2))2 = 1/3 ✓ （用了 Σk 奇1/k4 = π4/96）。
  • 锯齿波（峰值 ±1）：P = 1/3，Σ|ak|2 = 2Σk≥1(1/(kπ))2 = 1/3 ✓ （用了 Σ1/k2 = π2/6）。

为什么这些级数和要对得上：它们本身就是 Parseval 等式的两种算法。 实验 1 里切换波形时看到的"线谱总面积"其实就是这个功率；你也可以把 N 加大，看部分和往 1 或 1/3 靠。

11. 方波 1/k 与三角波 1/k²：衰减速度从哪来

第 5 节得到方波的 |ak| ∝ 1/k；实验里切到三角波你会发现它掉得快得多，是 1/k2。这不是巧合，而是"信号越光滑，高频越少"这条普遍规律的第一个例子。

推导：为什么"连续但导数有跳变"意味着 1/k²

对方波的系数公式做分部积分（把导数"移"过去）：

ak = 1T ∫T x(t)e−jkω0tdt = 1jkω0T ∫T x′(t)e−jkω0tdt   （当 x 连续且周期时）

为什么这一步成立：这就是第 9 节性质 (c) 的反用——把 bk=jkω0ak 里的 b 换成"导数信号的系数"即可。前提是那一步的边界项为 0，也就是 x 本身连续（没有跳变）。

所以：

  • 若 x 有跳变：上式的分部积分产生一个不为 0 的边界项，它正比于1/(kω0)， 所以 ak ∝ 1/k（方波、锯齿波都属这一类）。
  • 若 x 连续、但 x′ 有跳变：第一次分部积分边界项为 0，得到 ak = bk/(jkω0)， 而 bk ∝ 1/k，于是 ak ∝ 1/k2（三角波）。
  • 类推：每"多一阶连续"就多一个 1/k。极端的例子是 cos 本身——无穷光滑，于是只有一个 k=1 的系数非零，其余全为 0。

为什么这件事重要：它给出了一条"看波形猜带宽"的捷径。 同样要求误差能量降到 1%，方波要留的谐波数远多于三角波；工程上"信号有多难传"直接取决于它的光滑程度。

用实验台的数字对照（±1 电平，第 k 次谐波的真实振幅 Ak = 2|ak|）：

波形跳变情况振幅衰减A1A3A5要逼近到"看不出差别"需要
方波有跳变（高度 2）∝ 1/k（仅奇次）1.2730.4240.255很多项，且跳变处永远有 9% 过冲
锯齿波有跳变（高度 2）∝ 1/k（全部 k）0.6370.2120.127很多项；与方波同速衰减，只是奇偶都占
三角波连续，导数跳变∝ 1/k2（仅奇次）0.8110.0900.032少数几项就很像；没有过冲

数字来源：方波 Ak=4/(kπ)（奇 k）；锯齿 Ak=2/(kπ)； 三角 Ak=8/(π2k2)（奇 k）。把它们代进去就能自己复核。

12. 实验 2：让每个谐波各自乘 H(jkω0)

第 3 章的核心结论在这里兑现：LTI 系统对每个谐波单独动手—— 输入的 ak 变成 akH(jkω0)， 谐波之间互不干扰。所以"滤波"在频域里就是"逐条谱线乘一个复数"。

x(t) = a0 + ∞Σk=1 Akcos(kω0t + φk)  ⟶  y(t) = a0H(0) + ∞Σk=1 Ak|H(jkω0)| cos(kω0t + φk + ∠H(jkω0))
看懂了什么

把截止频率压低：高次谐波被清掉，方波的"角"变圆——这正是音频里把高音调低的效果。 切换成微分器：每条谱线被乘上 jkω0，高频被放大， 方波变成一串尖脉冲（跳变处导数最大）。 读数栏的"输出功率占比"用 Parseval 算出来：Σ|akHk|2 / Σ|ak|2。

13. 常见坑

坑 1：三角形式与指数形式的系数差 2 倍

Ak = 2|ak|（k ≥ 1），而 B0 = a0 不乘 2。 原因：指数形式把每个余弦拆成正负两个频率，幅度被平分。抄公式前先确认书里用的是哪种形式。

坑 2：忘掉分析式前面的 1/T

综合式没有系数，分析式有 1/T。漏掉它，所有谱线都会被放大 T 倍，Parseval 也对不上。

坑 3：把 ω0 和 T 搞混

ω0 = 2π/T。周期越长，基频越小、谱线越密。 把 T 拉大时线谱会挤在一起——第 6 章正是从这里出发把级数变成变换的。

坑 4：以为吉布斯现象说明级数不收敛

它收敛得很规矩：连续点逐点收敛，跳变点收敛到左右极限平均值，误差能量趋于 0。 过冲只是"有限项"的代价，与收敛性不矛盾。

坑 5：对方波套用 ak = sin(kπd)/(kπ)

这要看电平定义：0/1 方波用 sin(kπd)/(kπ)、a0=d； ±1 方波用 2sin(kπd)/(kπ)、a0=2d−1。 本页实验台用 ±1（与第 6 章的 SSC.squareCoeff 一致），画的是 |ak|=Ak/2。

坑 6：实信号只看正频率就下结论

实信号的系数满足 a−k=ak*，负频率那一半是"镜像"， 但它在能量（Parseval 求和）与相乘性质里都要算进去。只在"画幅度谱"时才可以只画 k≥0。
