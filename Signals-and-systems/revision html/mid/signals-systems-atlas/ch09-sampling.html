1. 一个让人不安的问题

你的手机录下一段钢琴声，存成 44100 个数每秒的数组。声音本来是连续变化的空气压强——两个采样点之间那段时间里， 压强究竟怎么走的？手机没存。那播出来为什么听不出丢东西？

反过来更让人不安：如果采样点很稀，会不会有一堆完全不同的信号，采样结果完全一样？ 答案是会。下面这个事实必须先接受：

只给一串采样点，能不能唯一确定原信号？

不能。比如 x1(t) = 0 和 x2(t) = sin(2π·5t)，在 t = 0, 1, 2, … 秒上取值全是 0。 无穷多个不同的连续信号可以有完全相同的采样值。

所以"采样"这件事，如果不对信号加限制，是一定会丢信息的。采样定理要做的事不是"反驳"这句话， 而是找出什么样的信号、以多快的速度采样，才能保证不丢。 那个限制条件就是：信号必须是带限的（band-limited）。

直觉先行：采样为什么能行

关键在于频率只有有限个"名额"。如果信号里最高的频率成分是 ωM， 那么频谱就集中在 [−ωM, ωM] 这一小段里。

采样会在频域造出这个频谱的无穷多份副本，一份接一份地排下去，相邻副本中心隔开 ωs（采样角频率）。只要 ωs 足够大， 相邻两份就不会碰到一起；不碰，就不会混。于是我们可以用一把"剪刀"（理想低通滤波器） 把原信号那一份单独剪下来，其余全部丢掉——原信号就完整回来了。

2. 采样 = 乘冲激串

要把"每 T 秒取一个值"这件事写成公式，需要一件工具： T 间隔的冲激串。T 叫 采样周期（sampling period）， 它的倒数就是采样率（sampling frequency）：

fs = 1T  (Hz),     ωs = 2πT  (rad/s) (9-1)
p(t) = ∞Σn=−∞ δ(t − nT) (9-2)

这个 p(t) 是一串等间距的冲激串（impulse train）—— 想象一把无限长的梳子，齿距 T。用它乘上信号，就得到采样：

xp(t) = x(t)·p(t) = ∞Σn=−∞ x(nT) δ(t − nT) (9-3)

这一步用的是冲激的筛选性质：x(t)δ(t−nT) = x(nT)δ(t−nT)， 即"冲激只挑出它所在那一刻的函数值"。于是 xp(t) 是一串冲激， 第 n 个冲激的"面积"就是第 n 个采样值 x(nT)。 术语上这叫冲激串采样（impulse-train sampling）。

别被"冲激"吓到

真实电路当然不会产生数学上的冲激（那需要无穷大的瞬时能量）。 这只是建模：我们关心的是"哪些时刻的值被保留了"，冲激串是最方便的记号。 实际实现里的"零阶保持"（zero-order hold）会在第 13 节单独讲，它和冲激串采样的差别是明确的、可以修的。

3. 完整推导：频谱为什么要周期延拓

这是本章的核心，也是全站最值得逐字读的一段推导。它只用两件你已经有的东西： 冲激串的傅里叶变换（第 6 章）和时域相乘 = 频域卷积（第 6 章）。

推导（点开/收起）：时域乘冲激串 → 频域卷积 → 频谱以 ωs 为周期延拓叠加

第 1 步：写出冲激串的频谱 P(jω)。

p(t) 是以 T 为周期的周期信号，基频正是 ωs = 2π/T。周期信号的傅里叶变换是一串冲激（第 6 章式 (6-?) 那一类结论）， 对 p(t) 算出来是：

P(jω) = 2πT ∞Σk=−∞ δ(ω − kωs) (9-4)

为什么：时域上间隔 T 的一串冲激，频域上就是间隔 ωs=2π/T 的一串冲激，每个的面积是 2π/T。这是"时域越窄（T 越小），频域越宽（冲激隔得越开）"的直接体现；严格的算法是把 p(t) 写成傅里叶级数 p(t) = (1/T)Σejkωst，逐项变换后每项给出一个 2πδ(ω−kωs)，合并系数即得 2π/T。

第 2 步：时域相乘 → 频域卷积。

第 6 章的相乘性质告诉我们：x(t)·p(t) 的频谱是 (1/2π) 倍的 X(jω) 与 P(jω) 的卷积：

Xp(jω) = 12π ∫∞−∞ X(jθ) P(j(ω−θ)) dθ (9-5)

为什么相乘会变成卷积：这是傅里叶变换的对偶性质之一（第 6 章性质表："时域相乘 = 频域卷积"，且必须带 1/2π）。它成立的原因是两边的 e−jωt 探针在时域乘积展开后会把两个频率"捆"在一起。

第 3 步：把 (9-4) 代进卷积，用"卷 δ 就是平移"把积分算掉。

核心事实：X(jω) ∗ δ(ω − ω0) = X(j(ω−ω0))—— 与一个位于 ω0 的冲激做卷积，等于把整个 X 平移 ω0。 于是求和与积分交换，逐项平移：

Xp(jω) = 12π ∞Σk=−∞ 2πT X(j(ω − kωs)) = 1T ∞Σk=−∞ X(j(ω − kωs)) (9-6)

为什么能交换求和与积分：P(jω) 是一串冲激（广义函数），逐项卷积的严格表述是"卷积的线性性"——卷积对相加的每一项分别做再相加，这是卷积定义式里积分线性带来的，不需要额外条件。系数 (1/2π)·(2π/T) = 1/T 就是全部的缩放。

第 4 步：读懂 (9-6) 说的是什么。

① 形状没变，只是被复制了无穷多份。 Xp(jω) 是原频谱 X(jω) 在频率轴上每隔 ωs 复制一份、 再整体乘 1/T 得到的（k=0 那一份是原信号本身）。 这个"隔 ωs 复制一份"的动作，就叫周期延拓（periodic replication）。

为什么"周期延拓"这个词很贴切：k 取遍所有整数意味着副本排在 …, −2ωs, −ωs, 0, ωs, 2ωs, …， 整体当然以 ωs 为周期：Xp(j(ω+ωs)) = Xp(jω)。 "时域采样 → 频域周期化"，这就是整个采样理论的第一句话。

到这一步，结论已经很硬了

我们不需要任何新假设，就从"采样 = 乘冲激串"推出了 采样信号的频谱 = 原频谱的周期延拓叠加（缩放 1/T）。 接下来唯一的问题就是：这些副本会不会互相重叠？

4. 采样定理：条件的由来

看图说话最清楚。设 X(jω) 只在 |ω| ≤ ωM 内非零 （ωM 就是信号的最高角频率）。 那么第 k 份副本占据的频率区间是

[kωs − ωM,   kωs + ωM]

第 0 份占据 [−ωM, ωM]，第 1 份占据 [ωs−ωM, ωs+ωM]。 两份不重叠的条件是第 0 份的右端不超过第 1 份的左端：

ωM ≤ ωs − ωM   ⟺   ωs ≥ 2ωM (9-7)

严格版本要求 ωs > 2ωM（临界时两份在 ω=ωM 处恰好相切， 教科书通常把等号算作"临界满足"，实做工程时会留余量）。以 Hz 为单位就是 fs > 2fM。

采样定理（Sampling Theorem，也叫 Nyquist–Shannon 定理）

设 x(t) 是带限信号，X(jω) = 0 当 |ω| > ωM。 若采样角频率满足

ωs > 2ωM

则 x(t) 被它的样本 x(nT)（n = 0, ±1, ±2, …）唯一确定， 并且可以如下精确重建：把这串样本做成冲激串，通过一个增益为 T、截止频率在 ωM 与 ωs−ωM 之间的理想低通滤波器， 输出的就是原来的 x(t)。

奈奎斯特率（Nyquist rate）

2fM 或 2ωM。 它是信号自己的属性，只跟信号有关、与你的采样器无关。 "这个信号的奈奎斯特率是 20 kHz"意思是：至少要 20 kHz 采样才不丢。

奈奎斯特频率（Nyquist frequency）

fs/2，也叫折叠频率（folding frequency）。 它是采样器的属性：在这个采样率下，你最多能"看清"到 fs/2 这么高的频率； 再高的成分会被折下来冒充低频。

这两个词必须分清

奈奎斯特率 = 2fM（信号说了算，是"需求"）； 奈奎斯特频率 = fs/2（采样器说了算，是"能力"）。 不混叠的条件就是"能力 ≥ 需求"：fs/2 ≥ fM。 考试里最常见的错法就是把这两个名字里的数字混着用。

5. 动手：原信号、采样点、与"混叠后的表观波形"

下面这个实验台是全站最重要的演示之一。它把三样东西画在同一张图上： 原来的正弦（蓝）、采样点（红点）、以及采样点"看起来像"的那条低频正弦（红虚线）。 慢慢把 fs 往下拖，你会看到红虚线停在一个较低的频率上不动， 而蓝线越来越密——到某一点，两者再也对不上。

务必盯住的一瞬间

当 fs 降到 2f 以下的那一刻， 红虚线（表观频率）突然与蓝线（真实频率）分道扬镳。 分道扬镳之后，采样点完全无法区分这两条曲线——它们在这串采样点上逐点相等。 这就是混叠：高频成分伪装成了低频成分，而且这个伪装在采样之后无法拆穿。

上图给你的是时域直觉，这张图给你频域的证据。它画出 (9-6) 式里那一串周期延拓的副本， 并用阴影标出奈奎斯特频率 ±fs/2 之间的"安全区"。

读图规则

灰色竖线是理想低通滤波器（重建滤波器）的边界，落在 ±fs/2 处。 重建时只保留这条边界以内的东西。

蓝色竖线是原信号的分量（在 ±f）。 红色竖线是周期延拓产生的副本（在 ±f + k fs）。 当 f > fs/2 时，落在安全区里的"蓝色"竖线其实已经不是原来那一根了—— 它被红色副本顶替，位置跑到了 fs − f。这就是混叠的频域样子。

7. 混叠频率怎么算

工程上需要的不是"发生了混叠"，而是"混成了什么"——采样之后我读到的频率是多少。 给你一个可以直接用的算法。

推导 + 算法：混叠表观频率 ωalias = |ω − kωs| 取最小

第 1 步：从一个具体的正弦开始。

设 x(t) = cos(ω0t)，以周期 T 采样，样本是

x(nT) = cos(ω0nT) = cos(nΩ0),    Ω0 = ω0T

为什么引入 Ω0：离散序列的"频率"只能用每样本转多少弧度来描述，这个量叫数字频率，它把时间单位 T 吸收掉了。Ω0 = 2πf0/fs。

第 2 步：关键的一步——余弦对 Ω 是"以 2π 为周期"的。

因为 cos(n(Ω0 + 2πk)) = cos(nΩ0 + 2πkn) = cos(nΩ0) （n、k 都是整数，2πkn 是 2π 的整数倍，余弦不变）。 所以数字频率 Ω0 与 Ω0+2πk 产生完全相同的样本。

为什么这直接给出混叠：把 Ω = ωT 代回去，ω0 与 ω0 + 2πk/T = ω0 + kωs 给出的样本一模一样。 也就是说，频率为 ω0 与频率为 ω0+kωs 的信号，在采样后完全无法区分。 这是混叠的数学本质，也是"频率轴被折叠"的来源。

第 3 步：选一个"落在安全区里"的代表。

既然 ω0 + kωs（k 取所有整数）全都等价， 我们就能从这一族频率里挑出离 0 最近的那一个来表示"表观频率"， 它一定落在 [−ωs/2, ωs/2] 内：

ωalias = mink∈ℤ |ω0 − kωs|   ,   以 Hz 写：  falias = mink∈ℤ |f0 − k fs| (9-8)

为什么取最小的那个：表观频率一定是"能产生同样样本的频率里最低的那个"。 因为重建滤波器只保留 fs/2 以内的成分，所以滤波器输出的那条正弦， 其频率必然是这个范围内、且与采样点相容的唯一值。用式子说：所有等价频率里只有一个落在安全区内，就是它。

第 4 步：等价的实用算法（随手可在脑子里算）。

把 f0 逐步加减 fs，直到落进 [0, fs/2]：

fr = f0 mod fs  (结果取到 [0, fs)),    falias = min(fr, fs − fr)

为什么这叫"折叠"：把长条纸上的频率刻度按 fs/2 为折痕反复对折， 所有频率最终都落到 [0, fs/2] 上。所以 fs/2 又叫折叠频率。 这个算法和 (9-8) 完全等价，但更适合口算。

别忘了幅度和相位也会被改

频率被折回来时，余弦可能被整体反转（等价于相位加 π），也就是系数 Δ = ±1： f 落在 (fs/2, fs) 时该分量取 负号， 落在 (fs, 3fs/2) 时取正号，如此交替。 所以混叠不只改频率，还可能把波形的相位翻个身——这就是为什么混叠的音频听起来不只是"音调变低"，而是失真、发糊。

8. 理想重建：sinc 内插公式的完整推导

定理只说"存在一个低通滤波器能把信号恢复回来"，还没说这个滤波器在时域长什么样。 把它算出来，就得到工程手册里那个著名的 sinc 内插公式。

推导（点开/收起）：从"理想低通滤波器"到 x(t) = Σ x(nT)·sinc((t−nT)/T)

第 1 步：确定重建滤波器的两个参数。

从 (9-6) 看到，采样把频谱乘上了 1/T，所以滤波器必须带增益 T 才能把幅度还原回去。 截止频率呢？必须大于 ωM（否则把信号自己的高频成分也砍掉了）， 同时小于 ωs − ωM（否则会把相邻副本吃进来）。 最常用的自然选择是取两者正中间：

ωc = ωs2 = πT   （即 fc = fs/2）

为什么可以取 ωs/2：因为条件是 ωM ≤ ωs/2 ≤ ωs−ωM， 中间这个值恰好同时满足"大于等于 ωM"与"小于等于 ωs−ωM"（临界时取等号）。 于是重建滤波器就是：H(jω) = T（|ω| < π/T），否则 0。

第 2 步：查表求这个滤波器的冲激响应 h(t)。

用第 6 章的变换对：理想低通 rect(ω/2W) ⟷ sin(Wt)/(πt)。放到我们这里，W = π/T，再乘增益 T：

h(t) = T · sin(πt/T)πt/T · 1T …

整理干净（把 T 与分母上的 1/T 合并）：

h(t) = sin(πt/T)πt/T = sincπ(t/T) (9-9)

为什么这里出现的是 sincπ(u) = sin(πu)/(πu) 而不是 sin u/u： 因为截止频率里带着 π/T。两种 sinc 定义的差别就在这个 π 上（第 6 章"坑 2"提过）， 采样定理的公式用 sin(πu)/(πu) 这一支最省事，因为它在整数点上正好是 0 或 1： sincπ(m) = 0（m 为非零整数）、sincπ(0) = 1，这个性质下一步要用。

第 3 步：时域卷积，得到内插公式。

重建就是把采样冲激串 xp(t) 送进这个滤波器，时域上是卷积：

xr(t) = xp(t) ∗ h(t) = ∫∞−∞ ∞Σn=−∞ x(nT)δ(τ−nT) · h(t−τ) dτ

用冲激的筛选性质把积分吃掉（

xr(t) = ∞Σn=−∞ x(nT) h(t − nT) = ∞Σn=−∞ x(nT) · sin(π(t−nT)/T)π(t−nT)/T (9-10)

为什么能直接把 τ 换成 nT：因为被积函数里只有 δ(τ−nT) 在 τ=nT 处非零， 积分等于把 τ 代入 nT（筛选性质），求和号只是把这些项加起来。

第 4 步：验证 (9-10) 真的是"内插"——它在采样点上必须回到原值。

取 t = mT（一个采样时刻），代入 (9-10)：

xr(mT) = ∞Σn=−∞ x(nT) · sincπ(m − n) = x(mT)

为什么：当 n = m 时 sincπ(0)=1 保留了 x(mT)； 当 n ≠ m 时 m−n 是非零整数，sincπ 为 0，其它样本"不许插嘴"。 每个样本只在自己那一刻说话——这就是内插（interpolation）：用一个已知在所有整数点为 0、在 0 点为 1 的函数， 把离散点连成连续曲线。

这一步的物理含义

重建不是"猜测"两个采样点之间发生了什么，而是由带限条件唯一地反推出来。 (9-10) 里的每一项都是一个 sincπ 波纹， 第 n 项的波纹在其它所有采样点上正好为 0，只在自己那个点上"顶起来"到样本值。 把所有波纹叠加，就得到一条唯一通过全部样本、且最高频率不超过 fs/2 的连续曲线。

9. 动手：sinc 内插重建，看曲线什么时候崩

这个实验台直接把 (9-10) 算给你看。灰虚线是真实信号，红点是采样值，青色曲线是 sinc 内插重建的结果。

请务必亲自试的一步

把 fs 从高往低拖，穿过 2f。 穿过之前：青线几乎和灰虚线重合（之所以不是完全重合，是因为实验里只用了有限多项 sinc，属于计算截断，不是理论误差）。 穿过之后：青线依然精准地穿过每一个红点，但与灰虚线彻底分家—— 它变成了一条低频波。这正是要记住的画面：重建算法从不报错，它总是给你一条完美通过所有样本的曲线，只是那条曲线可能不是你原来的信号。

10. 从冲激串到数字序列：C/D 与 D/C

(9-3) 得到的 xp(t) 还是一串带时间标签的冲激。计算机要的是纯粹的数组 xd[n] = xc(nT)：第 n 个元素、没有时间单位。 这一步叫C/D 转换（continuous-to-discrete，连续到离散）， 物理上就是 A/D 转换器。反方向的D/C 转换（discrete-to-continuous，离散到连续） 是 D/A 转换器 + 重建滤波器。

这一步在频域只做了一件小事：把频率轴"除以 T"

从冲激串换成数组，数学上就是把时间轴 t = nT 重新标记成 n， 相当于把时间轴压缩了 1/T 倍。由第 6 章的尺度性质（时域压缩 → 频域展宽）， 频域频率轴相应地被乘以 T：

Ω = ωT (9-11)

这就是"连续频率 ω（rad/s）"与"数字频率 Ω（rad/样本）"之间的换算。 ωs = 2π/T 映射成 Ω = 2π， 所以离散谱天然以 2π 为周期（第 7 章的结论在这里得到了物理解释）； 而 ωs/2 映射成 π，所以离散序列里 Ω = π 是最高频率（对应模拟世界的奈奎斯特频率）。

把上面的对应关系写成两个精确公式（含 D/C 侧的频率响应）

C/D 侧（采样后得到序列）：

Xd(ejΩ) = 1T ∞Σk=−∞ Xc( j(Ω − 2πk)/T )

为什么：把 (9-6) 里的 ω = Ω/T 代进去即可（也可直接用 Xd(ejΩ) = Xp(jΩ/T)）。 注意括号里的 (Ω−2πk)/T：k 变化 1， 连续频率就变化 2π/T = ωs——和 (9-6) 是同一件事，只是换了变量。

D/C 侧（离散滤波器对应一个连续滤波器）：

Hd(ejΩ) = Hc(jΩ/T),    |Ω| < π   ⟺   Hd(ejωT) = Hc(jω)

为什么这很重要：它意味着你可以在计算机里设计一个数字滤波器 Hd， 让它恰好等价于一个模拟滤波器 Hc。 这就是"用软件代替模拟电路"的理论依据：整条链路 C/D → Hd → D/C 在满足采样定理时，对连续输入 xc(t) 的作用与直接串一个 Hc(jω) 完全相同。 注意 |Ω| < π 这个限制：只在奈奎斯特区间内等价，之外本来就被混叠污染了。

11. 内插（上采样）与抽取（下采样）

同一套"周期延拓"的思想，换成离散时间自己来一遍，就得到数字信号处理里天天用的两个操作： 内插与 抽取。

抽取 / 下采样（decimation, downsampling）

xb[n] = x[nN]：每 N 个点留一个。 新采样率 fs' = fs/N。

频域：Xb(ejω) = Xp(ejω/N)， 频谱在 2π 内被"展宽"（拉伸）N 倍。 这很好理解：频率轴 [0, 2π) 现在要装下原来 N 倍宽的频率范围， 新奈奎斯特频率降到 fs/(2N)。

内插 / 上采样（interpolation, upsampling）

先在每两个样本之间插 N−1 个零（xe[n] = x[n/N]，n 为 N 的倍数时取值，否则为 0）， 再过一个低通滤波器把"零造成的尖角"磨平。

频域：插零让频谱在 2π 内被压缩 N 倍（出现 N 份副本挤在一起）， 那个低通滤波器的作用就是只留中心那一份、把其余副本全砍掉。 它砍掉副本的动作，就叫抗镜像滤波（anti-imaging）。

为什么下采样之前必须先做抗混叠滤波

抽取把奈奎斯特频率压低了 N 倍。原来"安全"的高频成分，在新的奈奎斯特频率看来就是超标的、 会被折叠下来的东西。所以正规流程是：

低通（截止 fs/(2N)）→ 抽取 N 倍

那个低通滤波器叫抗混叠滤波器（anti-aliasing filter）。 高频信息是被主动丢掉的，不是被动变质的——主动丢掉还能接受（你知道丢了什么），被动混叠则会让低频数据被污染，事后无法挽救。

12. 动手：抽取与抗混叠

下面的实验台用一个 16 点序列演示抽取。你可以改信号的数字频率（也就是它有多"高"）， 再改抽取倍数 N，看频谱被展宽成什么样子。

请按这个顺序操作

① 先选 f = 2 Hz、N = 1：蓝色曲线（原来 16 点的频谱）的峰在 2 Hz 处， 离新奈奎斯特（这时是 8 Hz）很远，一切正常。

② 把 N 调到 4：新采样率变成 4 Hz，新奈奎斯特变成 2 Hz。 峰正好压在边界上——还能勉强接受，因为 2 Hz 是"刚好没超标"。

③ 把 f 换成 7 Hz、N = 4：7 Hz 远超 2 Hz， 读出台会告诉你它折叠成了 |7 − 1×4| = 3， 再折一次变成 |3 − 4| = 1 Hz。一个 7 Hz 的成分，抽取后看起来是 1 Hz。 而且这个错误无法通过任何后续处理修回来。

13. 实操：零阶保持与其它实际重建办法

sinc 内插在数学上完美，但在工程上做不到，原因有两个：① h(t) 从 t=−∞ 延伸到 +∞，非因果，实时系统必须等到未来才知道现在的值；② 衰减只有 1/|t|，很慢， 需要无限多项求和。实际系统用的是它的近似品。

零阶保持（ZOH）

每个采样值保持 T 秒不变，输出是阶梯波。 等效于"冲激串先过一个 h0(t) = 宽度 T、高度 1 的矩形"。 频域增益是 |sinc(ωT/2)|：在 ω = π/T（奈奎斯特）处已经衰减到理论值的 2/π ≈ 63.7%，还有 ωT/2 的线性相位（半个采样周期的延时）。 代价小、能用，所以 D/A 芯片几乎都用它，后面常再补一个反 sinc 补偿滤波器。

一阶保持（线性内插）

把相邻采样点用直线连起来。等效冲激响应是三角形，频域是 |sinc(ωT/2)|2：衰减更快（更像理想低通）， 但输出的一阶导数不连续（折角），听感/画面上会有波纹。计算量比 ZOH 略高。

过采样 + 高阶保持

现代做法：先用远高于奈奎斯特率的频率采样（过采样，oversampling）， 让重建滤波器的过渡带变得极宽（好做、好造），再用多级数字滤波器降到目标采样率。 CD 用 44.1 kHz 存 20 kHz 带宽，靠的就是这条路线加上 1 bit 过采样 D/A。

重建方式冲激响应频响问题实际使用场合
理想（sinc）sin(πt/T)/(πt/T)无失真，但非因果、无限长理论基准、离线后处理
零阶保持rect(t/T − 1/2)幅度按 sinc 下垂、延时 T/2绝大多数 D/A 芯片
一阶保持tri(t/T)下垂更快、有折角图形/动画插值、音频粗修

顺带回答一个常见疑问

"现实信号有最高频率吗？"严格说——大多数没有（白噪声、理想方波、任何跳变都含有无穷高频）。 所以真实系统的做法是：在 A/D 之前先加一个模拟低通（抗混叠滤波器），人为地把信号变成带限的， 再按那个截止频率的 2 倍以上去采样。这样"满足采样定理"就不是碰运气，而是你设计出来的。 这也是为什么所有数据采集卡前面都有一颗模拟滤波器。

14. 常见坑

坑 1：把奈奎斯特率和奈奎斯特频率搞混

奈奎斯特率 = 2fM（信号的要求）；奈奎斯特频率 = fs/2（采样器的能力）。不混叠就是"能力 ≥ 要求"。

坑 2：以为 fs > 2f 是"约等于"条件

它是严格条件。fs = 2f 是临界情形（正弦的谱是冲激，临界时刚好相切，尚可）； 实际信号有一定带宽，必须留余量，别贴着边界设计。

坑 3：忘了 1/T 的幅度缩放

(9-6) 里那个 1/T 一直在。重建滤波器增益取 T 就是为了补它。漏掉它，恢复出来的信号幅度会差 1/T 倍。

坑 4：混叠能靠"事后滤波"补救

不能。混叠把高频成分搬到了低频位置上，和原有的低频成分混在同一个频段，没有任何滤波器能把它们分开。唯一的办法是采样前就滤掉。

坑 5：直接抽取，不做抗混叠

下采样 N 倍，奈奎斯特频率降到 1/N，原来安全的高频必然折叠。正规顺序是"先低通、再抽取"，顺序反了信息就毁了。

坑 6：把 sinc 的两种定义用混

采样定理的公式里是 sin(πu)/(πu)（本站记作 SSC.sincPi），不是 sin u/u（SSC.sinc）。混了会让内插的零点位置全部错位。

坑 7：以为采样点越密，重建就一定越准

在满足定理的前提下，是的（样本多、截断误差小）。但如果不满足定理，增加采样密度并不会让已经混叠的那部分"恢复"——它只是把混叠后的假信号描得更清楚。

坑 8：用频率算错了混叠

混叠后的频率要按 (9-8) 折回 [0, fs/2]，取绝对值、取最小； 而且别忘了幅度可能整体反号。别只算一半就下结论。
