DFT 与 FFT：计算机怎么算傅里叶

前七章我们算了一堆傅里叶变换，但全是"手算"：积分要么查表，要么靠技巧。 可是真实的机器——手机、示波器、心电图机——每秒钟要算几十万次频谱。 这一章回答一个非常具体的问题：只能存有限个数、只能做加法和乘法的计算机，怎么算傅里叶？ 答案是离散傅里叶变换（DFT）；而让它在 1965 年之后变得"随处可见"的，是快速傅里叶变换（FFT）这个算法。

1. 计算机到底卡在哪

先把第 7 章的结论摆出来。一个离散序列的DTFT（discrete-time Fourier transform，离散时间傅里叶变换）是

X(ejω) = ∞Σn=−∞ x[n] e−jωn (8-1)

它有两个让计算机绝望的地方，我们把它们拆开看清楚。

问题 ①：无穷多项，存不下

求和从 n=−∞ 到 +∞。计算机的内存是有限的，它没法对无穷多个数求和。 哪怕信号只有 10 秒，采样后也有几百万个数——"有限但很长"是可以接受的，"无穷"不行。

问题 ②：ω 是连续变量，画不完

X(ejω) 是一个连续变量的函数。要把它"完整"算出来，得在无穷多个连续的 ω 上各算一次求和。 计算机能吐出来的只有有限个点。

解题思路：两个"无穷"分别用两招对付

对付无穷多项：只取有限的一段，比如 n = 0, 1, …, N−1。 这不是妥协，而是把"我要分析的那一段信号"当成全部。取多长，由你决定。

对付连续 ω：在 [0, 2π) 里等间隔地取 N 个点，只算这 N 个频率上的值。 因为 DTFT 以 2π 为周期（第 7 章），整个频率轴的信息全都压缩在一个长度为 2π 的周期里， 在这个周期内均匀地取 N 个点，就是"采样"。

这两招合起来，就得到这一章的主角：

X[k] ≜ X(ejω) |ω = 2πk/N ,    k = 0, 1, …, N−1 (8-2)

但要小心："只取有限的一段"这件事，本身会偷偷改变信号的含义——下一节讲清楚。

第一个大坑就在眼前

取 n = 0…N−1 这一段，和"假设信号以 N 为周期无限重复"，在 DFT 的世界里是完全同一件事。 DFT 看不见"这段以外的世界"，它默认你把这一段首尾相接，无限循环下去了。 记不住这一点，后面的循环卷积、 泄漏、 栅栏效应全都会变成玄学。

2. DFT 的定义与第一次说明

把上一节的两招写成公式，就得到本页最重要的两个式子。

结论：离散傅里叶变换对（本站统一约定）
正变换（分析式）　 X[k] = N−1Σn=0 x[n] e−j2πkn/N,   k = 0, 1, …, N−1 (8-3)
反变换（综合式）　 x[n] = 1N N−1Σk=0 X[k] e+j2πkn/N,   n = 0, 1, …, N−1 (8-4)

记号：x[n] ⟷ X[k]， N 叫变换长度（transform length）。 注意反变换前面的 1/N：正变换没有系数，反变换才有，这和 CTFT 里"反变换带 1/2π"是同一套约定。

关于 1/N 放在哪一边：两种教材约定的对照（很多人算错就错在这里）

Oppenheim 教材（本站内容依据）把 1/N 放在正变换： X[k] = (1/N)Σ x[n]e−j2πkn/N， 反变换不带系数。这样定义的 X[k] 正好等于 DTFS（第 5 章）的系数 ck。

为什么：因为 DTFS 的系数天然带 1/N（是"一个周期内的平均值"），而 DFT 最早就是从"把有限长序列看成周期序列的一个周期"推出来的，所以继承了这个 1/N。

本站与绝大多数工程实现（MATLAB、NumPy、本页内核的 SSC.dft / SSC.fft）把 1/N 放在反变换， 即上面 (8-3)、(8-4) 的写法。

为什么：这样正变换是纯粹的"内积/投影"，没有任何缩放，写代码时最省事；代价是反变换要除以 N。

两套约定怎么互相换算？记一个关系就够了：

X本站[k] = N · XOppenheim[k] = N · ck

为什么：同一组 x[n] 对应同一个物理频谱，两套定义只差一个 N 倍。只要一次变换和一次反变换用的是同一套约定，结果就永远正确——混用两套约定才会出 N 倍的错。

还有一个常见记号：WN

很多书把 e−j2π/N 记作 WN， 于是 e−j2πkn/N = WNkn， 正变换写成 X[k] = Σn x[n]WNkn。 记号叫旋转因子（twiddle factor）， 它就是把单位圆 N 等分、每次转一点点的那把"尺子"。看到 WN 不要慌，把它读回 e−j2π/N 就行。

4. 核心推导：DFT 就是 DTFT 的等间隔采样

这是本章的骨架。这个结论不只是"看起来像"，它是可以严格证出来的。逐字看，不要跳。

推导一：X[k] = X(ej2πk/N)（DFT 系数 = DTFT 在 ω=2πk/N 处的值）

第 1 步：写出 DTFT，并指出它只用得到有限个 x[n]。

设 x[n] 只在 0 ≤ n ≤ N−1 内可能非零，其他位置全是 0。则

X(ejω) = ∞Σn=−∞ x[n]e−jωn = N−1Σn=0 x[n]e−jωn

为什么：n < 0 和 n > N−1 的项都是 0·e−jωn = 0，加 0 不改变结果，所以无穷求和可以就地砍成有限求和。这一步说明：有限长序列的 DTFT 是"有限项的和，但 ω 仍然连续"——只剩问题 ②。

第 2 步：把 ω 取成 N 个等间隔的点。

令 ω = 2πk/N（k = 0, 1, …, N−1），代入上式：

X(ej2πk/N) = N−1Σn=0 x[n] e−j(2πk/N)n = N−1Σn=0 x[n] e−j2πkn/N = X[k]

为什么：把 ω=2πk/N 直接代进 e 的指数，指数上就是 −(2πk/N)n = −2πkn/N。右边正好是 DFT 的定义式 (8-3)。于是结论成立：DFT 的每一个 X[k]，就是 DTFT 在频率 ωk=2πk/N 上的取值。

第 3 步：这 N 个频率点在单位圆上长什么样。

在 z 平面（第 13 章会专门讲）上，ejω 是单位圆上的点。 ωk = 2πk/N 意味着把单位圆均分成 N 份，取第 k 个分点，从 ω=0（即 z=1）出发逆时针走。 k = 0…N−1 走满一圈回到起点。

ω0 = 0,   ω1 = 2πN,   ω2 = 4πN,   … ,   ωN−1 = 2π(N−1)N

为什么只取一圈：DTFT 以 2π 为周期（第 7 章），X(ej(ω+2π))=X(ejω)，所以 [0,2π) 之外的频率没有任何新信息。取 k = 0…N−1 恰好覆盖一个完整周期，一个不多一个不少。

这就是"频域采样"

时域上我们采了 N 个样，频域上我们也采了 N 个样。 时域 N 个样本 ↔ 频域 N 个样本，这是本章后面一切"坑"的根源：两边的自由度必须一样多， 多出来的信息没有地方放，只能挤在"周期性"里。

推导二：反变换公式 (8-4) 为什么成立（正交性 + N 个方程的联立）

第 1 步：准备一个"选择器"公式。

对整数 m，考虑

N−1Σk=0 ej2πkm/N = N,   当 m 是 N 的整数倍（即 ej2πkm/N=1） 0,   其它情况

为什么：当 m 是 N 的倍数时，每一项都是 1，N 项相加得 N。否则这是一个等比数列：Σk=0N−1 rk = (1−rN)/(1−r)，其中 r = ej2πm/N 且 r ≠ 1；而 rN = ej2πm = 1，分子为 0，故和为 0。这个"选择器"就是离散世界的正交性：N 个复指数在 N 点上两两正交。

第 2 步：把 (8-4) 的右边代进 (8-3)，验证得到 X[k]。

设 y[n] = (1/N)Σk=0N−1 X[k]ej2πkn/N，把 X[k] = Σm x[m]e−j2πkm/N 代入：

y[n] = 1N N−1Σk=0 N−1Σm=0 x[m] e−j2πkm/N ej2πkn/N = N−1Σm=0 x[m] · 1N N−1Σk=0 ej2πk(n−m)/N

为什么能交换求和次序：两个都是有限和（各 N 项，总共 N² 项，都是有限个数），有限个数的加法可以任意交换顺序，结果不变。这一步不需要任何收敛条件——这正是 DFT 比 DTFT"乖"的地方。

第 3 步：用第 1 步的选择器，内层求和只剩 m = n 那一项。

y[n] = N−1Σm=0 x[m] · [ m ≡ n (mod N) ? 1 : 0 ] = x[n]

为什么：内层求和里 m 是固定的，它作为"选择器变量"就是 m−n。只有当 m−n 是 N 的倍数时内层和才等于 N·(1/N) = 1，否则等于 0。在 0 ≤ m, n ≤ N−1 范围内，m−n 是 N 的倍数只有 m = n 一种情况，所以只剩这一项，正好等于 x[n]。

注意第 3 步括号里那句话

"m−n 是 N 的倍数"——如果 m 可以超出 0…N−1， 那么 m = n + N 也会被选中，我们会得到 x[n] + x[n+N] + x[n+2N] + …。 换句话说，反变换给出的永远是"把 x 以 N 为周期重复后"的那个序列。 在 0…N−1 内它和原序列一样，所以平时看不出问题——但一旦发生了循环卷积或补零， 这个隐含的周期性就会跳出来咬你一口。

5. 动手：把 N 从 4 拉到 16，看 DFT 点"落"在 DTFT 曲线上

下面是本页第一个实验台。它要让你亲眼确认那个结论：DFT 的茎叶图（stem）永远长在 DTFT 这条连续曲线上， 改 N 只是改变采样的疏密。

盯住这三件事

① 茎叶图的高度永远等于曲线在该频率的高度。不管 N 取 4、8 还是 16，把 stem 的顶点和曲线比一比——一个不差。这就是 X[k] = X(ej2πk/N)。

② N 变大，采样点变密，但曲线本身纹丝不动。曲线由 x[n] 决定，与 N 无关（只要 x 的那些非零值没被截掉）。N 只是"在这条曲线上取几个点"。

③ 把 N 拉大到超过序列长度，就是在补零。补零后曲线不变、点变密——这是第 8 节要专门讲的"栅栏效应"的解药。 但请注意：点变密不等于分辨率提高，这件事下一节末尾会说清楚。

6. 循环卷积：DFT 世界里"卷积"变成了什么

第 2 章我们花了很大力气学卷积，第 6、7 章又学到"时域卷积 = 频域相乘"。到了 DFT， 这个性质当然还在，但形式变了：

x[n] ⊛ h[n] ⟷ X[k] · H[k] (8-5)

这里的 ⊛ 读作循环卷积（circular convolution），定义是

y[n] = x[n] ⊛ h[n] ≜ N−1Σm=0 x[m] h[(n−m) mod N] (8-6)

其中 (n−m) mod N 表示"除以 N 取余数"，规定结果落在 0…N−1。 这个术语必须解释清楚：

什么是循环卷积（circular convolution）

对比一下就会有感觉。线性卷积（第 2 章）要算 h[n−m]：

线性卷积：把 h 翻转、右移 n 格。n−m 一旦小于 0，h 就取 0（因为序列在 0 左边是空的）——滑出去的部分就没了。

循环卷积：把 h 写成一个长度为 N 的环（n=0 和 n=N−1 首尾相接）。 翻转、右移 n 格时，滑出右端的那部分会从左端绕回来，所以 (n−m) 为负数时不是取 0，而是回绕到 n−m+N。 这就是"循环"两个字的全部含义：把线性平移换成了钟表上的圆周平移。

为什么 DFT 里天然是循环卷积（而不是线性卷积）

起点：DFT 的隐含假设是"x 和 h 都以 N 为周期"。

由第 4 节推导二的括号说明：当序列以 N 为周期时，x[n] 与 x[n+N] 是同一个数， 下标只要按 mod N 理解就永远合法。

为什么：DFT 只认识 0…N−1 这 N 个数。要让"x[n−5] 在 n=2 时"这句话有意义，唯一不引入额外假设的办法，就是认为 x[−3] = x[N−3]。

把两个周期序列做卷积，求和必然回绕。

y[n] = N−1Σm=0 x[m] h[n−m]

其中 h[n−m] 要按周期性理解：若 n−m < 0，就用 h[n−m+N]，这正是 h[(n−m) mod N]。

为什么这就等于式 (8-6)：因为周期性把"平移出界"和"回绕"变成了同一件事——h 在环上走，走到哪里都还在环上，没有"界外"。

结论与"两者何时相等"。

设 x 长为 N1、h 长为 N2， 则线性卷积长度为 L = N1 + N2 − 1。只要

N ≥ N1 + N2 − 1 (8-7)

回绕的那一段就只会落在"本来该是 0 的尾巴"上，于是 循环卷积 = 线性卷积。 做法是给两个序列都补零到 N 点再做 N 点循环卷积（或 N 点 DFT → 相乘 → N 点 IDFT）。

为什么：如果 N 比 L 还小，第 L 个位置上的值（它是"尾巴"的一部分）会被绕回来加到第 0 个位置上，这个"加"就是时域混叠（time-domain aliasing）。它洗掉了本来能分开的两段信息，所以结果错了。

7. 动手：线性卷积 vs 循环卷积

这个实验台做一件事：同一个 x、同一个 h，只改 N，看循环卷积的结果怎么从"等于线性卷积"变成"绕回来出错"。

实验读数怎么看

读出台会告诉你线性卷积的长度 L = N1+N2−1， 以及当前 N 是否满足 N ≥ L。 不满足时，红色那段就是"绕回来的尾巴"：把它和蓝色头部相加，正好得到红色的循环卷积。 只要把 N 调到 ≥ L，红色曲线的前 L 点会和蓝色曲线完全重合。

8. 泄漏与栅栏效应：截断和采样带来的两个假象

前面所有的推导都是"精确"的，但有两个现象会让第一次看频谱的人以为程序坏了。它们都是 DFT 的隐含假设造成的， 必须一次讲透。

8.1 泄漏（leakage）：明明是单一频率，谱上却到处都是

泄漏的完整解释：矩形窗 × 无限长信号 = 频域卷积出一个 sinc

第 1 步：认清 DFT 真正在处理什么信号。

假设真实信号是纯粹的 x[n] = cos(ω0n)，它无限长。 但 DFT 只能吃 N 个数，所以你实际喂进去的是

xw[n] = x[n] · w[n],    w[n] = 1 (0 ≤ n ≤ N−1), 其余为 0

为什么可以这么写：把"只取一段"看成"乘上一个只在 0…N−1 为 1 的函数"，物理上完全等价。这个 w[n] 叫矩形窗（rectangular window），"加窗"这个词就是这么来的。

第 2 步：时域相乘 = 频域（周期）卷积。

第 7 章的相乘性质说：时域相乘，频域做周期卷积。而矩形窗的 DTFT 是离散版的 Dirichlet 核，形状是"一个高的主瓣 + 无穷多个旁瓣"。

Xw(ejω) = 12π ∫2π X(ejθ) W(ej(ω−θ)) dθ

为什么这会导致泄漏：X(ejω) 本来是两根冲激（在 ±ω0）； 与窗的谱一卷积，每根冲激就被"换成了"一个完整的主瓣加旁瓣的形状——能量从一根线摊到了一整片。 这就是泄漏：原始信号的频率成分从它本来的频点上"漏"到了别的频点上。

第 3 步：什么时候"不漏"——整数周期截断。

如果截取长度恰好包含整数个信号周期，即 ω0N/(2π) 是整数， 那么 ω0 恰好落在某个 DFT 频点 2πk/N 上， Dirichlet 核的所有零点正好压在其它频点上，于是谱变成干干净净的两根线。

为什么：Dirichlet 核 sin(Nω/2)/sin(ω/2) 在 ω = 2πm/N（m 为非零整数）处正好为 0。频点与零点重合，其它频点就都读到 0。所以工程上做频谱分析时，习惯让采样长度与信号周期对齐（"整周期采样"），就是为了消掉泄漏。

抑制泄漏的正规做法：换窗

现实里信号周期往往未知，对齐做不到。那就换一个两端平滑地降到 0 的窗，比如汉宁窗（Hanning window）、汉明窗（Hamming window）、布莱克曼窗。 旁瓣大幅降低（泄漏变小），代价是主瓣变宽（频率分辨变差）。窗的选择永远是"旁瓣高度 ↔ 主瓣宽度"的折中，没有免费的午餐。

8.2 栅栏效应（picket-fence effect）与补零的真相

栅栏效应

你看到的频谱只是 DTFT 这条连续曲线上的 N 个采样点。 这就像透过一道栅栏看风景：栅栏的缝隙之间有什么，你看不见。 如果信号的频率恰好落在两个缝隙中间，你读到的最大值会比真实幅度低（最坏情况低到 2/π ≈ 63.7%）， 而峰值位置也读不准。

术语就是前面提到的栅栏效应（picket-fence effect）。

补零：能加密，不能提分辨

补零（zero padding）就是在序列尾部加 0，让 N 变大。 因为 0 不影响 DTFT，曲线不变；变的只是"在这条曲线上取多少个点"——点更密了，栅栏缝隙更细了， 峰值幅度可以读得更准。

但它不能提高真实分辨率。分辨两个靠得很近的频率，靠的是"观测了多长时间"： Δf = 1/T（T 是实际观测时长）， 与你在后面补了多少个 0 毫无关系。补零只是把同一条曲线画得更光滑，两个本来就分不开的峰，补再多零也还在一个鼓包里。

一条必须记住的等式
Δf = fsN = 1N Ts = 1T

Δf 是相邻两个 DFT 频点之间的间隔，Ts 是采样间隔，T = N·Ts 是总观测时长。 "N 越大分辨越好"这句话里的 N，指的是真实采集到的点数，不包括补的零。 而且注意：DFT 输出只有 N 个数，却要描述 [0, fs) 这段频率——这就是 8.1 式里 N 个样本只能给出 N 个频点的由来。

9. 动手：时域周期延拓 ↔ 频域采样

这一节把"对偶关系"摊在桌面上让你看。对偶说的是同一件事的两种说法：

时域采样（只取 N 个数） ⟷ 频域周期延拓（谱以 2π 为周期重复）
频域采样（只取 N 个频点） ⟷ 时域周期延拓（x[n] 以 N 为周期重复）

下面这个实验台让你亲手验证第二条：补零让频域采样点变密，而被"截断"这件事本身，等价于在频域把 x 的周期延拓给采了样。 你翻动 N，看左侧的周期延拓波形和右侧的谱线。

10. FFT：一个算法，不是一种新变换

到这里你可能觉得：DFT 挺好，可是式 (8-3) 要算 N 个 k， 每个 k 又要加 N 项，一共 N² 次复数乘法。 N = 1024 时是约 一百万次；N = 106 时是 一万亿次。这没法用。

关键定义：FFT 到底是什么

FFT（fast Fourier transform，快速傅里叶变换） 不是新的变换。它算出来的 X[k] 和 DFT 一模一样，一个 bit 都不差。 它只是把 DFT 的计算排了个聪明的顺序，让复数乘法从 N² 次降到约 (N/2)log2N 次。 写论文、写代码时要说准确：FFT 是 DFT 的算法。

FFT 的核心思想：把 N 点 DFT 拆成两个 N/2 点 DFT（时分基 2）

第 1 步：把 n 分成偶数、奇数两组。

记 WN = e−j2π/N，则 X[k] = Σn=0N−1 x[n]WNkn。设 N 为偶数，令

f[m] = x[2m],    g[m] = x[2m+1],    m = 0, 1, …, N2 − 1

为什么这么拆：偶数和奇数下标合起来正好是全部 n。拆开之后，两组各自的长度只有 N/2，为"递归"创造了条件——这就是分治（divide and conquer）。

第 2 步：分成两个求和。

X[k] = N/2−1Σm=0 f[m] WN2km + WNk N/2−1Σm=0 g[m] WN2km = F[k] + WNk G[k]

为什么：把 n = 2m 的项归为第一个和、n = 2m+1 的项归为第二个和；第二个和里的 WNk(2m+1) = WNk·WN2km，把与 m 无关的 WNk 提到求和号外面。而 WN2km = e−j2π·2km/N = e−j2πkm/(N/2) = WN/2km——两个和分别就是 f、g 的 N/2 点 DFT，记作 F[k]、G[k]。这一步的"为什么"就是旋转因子的指数运算规则。

第 3 步：利用周期性，把后一半也算出来，几乎不要钱。

因为 F[k]、G[k] 是 N/2 点 DFT，它们以 N/2 为周期：F[k+N/2] = F[k]。又因为 WNk+N/2 = −WNk，所以

X[k] = F[k] + WNk G[k]     X[k + N2] = F[k] − WNk G[k]

为什么 WNk+N/2=−WNk：WNN/2 = e−jπ = −1，转半圈正好是反向。这一对式子就是蝶形运算（butterfly）：一次乘法 + 两次加减，同时产出两个输出，代价只有"一个乘法"。

第 4 步：递归下去，数一数省了多少。

对 F、G 再各拆一次……只要 N 是 2 的幂，就能一直拆到 2 点 DFT 为止，共折 log2N 层， 每层总运算量 ∝ N。所以总复数乘法约为

(N/2)·log2N   vs   N²（直接算法）

为什么这是革命性的：N 翻一倍，N² 变 4 倍，而 N log N 只变约 2.1 倍。规模越大优势越恐怖——这就是为什么 1965 年 Cooley 与 Tukey 把算法写成论文之后，数字信号处理才真正遍地开花。

数量级对照（自己乘一下就能验证）

N = 64：N² = 4096，(N/2)log₂N = 192，快约 21 倍。
N = 1024：N² ≈ 1.05×106，(N/2)log₂N = 5120，快约 205 倍。
N = 4096：N² ≈ 1.68×107，(N/2)log₂N = 24576，快约 683 倍。
顺带说一句：本站内核 SSC.fft 就实现了这个基 2 迭代算法，和 SSC.dft 的暴力算法结果逐位一致（误差只在 10−14 量级的浮点噪声上，等价于完全相同）。

实序列的一个免费技巧：一次 FFT 算两个实序列

实际信号大多是实数。如果手上有两个实序列 x1[n]、x2[n] 要算 DFT， 不必算两次。构造复序列 x[n] = x1[n] + j x2[n]，做一次 N 点 FFT，然后利用共轭对称性拆分：

X1[k] = X[k] + X*[(−k) mod N]2,    X2[k] = X[k] − X*[(−k) mod N]2j

为什么成立：实序列的 DFT 满足 X1*[k] = X1[(−k) mod N]（共轭对称）。 于是两个实序列的谱可以写成"和的一半"与"差的一半除以 j"，两者刚好把复序列的 N 个复数用得一个不剩。 一次 N 点 FFT 的运算量 ≈ 两次一半规模的 FFT，这个技巧常用在实信号的批量处理里。

FFT 相关的其它实用事实（不推导，只记住怎么用）

事情结论什么时候用
N 不是 2 的幂怎么办基 2 算法要求 N 是 2 的幂补零到最近的 2 的幂（代价：泄漏与谱线位置略变，注意补零≠提分辨）
用 FFT 做长序列卷积补零到 N ≥ N1+N2−1 → FFT → 相乘 → IFFT滤波器系数很长时（如 1024 点 FIR），比直接卷积快得多
为什么要"重叠相加/重叠保留"信号远长于内存时，分段做循环卷积再把结果拼起来实时音频、长数据流的滤波
只想要幅度谱仍要算完整的复 FFT（幅度与相位是一体的）除非明确知道信号是实偶序列

11. 常见坑

坑 1：以为 FFT 是另一种变换

FFT 就是快速算 DFT 的算法，输出完全一样。说"用 FFT 变换"没错，说"FFT 变换和 DFT 变换结果不同"就错了。

坑 2：忘了 DFT 隐含周期延拓

把一段非周期的信号直接做 DFT，等于把它首尾相接无限重复。如果这段的首尾不连续，会在接缝处引入一个"假跳变"，频谱上多出能量——这是泄漏的另一种说法。

坑 3：循环卷积长度不够

想用 FFT 做线性卷积，必须补零到 N ≥ N1+N2−1。少了就会时域混叠，尾巴绕到头上。

坑 4：用补零来"提高分辨率"

不行。补零只是把同一条曲线画得更密。分辨率取决于真实观测时长 T：Δf = 1/T。

坑 5：把 |X[k]| 当成 0…fs/2 的物理幅度

要点：k > N/2 的那一半其实是负频率（ωk−2π），对实信号它与前半共轭对称，不是新的正频率。画单边谱时要记得乘 2（直流与 k=N/2 除外）。

坑 6：1/N 放错边

本站约定"反变换带 1/N"。用别的库（如 NumPy）时先看清它的约定，否则会差一个 N 倍。数字对不对，用"单位冲激的 DFT 全为 1"这类极端例子一试就知道。

坑 7：以为 X[k] 就是 DTFT

X[k] 只是 DTFT 上的 N 个采样点。两点之间的真实形状（可能有峰）你看不到——这就是栅栏效应。

坑 8：拿频谱峰值位置当信号频率

峰值只落在最近的 DFT 频点上，真实频率可能在两个频点之间，误差最大可达 ±Δf/2 = ±1/(2T)。要更准，就得看更长时间，或者用插值/相位差分等专门方法。
