# 信号与系统 · 交互图谱

一套**完全离线**的中文交互课程网页：双击 `index.html` 即可开始，无需联网、无需安装、无 CDN 依赖。
按"正常学习路径"从零基础一路铺到傅里叶变换、拉普拉斯变换与 z 变换，每页都能动手改参数看图形变化。

---

## 快速开始

```bash
# 方式一：直接双击（推荐，所有功能都可用）
xdg-open index.html       # Linux
open index.html           # macOS
start index.html          # Windows

# 方式二：起个本地静态服务（可选，便于手机/平板在同一局域网访问）
cd signals-systems-atlas && python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

页面已按 `file://` 协议验证：所有脚本都是普通 `<script src>`（非 ES module），不触发浏览器跨域限制。

## 一条主线（全课程的逻辑）

> **LTI 系统不创造新频率。** 复指数 `e^{st}` / `z^n` 是它的**特征函数**——进去之后形状不变，只被乘一个数（特征值 `H(s)` / `H(z)`）。
> 于是"分析系统"= 把信号摊成特征函数的线性组合；"摊开"是傅里叶级数 / 傅里叶变换，
> "摊开且容忍发散"是拉普拉斯变换 / z 变换，而"摊回去"就是各自的逆变换。

## 自检（改完页面后跑）

```bash
cd signals-systems-atlas
node tools/check.js     # 结构/链接/外部资源/脚本语法（静态规范）
node tools/smoke.js     # 桩 DOM 真跑内联脚本（运行时异常、id 拼错）
node tools/render.js    # 每个实验台推到极端参数（NaN 坐标、坐标爆掉、空帧）
```

三个脚本都必须全绿。`render.js` 会把每个滑块的 min / max / 中间值都试一遍，
专门用来抓"某个参数取值下图形变空白"这类只有真动手才会发现的问题。

最近的完整自检结果：

```
check.js   静态自检全部通过（17 页）
smoke.js   通过 17 / 17（含把内核 try/catch 吞掉的绘制异常捞出来）
render.js  全部 17 页的互动实验台在极端参数下几何正常
           （共 53 个实验台 / 444 帧极端参数，覆盖拖动极点、下拉切换、整数与小数边界）
```

自检过程中真实抓到并修掉的问题（留档，便于以后维护）：
1. **z 变换逆变换实验台**：整数滑块被取到小数中点时 `new Array(17.5)` 抛异常 → 所有整数控件改为 `Math.round` + 下限兜底。
2. **DTFS 重建实验台**：控件值未取整就当下标用（`c[5.5]` → `undefined.re`）→ 统一封装 `intOf/oddOf`，越界返回 0。
3. **图像二维 DFT 实验台**：`cv.width` 未初始化导致 `arc()` 三坐标 NaN（真浏览器里是潜伏 bug）；同时发现**二维 DFT 的反变换实现是错的**（行列分离第二步丢了虚部、并把只有负指数的 FFT 当逆变换用）→ 改用共轭技巧 `idft(X)=conj(fft(conj(X)))/N`，往返误差 7.8e-16。
4. **界面反演**：FIR 窗函数法的"第一旁瓣"实际抓到的是过渡带过冲（1.09×），改正为 −3 dB 点之后的第一个局部极大（矩形 −21 dB / 汉宁 −44 dB / 汉明 −54 dB）。
5. **课件里一处公式笔误**：解调式在课件 PPT 写作 `x/2 − (x/2)cos2ω_c t`，但由 `cos²θ=(1+cos2θ)/2` 应为 **加号**（减号会与频域结论 `W=½X+¼[X(ω∓2ω_c)]` 自相矛盾）。网页按正确写法（Oppenheim 8.13）并加了显式提醒。
