1. 为什么要给 DTFT 加"旋钮"

先明确 DTFT 是什么（第 7 章）：

下面用到的 X(z) 是双边 z 变换，除非特别说明。

X(ejω) = ∞Σn=−∞ x[n] e−jωn

这个级数收敛的充分条件是 绝对可和 （absolutely summable）：Σn|x[n]| < ∞。 像 2nu[n] 这种随 n 指数增长的序列就不满足——DTFT 直接"不存在"。

关键动作：先乘一个实指数再算 DTFT

我们不去改信号，而是先把它乘上 r−n（r 是正实数）： x[n]·r−n。若 r > 1，增长的序列被压住（因为 r−n 在衰减）； 若 r < 1，衰减的序列反而被放大。于是总有某些 r 能让新序列绝对可和。

对新序列做 DTFT，并把它记成一个关于 r 和 ω 的函数，再把两者合并写成复数 z = rejω，就得到

X(rejω) = ∞Σn=−∞ { x[n] r−n } e−jωn   ⟺   X(z) = ∞Σn=−∞ x[n] z−n (13-1)
推导：为什么 z = re^{jω} 能把两件事合并成一个符号

把 z = rejω 直接代入 z−n：

z−n = (rejω)−n = r−n e−jωn

为什么：指数的乘法法则 (ab)−n = a−nb−n，且 (ejω)−n = e−jωn。

于是式 (13-1) 右边的求和自动分裂成"衰减旋钮 × 频率探针"两部分：

∞Σn=−∞ x[n] z−n = ∞Σn=−∞ {x[n] r−n} e−jωn

为什么：这正是上面那一步的重新排列。r 负责"压住"信号让它收敛，ω 负责"挑频率"。

取 r = 1（即 |z| = 1，单位圆），衰减旋钮不起作用，式子退化成 DTFT：

X(z)|z=ejω = X(ejω) = DTFT (13-2)

为什么重要：DTFT 就是 z 变换在单位圆上的取值。前提是 ROC 包含单位圆——否则那个位置根本不收敛，DTFT 不存在。

3. 收敛域 ROC：三条铁律

ROC 一定是"以原点为中心的圆环"（或整个平面、或圆外、或圆内），因为收敛条件 Σ|x[n]|r−n < ∞ 只和 r 有关，和 ω 无关： 沿同一半径转一圈（ω 变化），收敛性完全一样。这就是"ROC 是环形"的根本原因。

序列类型例子ROC图示
有限长（只在有限个 n 上非零） δ[n]、{1,2,3} 整个 z 平面（可能去掉 z=0 或 z=∞） 全平面
右边（n < N₀ 时为 0，又称因果型） anu[n] |z| > rmax（最外极点之外） 圆外
左边（n > N₀ 时为 0，又称反因果型） −anu[−n−1] |z| < rmin（最内极点之内） 圆内
双边（左右都无限延伸） a|n| r₁ < |z| < r₂（两个极点之间的环） 圆环
三条铁律（考试高频，务必背下来）
  1. ROC 不包含任何极点（极点处级数一定发散）。
  2. ROC 由极点划分边界，一定是圆环形状（也可能是整个平面或圆外/圆内）。
  3. 同一个 X(z) 表达式 + 不同 ROC = 不同序列。所以答题时"写出 X(z) 与 ROC"两件缺一不可。

推论（判断稳定性）：若系统因果（h[n] 是右边序列）且 ROC 包含单位圆，则系统稳定，等价于 全部极点在单位圆内。

4. 动手：同一个 X(z)，三种序列

取最经典的那个例子 X(z) = 1/(1 − a z−1)（0 < a < 1）。 它在 z = a 处有一个极点。下面切换三种 ROC，看同一个 X(z) 如何对应完全不同的 x[n]。 拖动 a，看极点位置与衰减速度如何一起变化。

看懂了什么

因果读法（ROC = |z|>a）：把 1/(1−az−1) 展开成 Σ(az−1)n， 幂次是 z−n 且 n≥0，对应 x[n]=anu[n]（n 越大越小，右边序列）。

反因果读法（ROC = |z|<a）：改按 z 的正幂展开（长除要换个方向），得到 x[n] = −anu[−n−1]（n 越负越小，左边序列）。

两个都取（ROC = a<|z|<1/a）：两者相加，得到一个左右都无限的"双边"序列。 这就是 ROC 存在的意义：它是"选哪一份答案"的开关。

X(z) = 11 − az−1,    收敛条件 |az−1| < 1  ⟺  |z| > |a|

为什么是 |z| > |a|：|az−1| = |a|/|z| < 1 ⟺ |z| > |a|。 这正是"因果序列的 ROC 在最外极点之外"这条铁律的来源。

为什么要在意：极点与零点的位置直接决定 ROC 的边界和系统稳定性（第 9 节会用图来玩这件事）。

7. 逆 z 变换三法（含完整算例）

方法一：部分分式展开

把 X(z) 拆成 Σ Ai/(1−piz−1)，再对每项查表。 每一项是取右边还是左边，由 ROC 决定。最常用、最稳。

方法二：幂级数（长除）

直接做多项式长除，把 X(z) 展成 Σ cnz−n， 系数序列就是 x[n]（因果时 n≥0）。适合只求前几项。

方法三：留数法

x[n] = Σp 在 ROC 内 Res[ X(z)zn−1 ]。 对有理 X(z)，等于把 X(z)zn−1 在 ROC 内每个极点处的留数加起来。

完整算例：X(z) = 1 / [(1−0.5z⁻¹)(1−0.8z⁻¹)]，且 x[n] 因果（ROC: |z|>0.8）

第 1 步：写部分分式形式。两个一阶极点 p₁=0.5、p₂=0.8，所以

X(z) = A₁1 − 0.5z−1 + A₂1 − 0.8z−1

为什么这样设：查表里 anu[n] ↔ 1/(1−az−1) 的形状正好是这个形式，拆开就能逐项对表。

第 2 步：求系数。技巧是"盖住某个因子后代入该极点"：

A₁ = (1−0.5z−1)X(z) |z=0.5 = 11 − 0.8/0.5 = 1−0.6 = −53
A₂ = (1−0.8z−1)X(z) |z=0.8 = 11 − 0.5/0.8 = 10.375 = 83

为什么要"代入极点"：在 z=p₁ 处，第一项的分母变得极大（1−p₁/p₁ = 0），把它乘回去就消掉了其它项，只剩 A₁。这是留数公式 A₁ = (1−p₁z−1)X(z)|z=p₁ 的直观来源。

第 3 步：按 ROC 决定方向。ROC 是 |z|>0.8，说明是因果（右边）序列，两项都取右边形式：

x[n] = [ −53(0.5)n + 83(0.8)n ] u[n]

验算：n=0 时 x[0] = −5/3 + 8/3 = 1。这也符合"X(z) 在 z→∞ 时趋于 1，所以 x[0]=1"（初值定理）。

如果换成 ROC: 0.5 < |z| < 0.8 呢？那就不是因果序列了：|z|>0.5 让 p₁=0.5 那项取右边， 而 |z|<0.8 让 p₂=0.8 那项必须取左边：

x[n] = −53(0.5)nu[n] − 83(0.8)nu[−n−1]

结论：部分分式只是一半工作，ROC 决定了每一项取 u[n] 还是 u[−n−1]。这就是为什么题目不给 ROC 就没法做。

算例（方法二）：用长除法把 X(z) 展成幂级数，直接读出前几项

仍取 X(z) = 1/[(1−0.5z−1)(1−0.8z−1)]， 先乘开分母：1 − 1.3z−1 + 0.4z−2。

第 1 步：写成"分母除分子"的长除形式。把 z−1 当变量 x 看：

x[n] ↔ 1 ÷ (1 − 1.3x + 0.4x2)，其中 x = z−1

为什么这样做合法：因果序列的 z 变换按 z−1 的升幂展开正是 Σn≥0x[n]z−n，所以商的系数就是 x[0], x[1], x[2], …

第 2 步：逐项做除法（每一步"消掉最高次"）。

1 ÷ (1 − 1.3x + 0.4x²) = 1 + 1.3x + 1.29x² + 1.157x³ + …

为什么：第 1 项取 1，因为 1·(1−1.3x+0.4x²) 与 1 相减后余 1.3x − 0.4x²； 再取 1.3x，余 1.29x² − 0.52x³；依此类推。每一步都保证把当前最低次项消掉。

第 3 步：读系数。x[0]=1, x[1]=1.3, x[2]=1.29, x[3]=1.157, …

与部分分式的闭式解对照：x[n] = −(5/3)(0.5)n + (8/3)(0.8)n → n=0: 1, n=1: 1.3, n=2: 1.29, n=3: 1.157 …完全一致。 长除法适合"只要前几项"，部分分式适合"要通项"。

算例（方法三）：留数法，并与 ROC 的选择配上

留数法公式（对有理 X(z)）：

x[n] = ΣROC 内的极点 p Res[ X(z)zn−1 ]z=p

一阶极点的留数怎么算。若 X(z)zn−1 在 p 处是一阶极点：

Res = limz→p (z − p)·X(z)zn−1 = (1 − pz−1)X(z)|z=p · pn

为什么两个式子相等：(z−p) = z(1−pz−1)， 而 z·zn−1 = zn。乘出来正好是"盖住因子"的形式，所以部分分式的系数 A 就是留数（乘上 pn）。

谁在 ROC 内，谁就参与。回到同一个例子，三个不同 ROC 给出三种答案：

ROC哪些极点在 ROC 内x[n]
|z| > 0.8两个都在（0.5 与 0.8） [−(5/3)(0.5)n + (8/3)(0.8)n]u[n]
0.5 < |z| < 0.8只有 0.5 −(5/3)(0.5)nu[n] − (8/3)(0.8)nu[−n−1]
|z| < 0.5一个都没有 −[(5/3)(0.5)n + (8/3)(0.8)n]u[−n−1]

规律：极点落在 ROC 内 → 该项对应右边序列（u[n]）；极点落在 ROC 外 → 该项对应左边序列（u[−n−1]）， 并且要整体加一个负号。这与部分分式的"逐项判方向"是同一件事的两种说法。

注意最后一行：ROC 内没有极点时 n ≥ 0 的留数和为 0， 说明序列在 n ≥ 0 上恒为 0——即纯左边序列。这也是判断"因果与否"的一个视角。

性质证明（时移 / z 域尺度 / 卷积 / 累加）

(a) 时移：x[n−n₀] ⟷ z−n₀X(z)

∞Σn=−∞ x[n−n₀]z−n  令 m = n − n₀ ⇒ n = m + n₀  = ∞Σm=−∞ x[m]z−(m+n₀) = z−n₀X(z)

为什么：换元只改求和指标，z−n₀ 是常数可提到求和号外。 注意它可能改变 z=0 / z=∞ 处的收敛性（延迟一个样本会让 z=∞ 出现极点）。

(b) z 域尺度：anx[n] ⟷ X(z/a)

∞Σn=−∞ anx[n]z−n = ∞Σn=−∞ x[n](z/a)−n = X(z/a)

为什么：把 an 塞进括号写成 (z/a)−n。 几何效果就是"把整张极点零点图沿径向缩放 |a| 倍"，ROC 也随之缩放——这正是变换对表里 rncos(ω₀n)u[n] 那几行的来历。

(c) 卷积：x[n] ∗ h[n] ⟷ X(z)H(z)

∞Σn=−∞ ( ∞Σk=−∞ x[k]h[n−k] ) z−n

为什么可以交换两个求和次序：在 ROC 内部两个级数都绝对收敛（这正是 ROC 的定义）， 绝对收敛时重排求和不会改变结果。

= ∞Σk=−∞ x[k] ( ∞Σn=−∞ h[n−k]z−n )  =  ∞Σk=−∞ x[k]·z−kH(z)  =  X(z)H(z)

括号里用的是刚证的时移性质（把 n₀ 换成 k）。结论：时域卷积 = z 域相乘， 这是把差分方程变成代数方程、把滤波器级联变成 H₁(z)H₂(z) 的全部依据。

(d) 累加：Σk≤nx[k] ⟷ X(z)/(1−z−1)

y[n] = nΣk=−∞ x[k]  ⇒  y[n] − y[n−1] = x[n]

为什么：累加器的"差分"就是原信号——这一步是理解累加性质的关键。

Y(z) − z−1Y(z) = X(z)  ⇒  Y(z) = X(z)1 − z−1

为什么：两边取 z 变换并用时移性质（y[n−1] ↔ z−1Y(z)）， 再把 Y(z) 解出来。"累加 = 乘 1/(1−z−1)"，而 1/(1−z−1) 正是 u[n] 的 z 变换—— 所以累加器就是"与阶跃做卷积"，两种说法完全一致。

下面把上节的算例做成可调的：拖动两个极点位置，页面同时用两条完全不同的路算出 x[n]—— 一条用部分分式闭式公式，一条用差分方程逐项递推（这是"长除/递推"的等价形式）。 两条茎叶图必须完全重合，这是对你理解的最直接检验。

9. 动手：拖极零点，看 ROC 与滤波器

10. 系统函数、差分方程与方框图

对 DT LTI 系统 y[n] = x[n] ∗ h[n]，用卷积性质：

Y(z) = H(z)·X(z),     H(z) = Y(z)X(z) = ∞Σn=−∞ h[n]z−n

H(z) 叫 系统函数 （system function）。若系统由线性常系数差分方程描述：

NΣk=0 ak y[n−k] = MΣk=0 bk x[n−k]
推导：差分方程 → H(z)（两步，不用求 h[n]）

两边取 z 变换，用时移性质 y[n−k] ↔ z−kY(z)：

NΣk=0 ak z−k Y(z) = MΣk=0 bk z−k X(z)

为什么：z 变换是线性的（和、常数都能穿透），所以可以把变换搬到每一项上。

两边同除 X(z) 与那个分母和，立刻得到 H(z)：

H(z) = MΣk=0 bkz−k NΣk=0 akz−k = B(z)A(z)

为什么这个结果重要：把 z 代进系数多项式就能得到系统函数，不必解差分方程求 h[n]—— 与第 6 章"微分方程 → H(jω)"完全平行的技巧。分子根 = 零点，分母根 = 极点。

系统类型h[n]H(z)极点例子
FIR（有限冲激响应 finite impulse response） 有限长 只有分子多项式（A(z)=1） 只在 z=0（或没有） y[n]=x[n]+x[n−1]（滑动平均）
IIR（无限冲激响应 infinite impulse response） 无限长 有理分式，分母非平凡 有限个非零极点 y[n]=ay[n−1]+x[n]
因果性与稳定性的完整判据（务必分清）
想要条件（用 ROC 说）条件（用极点说）
因果ROC 是最外极点之外的圆外区域（含 z=∞）极点个数 ≥ 零点个数（z=∞ 处不是极点）
稳定ROC 包含单位圆若因果，则全部极点在单位圆内；一般情形要求极点不落在单位圆上、且单位圆在某个 ROC 内
因果且稳定ROC 是 |z|>r_max 且 r_max<1全部极点严格在单位圆内

注意"稳定"并不蕴含"因果"：一个左边序列（反因果）也可能稳定（ROC 是圆内且包含单位圆），只是它不能实时实现。

11. 单边 z 变换：初值定理与终值定理

上面用的都是双边 z 变换（n 从 −∞ 加到 +∞）。处理"从 n=0 开始的因果信号 + 初始条件"时， 常用单边 z 变换：

Xu(z) = ∞Σn=0 x[n]z−n
两个"不用求逆变换"的技巧
  • 初值定理：x[0] = limz→∞Xu(z)。 为什么？z→∞ 时 z−n 只有 n=0 那一项还活着。
  • 终值定理：limn→∞x[n] = limz→1(1−z−1)Xu(z)。 为什么？(1−z−1) 相当于"累加"的逆操作，(z→1) 相当于"直流"处取值；前提是极限真的存在 （要求极点都在单位圆内，或至多在 z=1 处一个一阶极点，否则会发散或振荡）。
完整算例：用单边 z 变换解带初始条件的差分方程

解 y[n] − 0.8y[n−1] = x[n]，输入 x[n] = u[n]， 初始条件 y[−1] = 2（系统在 n=0 之前已经"带着能量"）。

第 1 步：用单边 z 变换的时移性质。单边时移要多出一项初始条件：

y[n−1]  ⟷  z−1Yu(z) + y[−1]

为什么多一项：双边时移只乘 z−1，但单边变换的求和从 n=0 开始， 丢掉了 n=−1 那一项，所以要把它补回来。这就是单边变换能"带初始条件"的原因。

第 2 步：代入并解出 Yu(z)。取 Xu(z) = 1/(1−z−1)：

Yu(z) − 0.8[z−1Yu(z) + y[−1]] = Xu(z)
Yu(z) = Xu(z) + 0.8y[−1]1 − 0.8z−1 = 1(1 − z−1)(1 − 0.8z−1) + 1.61 − 0.8z−1

为什么要把两项分开：第一项只含输入 X，是零状态响应； 第二项只含初始条件 y[−1]，是零输入响应。分开算，物理含义立刻清楚。

第 3 步：部分分式 + 查表。第一项拆成 A/(1−z−1) + B/(1−0.8z−1)， 用"盖住因子代入极点"得 A = 1/(1−0.8) = 5、 B = 1/(1−1/0.8) = −4。于是

y[n] = [ 5 − 4(0.8)n ]u[n]  (零状态)  + 1.6(0.8)nu[n]  (零输入)  = [ 5 − 2.4(0.8)n ]u[n]

第 4 步：用初值/终值定理快速验算。

  • 初值：y[0] = limz→∞Yu(z) = 1 + 1.6 = 2.6， 与公式代入 n=0 得 5 − 2.4 = 2.6 ✓
  • 终值：limz→1(1−z−1)Yu(z) = 1/(1−0.8) = 5， 公式在 n→∞ 时也趋于 5 ✓（物理上：直流输入 u[n] 经过增益 1/(1−0.8)=5 的系统）

为什么这个验算有效：系统极点是 0.8（在单位圆内），所以终值确实存在，定理适用。 如果极点是 1.2，终值定理就不适用——那时序列在发散，你还会发现 z→1 的极限根本给不出有限值。

12. 常见坑

坑 1：只写 X(z)，不写 ROC

同一个 1/(1−az−1) 至少两种序列。ROC 是答案的一部分，漏了就错。

坑 2：以为单位圆永远在 ROC 里

只有 |z|=1 落在 ROC 内，DTFT 才存在。讨论"频响"之前先确认这件事。

坑 3：把 z 变换与 DTFT 的变量混用

写 X(z) 时用它自己的变量；只有在单位圆上才能代 z=ejω 写成 X(ejω)。

坑 4：部分分式后忘了按 ROC 选方向

求系数只是第 2 步；第 3 步必须逐项判断取 u[n] 还是 u[−n−1]。这一步错了整题全错。

坑 5：把 z−1 当成 1/z 的"小量"近似

它只是记号：z−1 是"延迟一个样本"。它是定义的一部分，不是近似。

坑 6：终值定理乱用

如果极点跑到单位圆外（或单位圆上有二阶极点），终值不存在，公式给出的数是无意义的。先查极点。
